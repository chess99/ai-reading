# 海绵阅读法

## 一句话总纲

《海绵阅读法》把阅读当成一套可训练的能力系统，而不只是教人多读几本书：先用明确动机和选书判断决定读什么、读到什么程度，再用笔记、提问、复述、思考和输出完成深度吸收，最后通过主题阅读、知识体系、行动实践和稳定习惯，把书里的内容转化为自己的认知、能力、作品和生活变化。

作者反复强调，真正的阅读成果不看“读完了多少本”，而看阅读吸收率有多高、对人生和行动的改变有多深。读书不是孤立行为，它应当服务于能力养成、目标推进、人生愿景和具体问题解决。

## 核心框架：海绵阅读法的七大能力

本书把高效阅读拆成七种互相影响的能力：

1. 高效做读书笔记的能力：用三种层次的笔记完成理解、筛选、记忆和输出。
2. 独立思考的能力：在阅读中产生想法、判断想法、整理想法。
3. 掌握阅读速度的能力：该快时速读检索，该慢时精读消化。
4. 阅读不同书籍的能力：不同书类有不同价值，也需要不同读法。
5. 建立知识体系的能力：通过主题阅读把零散知识组织成有目的的系统。
6. 让读书有用的能力：把阅读与目标、成长、行动、创造和知行合一连接起来。
7. 长期持续稳定阅读的能力：把阅读变成习惯，用日日不断之功取代偶尔爆发。

这七种能力形成一个闭环：选书和阅读目标决定输入方向，笔记和思考决定吸收质量，速度和分类读法决定效率，主题阅读决定知识体系，行动和输出决定现实改变，习惯决定这一切能否长期发生。

## 阅读前：先明确为什么读

作者把“阅读动机”放在第一位。拿到一本书，不应立刻从第一页机械读起，而要先问：

- 我为什么要读这本书？
- 它和我现在的问题、目标、兴趣或困境有什么关系？
- 我想从书中得到什么？
- 它可能给我行动指导、精神力量，还是满足认知需求？

阅读动机会改变阅读速度、阅读深度和关注重点。动机明确时，阅读从被动接收信息变成主动寻找答案。动机不强，或只能勉强写出一个理由，作者通常会建议暂时不读。

阅读动机也要在读完后回看。读书文章的核心追问是：“读这本书，和没读这本书，对我来说有什么区别？”这个问题会迫使读者从书里提取真实的改变量，避免停留在“好像有收获”的模糊状态。

## 选书：先判断值不值得读、值不值得精读

本书反对不加筛选地追求数量。不是所有书都值得通读，更不是所有书都值得精读。选书和找书本身就是主动设计成长的过程。

### 好书的基本判断

论述类书籍可从三个方面判断：

1. 是否有明显错误和局限。
2. 是否有创见，能不能提供新知。
3. 是否有成熟、清晰的逻辑结构和体系。

好书常见特征包括：主题下认可度高的经典书、反复修订的经典教材、评分人数足够且评价较高的作品、权威榜单或重要奖项中的作品。但作者也提醒，判断标准只是辅助，真正的选书眼光来自长期阅读形成的“手感”。

### 找书的六种方法

做主题阅读或搭建书单时，可以从这些渠道海选：

1. 豆瓣读书：书名搜索、标签搜索、书单搜索、相关推荐。
2. 卖书网站：当当、京东、亚马逊、多抓鱼、孔夫子旧书网等。
3. 图书馆：适合宽泛主题，尤其是大学图书馆。
4. 微信读书等电子书平台：试读、全文搜索、作者搜索、书单搜索。
5. 以书找书：参考文献、引用书目、同主题推荐、作者全集。
6. 阅读导游：师长、资深读者、读书博主、专精主题的人，以及导读型书籍。

### 筛选书单

海选出一批书后，不应全部通读，而要通过检视阅读分成三类：

- 精读书单：主题下最重要、最能帮助自己的 3-5 本。
- 速读书单：对精读书单做补充的 5-10 本或更多。
- 淘汰书单：与主题无关、质量低、逻辑差、没有新知的书。

精读书单要讲究组合效果。一本负责入门和激发兴趣，一本负责更专业的核心内容，一本打开宏观视野，一本进入专家问题，一本了解前沿趋势；或者选择开创者、分歧者、综合者的作品，让观点之间形成张力。

## 读法一：用速读做筛选和定位

作者区分“值得的慢”和“不值得的慢”。精读精思的慢是必要的，阅读障碍造成的慢则要克服。阅读的理想状态不是永远快，而是能根据目的、书籍和章节选择速度。

速读不是把一本书一目十行地从头读到尾，而是在短时间内抓取主要信息，判断它是否匹配目标、哪些部分值得读、是否需要启动精读流程。

速读七步：

1. 写下阅读目标：想解决什么问题。
2. 看书名、作者介绍、内容提要、序言、前言，判断主题、可靠性和写作意图。
3. 研究目录，圈出关键词和最相关章节。
4. 快速翻读标题、特殊标记、图表、摘要等，继续检索关键词。
5. 细读被折页或标记的重点部分。
6. 围绕阅读目标绘制一张思维导图。
7. 用自己的话回答阅读前的问题。

速读最适合结构清晰的非虚构、论述类书籍，也适合选书、判断阅读方式和限时查找信息。小说、诗歌、散文、国学经典等更依赖细节、情绪和语言节奏的书，不适合粗暴速读。

## 读法二：用三层笔记完成精读吸收

本书的核心方法是三种层次的读书笔记。做笔记不是阅读之后的额外负担，而是精读过程本身。笔记的作用有两个：帮助当下理解，帮助以后记忆和调用。

### 第一层：万能读书笔记模板

这是局部、碎片化但高价值的笔记，用来在阅读过程中筛选重点、保留触发点。九个要素是：

1. 阅读动机：为什么读，想解决什么问题。
2. 核心概念：论述类书的关键概念；小说则换成核心人物和核心情节。
3. 金句收集：高度浓缩作者思想或触动自己的表达。
4. 故事案例：支撑观点、便于理解和迁移的案例。
5. 联想发散：它让我想到什么旧知识、经历、现实问题或其他书。
6. 任何疑问：哪里不懂、哪里存疑、哪里需要查证。
7. 洞见时刻：认知被刷新、观念被改变、突然想明白的瞬间。
8. 情绪感受：被打动、震动、抗拒、痛苦、兴奋等体验。
9. 行动灵感：读完后可以马上做什么、试什么、创造什么。

这个模板的重点不在抄录，而在让大脑主动筛选、分类、联结和加工信息。

### 第二层：思维导图笔记

这是全局概览笔记，用来把一本书的逻辑结构提炼出来。做法是：

1. 准备一张横向白纸，把书名写在中间。
2. 用章节名或自己重组后的逻辑作为一级分支。
3. 回看第一遍标注内容，提取关键词和关键句，梳理关系，附上页码或可检索词。
4. 保持实用，不追求装饰。它的价值是复习、检索、理解结构，不是展示。

思维导图笔记模拟作者从主题向外展开的思考过程，也帮助读者获得鸟瞰视角。对小说，可以把一级分支设为作者及背景、主要人物、重要情节。

### 第三层：读书文章

这是结构内化笔记，用写作逼迫自己深度思考、复述、筛选和重组。它不一定要公开，也不要求文采，核心是回答：

读完这本书后，我和没读之前有什么不同？

作者给出一个总结公式：

旧的我（障碍、卡点、旧观念和旧方法）+ 书中的具体启发点（概念、金句、案例、方法）= 新的我（新观念、新方法、可落地行动）。

常见写法有四种：

1. 清单式：提炼几个最打动自己的要点。
2. 单点式：抓住一个最重要的启发深入写。
3. 问题式：提出一个关心的问题，用书中知识回答。
4. 现象式：结合现实事件，用书中框架解释。

写读书文章的价值在于：用自己的话完成精细复述，把零散收获串成结构，并筛出重点中的重点。

## 提问与思考：阅读不是让大脑成为作者的跑马场

作者把阅读思考分成三个阶段：想法产生、想法判断、想法整理。很多人思考混乱，是因为把这三个阶段混在一起。

### 第一阶段：产生想法

此阶段先追求“想得多”，再追求“想得好”。四个方法：

1. 前后对比：读前的我和读后的我有什么变化？新知改变了我的信念、态度、行为或生活方式吗？
2. 提问：写下所有疑问，用红黄绿标记理解程度，模仿书里的好问题，用 5W2H 练习。
3. 联想：把新知识和自身经历、现实生活、其他书、案例、抽象概念连接起来。
4. 行动导向：追问“我能用它做什么”，学到一个方法后尽量立刻用三遍。

提问是思考的发动机。对实用类书，重点问是什么、为什么、怎么做；对小说，重点问人物为何如此行动、情节为何这样发展、它揭示了什么生活隐喻；对主题阅读，问题要来自自己的目标和困惑。

### 第二阶段：判断想法

独立思考不是故意反对作者，而是审慎地建立自我意见。判断步骤是：

1. 区分事实和观点。事实可证实或证伪，观点只能讨论同意与否。
2. 核查事实和观点。事实要看来源、一手材料、传播过程和可靠性；观点要看论题、论据、结论、推理、立场和情绪操纵。
3. 得出自己的观点。无论同意还是反对，都要组织理由。
4. 让观点成长。继续接触反方材料和新证据，允许观点修正。

### 第三阶段：整理想法

想法产生和判断后，要用结构化方式整理：

1. 汇总精华：从笔记中提取最影响自己的内容。
2. 分组归类：尽量符合 MECE，避免重复和遗漏。
3. 提炼结构：可以沿用原书结构，也可以用“是什么、为什么、怎么做”、现状-问题-策略、二维矩阵、流程法等框架。
4. 形成文字：用写作让想法变清楚。

作者的关键判断是：阅读后的思考、输出和实践，花费数倍于阅读本身的时间是正常的。阅读只是起点。

## 复述与记忆：把瞬时记忆变成长时记忆

读完就忘不是记忆力差，而是信息只停留在瞬时记忆。要进入短时记忆，需要主动加工：筛选、分类、联结和复述。要进入长时记忆，需要有规律的重复和使用。

有效记忆的原则：

- 简化信息：提取关键词、关键句。
- 结构化信息：用思维导图整理逻辑。
- 用自己的话复述：把作者语言翻译成自己的语言系统。
- 联想发散：把新知识粘到旧知识和生活经验上。
- 加入情绪和自身关系：大脑更愿意记住与自己有关、情绪反应强的信息。
- 复习：睡前、一天后、一周后、一个月后都是重要节点；也可以把复习嵌入流程，如做导图、隔天上色、写文章前复习、调用时复习。
- 用起来：调用和实践是更深层的记忆。

复述不是简单背原文。有效复述要用自己的话解释概念、结构、案例和启发，并能迁移到自己的问题中。

## 不同书要有不同读法

作者借郝明义的分类提醒读者不要“偏食”：

- 主食阅读：实用类书，解决学习、工作、生活中的现实问题。
- 美食阅读：文学、史学、哲学、社科经典，审视人生、价值和世界。
- 甜食阅读：娱乐消遣型阅读，激发阅读兴趣，但不能成为全部。
- 蔬果阅读：工具书、百科、年鉴等查阅式阅读。

### 实用类书籍

实用类书的底层结构是：是什么、为什么、怎么做。

读这类书时先判断作者要解决的问题是否与自己匹配，再提取行动建议，最后理解原理，判断自己是否被说服。实用类书最重要的读法是行动。只读得激动、感动，最后一动不动，就没有真正读好。

### 哲学和社科类书籍

这类书帮助读者回到思想本源，理解世界为何如此运转，也训练读者围观优秀思考者如何提出问题、构建概念、推导结论和反驳旧观念。阅读时要重视概念、问题意识、论证结构、思想分歧和现实解释力。

### 小说

小说不能只读梗概。它的价值在场景、人物、情绪、细节和隐喻中。读小说要投入地、代入地、从头到尾地读。笔记可分三部分：作者和背景、主要角色、重要情节。最终要思考人物处境、选择和命运对自己生活的启发，提取生活隐喻。

论述类书持续影响人的方式常常是“框架”，小说持续影响人的方式常常是“隐喻”。

### 历史类书籍

读历史不是为了死记年份，而是认识过去、理解现在、看见趋势，并从前人的言行中学习做人做事。读法是：

1. 从感兴趣、简单好玩的内容开始。
2. 用一本或几本通史搭建基本历史世界观。
3. 深入感兴趣的国家、时代或专题，不只看一家之言。
4. 配合传记、小说、纪录片、博物馆、遗迹等补充细节。
5. 回到通史重新串联，获得新的理解。

## 建立知识体系：从读一本书到读一个主题

知识体系不是知识堆积，而是有机系统。它有三个特征：

1. 由若干要素组成。
2. 要素之间相互作用。
3. 整体具有特定功能和目的。

没有目的的知识体系是死的。一个真正可用的知识体系，必须服务于个人目标、人生问题或能力建设。它让知识从零散砖头变成有结构的建筑，让读者能分析、判断、行动和解决复杂问题。

### 建立路线

作者建议综合三组路线：

- 野生模式 + 高度规划模式：平时保持好奇心，闲逛偶遇；发现重要方向后，切换到有计划的主题阅读。
- 先广 + 先深：早期可以广泛涉猎，但要尽快锁定垂直方向，建立思考主场，再向周边扩展。可参考 70/20/10：70% 投入专业领域，20% 投入相关周边，10% 投入未知领域。
- 以个人为中心 + 以知识为辅助：不是为了复制学科体系而学习，而是让知识体系服务于自己的志向、目标和问题。

### 主题阅读五步

1. 确定主题：从人生目标、年度关键词、现实困境、能力短板或长期问题出发。
2. 海选书单：用豆瓣、卖书网站、图书馆、电子书平台、以书找书、阅读导游等渠道找 30-50 本相关书。
3. 筛选书单：用检视阅读分成精读、速读、淘汰三类。
4. 分别精读和速读：先精读主题下最好的 3-5 本，建立总体把握，再速读补充书；必要时把速读书升级为精读书。
5. 做主题笔记：先做单本书笔记，再用目录矩阵表做横向比较，最后把问题和答案整理成书、课程或产品化笔记。

目录矩阵表的价值在于把多本书当成整体来读：看哪些内容是共通的，哪些是某书独有的，哪些观点有分歧，哪些论述可以互补。

主题阅读的最高目标不是囤积材料，而是围绕自己的核心问题，向一组优秀作者组成的“智囊团”征求答案，再结合实践和思考，形成自己的系统答案。

## 把书转化为行动：让读书有用是一种能力

作者反对抽象地问“读书有没有用”，主张问“怎么读书才有用”。她总结读书的五种重要作用：

1. 跨越现实和梦想的鸿沟。
2. 提升对世界、人生、他人和自我的理解。
3. 扩展视野和眼界。
4. 疗愈自己和关心的人。
5. 获得人格和生活选择的参考答案，雕刻自我。

让读书有用的五个原则：

1. 精准输入：需要什么学什么，从目标、愿景、困境、挑战和能力短板倒推阅读方向。
2. 追问成长：从每本书中提取成长养分，即使书不完美，也问它提供了什么新东西。
3. 关联到我：始终追问“这本书和我有什么关系”。
4. 行动导向：读完后做点什么或创造点什么。
5. 躬身入局：真心认可一种观念，就用行动和人生实践它。

行动导向可以用 5W1H 落地：

- Why：我为什么要用它？
- When：它适合什么时候用？
- Who：它适合谁？
- Where：我能把它用在哪里，能否迁移到别处？
- What：它能转化成什么产品、项目或成果？
- How：我如何把它转化为具体行动？

作者强调，“知道”不等于“做到”。知道只是起点，做到需要多次刻意练习。知和行会互相强化：知识在行动中变深，行动在知识指导下少走弯路。

## 输出：从读书文章到个人品牌

输出不是狭义的写文章，而是把输入转化为行动、表达、作品、项目、课程、服务或生活改变。最深的化为己用是创造。

本书中的输出有三个层级：

1. 单本书输出：写读书文章，回答这本书如何改变我。
2. 主题输出：把主题阅读的问题和答案整理成书、课程或产品化笔记。
3. 价值输出：用帮助过自己的知识帮助别人，形成内容、社群、咨询、课程、书籍甚至平台。

读书变现金字塔分四层：

1. 写手级：讲书稿、领读稿、推广稿、视频文案。
2. 自媒体级：广告投放、流量分成、平台补贴、直播带货。
3. 知识付费产品经理级：书、付费课程、付费社群、一对一咨询。
4. 平台级：打造平台，为其他知识型 IP 提供承载。

底层逻辑是：先通过阅读真正让自己受益，再把帮助过自己的东西整理出来帮助别人。变现不能跳过吸收、思考、实践和创造。

## 长期阅读：用习惯代替意志力

作者用南极探险的例子说明：长期稳定推进比偶尔爆发更可靠。阅读高手不是只在状态好时猛读，而是能保持日日不断之功。

习惯形成的原理是重复。前期由前额皮层负责，需要意志力和决策；神经通路建立后，基底神经节接管，行为变得自动化。目标是让阅读成为日常 40%-50% 自动行为中的一项。

依据《掌控习惯》的四阶段模型，阅读习惯也要对应设计：

1. 得到提示：让阅读显而易见。固定时间、绑定老习惯、固定地点和设备、在环境中增加书和阅读视觉提示。
2. 产生渴求：让阅读有吸引力。自由阅读，允许跳读、不读完、重读、随意选读；把阅读与愉快、有趣、身份认同和人生愿景绑定。
3. 做出反应：让阅读简便易行。降低启动门槛，设置微习惯，如每天读 1 页或 2 分钟；提前准备书、地点和时间。
4. 获得奖励：让阅读带来满足感。记录进度、可视化成果、复盘收获、给予奖励，让大脑愿意重复。

习惯养成会遇到四个阶段：

- 禁欲期：欲望强，要避开高诱惑环境，设置极低下限。
- 动力缺乏期：要回到意义，使用愿景、奖励、惩罚、复盘、社群和公开承诺。
- 平稳期：容易误以为已经成功，要适当提高要求。
- 倦怠期：重复带来停滞感，要引入新作者、新领域和新挑战。

不要陷入“全无或全有”。中断不等于清零，每一次重复都在强化神经通路。最好一次只培养一个习惯，降低负荷。

## 可执行的海绵阅读流程

1. 选书前：写下当前问题、目标或年度关键词。
2. 找书：用多渠道海选，别被动等别人给书单。
3. 检视：看书名、作者、前言、目录和关键章节，决定淘汰、速读或精读。
4. 开读前：在空白页写阅读动机。
5. 第一遍：用万能读书笔记模板标记九类信息。
6. 第二遍：跳读标记内容，做思维导图笔记，提炼结构和关键词。
7. 思考：用前后对比、提问、联想、行动导向产生想法；再区分事实观点，判断论据和推理。
8. 复述：看着导图，用自己的话讲清楚全书框架、核心概念和关键启发。
9. 输出：写一篇读书文章，回答“读完后我有什么变化”。
10. 行动：把行动灵感转成一次实验、一个项目、一个习惯或一个作品。
11. 复习：当天睡前、一天后、一周后、一个月后复习导图和文章；调用时再回看局部。
12. 体系化：对重要主题做主题阅读，用目录矩阵表比较多本书，整理自己的问题和答案。

## 最重要的提醒

本书最终落点不是“学会一套读书技巧”，而是“用阅读支撑人生”。如果只是获得方法的兴奋感，随后仍用旧流程读书，学习就是无效的。真正的改变只发生在行动里。

海绵阅读法的难点也正在这里：做三层笔记、提问、复述、写读书文章、主题阅读、实践行动都比浏览和画线困难。但作者明确主张，读书要在困难和容易之间选择困难。少读但读透，慢读但吸收，输出但言之有物，行动但持续练习，才是这套方法的核心精神。
