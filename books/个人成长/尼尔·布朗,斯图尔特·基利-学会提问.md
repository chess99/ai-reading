# 学会提问

## 核心主张：为什么需要批判性思维

我们生活在一个信息嘈杂、观点泛滥的时代。商人、政客、专家、媒体每天都在试图说服我们接受某些结论，而他们提供的信息往往是有选择性的，甚至是误导性的。专家会自相矛盾，权威会犯错，感情会蒙蔽判断。

在这种环境下，有两种截然不同的思维姿态：

**海绵式思维**：被动吸收信息，对听到和读到的一切不加甄别地接受。优点是积累知识快；致命缺陷是无法判断哪些信息值得相信、哪些应该摒弃。

**淘金式思维**：主动与信息互动，不断提出批判性问题，像淘金一样从信息中筛选出值得信赖的部分。这是本书倡导的核心姿态。

批判性思维有两种用法，品质截然不同：

- **弱势批判性思维**：用批判性技能捍卫自己已有的信念，目的是击败对手而非追求真理。
- **强势批判性思维**：用批判性技能评价所有主张，包括自己的主张，保持开放心态，愿意修正信念。

真正的批判性思维者拥有四项核心价值观：**自主决断**（不盲从）、**好奇心**（不断追问）、**谦恭有礼**（认识到自己可能出错）、**对严密论证的尊重**（以理由和证据为判断依据）。

## 第一步：找到论题与结论

**论题**是引发讨论的问题或争议，分为两类：
- **描述性论题**：关于世界过去、现在或将来是什么样的（"手机是否导致癌症"）
- **规定性论题**：关于什么应该做、什么是对的（"是否应该禁止校园手机"）

**结论**是写作者或发言者希望你接受的核心主张。找结论的五条线索：
1. 论题是什么（结论是对论题的回答）
2. 寻找指示词：因此、由此可知、表明、证明、显示出、事情的真相是……
3. 检查文章开头和结尾（常见位置）
4. 排除不可能是结论的内容：例子、数据、定义、背景材料
5. 考察作者背景和组织机构（推断可能的立场）

没有找到结论就开始评价，等于对着空气辩论。

---

## 第二步：找到理由

**理由**是支撑结论的信念和陈述，是"为什么应该相信这个结论"的答案。**证据**是证明理由真实性的事实材料。

论证的基本结构：**甲之所以成立，是因为乙**——甲是结论，乙是理由。

找理由的方法：找到结论后，不断追问"为什么？"，凡是回答这个问题的陈述就是理由。指示词包括：由于、因为、研究显示、由以下材料支撑……

警惕**操控型论证**：先有结论，再倒推选择理由，目的不是追求真理而是证明预设结论。律师的辩护是典型例子——理由服务于委托人的立场，而非服务于事实。

---

## 第三步：识别歧义

语言天然模糊。许多重要词汇（自由、淫秽、幸福、公平、质量）有多重含义，不同的理解会导致截然不同的评价结论。

识别重要歧义的方法：
1. 在论题、结论、理由中寻找关键词
2. 一个词越抽象，歧义可能越大
3. **反串测试**：如果你持相反立场，会如何定义这个词？如果定义不同，说明存在重要歧义
4. 想象这个词代表的具体画面，画不出来则可能存在歧义

定义一个关键词有三种方式：同义替换（不够精确）、举例说明（不够全面）、具体标准定义（最有用）。字典定义往往不足以解决特定语境下的歧义问题。

**谁想说服你，谁就有责任澄清歧义**。如果对方拒绝解释，你有权拒绝接受其论证。

---

## 第四步：识别假设

论证的表面结构只有理由和结论，但将两者联系起来的是大量**没有明说出来的信念**，即假设。假设的特征：通常隐藏、论证者认为理所当然、对结论有重大影响、可能具有欺骗性。

假设分两类：

### 价值观假设

**价值观假设**是对"哪种价值更重要"的隐含判断。例如：认为公共安全比个人自由更重要，因此支持毒品管制。

常见的价值观冲突对立：
- 个人责任 vs 集体责任
- 竞争 vs 合作
- 自由 vs 秩序
- 效率 vs 公平
- 进步 vs 传统

找价值观假设的方法：
1. 检查作者背景（他的利益倾向可能透露其价值偏好）
2. 思考结论背后哪种后果被重视（反映什么价值观）
3. 反串：如果持相反立场，会关心哪些价值观？
4. 留意个人权利 vs 集体福祉的冲突（几乎无处不在）

### 描述性假设

**描述性假设**是对世界"是什么样的"的隐含信念，比如"更多竞争会带来更好的结果"或"人们能够理性地权衡利弊"。

找描述性假设的方法：
1. 不断追问理由和结论之间有什么鸿沟，填补这个鸿沟需要什么额外信念
2. 设想：即使理由成立，结论是否仍可能不成立？为了让结论成立，还需要什么假设？
3. 站在反对方立场思考
4. 留意常见的错误假设，如"结果反映了个人选择""过去发生的事将来还会发生"

---

## 第五步：识别论证谬误

**谬误**是论证中的欺骗手段，依赖错误或高度存疑的假设，使结论看似合理。识别谬误最有效的方法不是死记名字，而是养成问"这个假设成立吗"的习惯。

### 主要谬误类型

**转移注意力类**

- **人身攻击谬误**（ad hominem）：攻击提出论证的人，而非论证本身。"他是自由派，所以他的观点不可信。"
- **转移话题谬误**（red herring）：将讨论引向不相干话题，使原论题被搁置。
- **稻草人谬误**：歪曲对方立场，将其变成容易攻击的版本，再加以驳斥。

**错误推理类**

- **诉诸公众谬误**：因为很多人相信，所以是对的。
- **诉诸可疑权威谬误**：引用对该论题没有专门知识的权威。
- **诉诸感情谬误**：用情绪化语言代替理性证据，通过恐惧、怜悯、爱国主义等情绪说服人。
- **滑坡谬误**：假设采取某行动会引发一连串不可控的后果，而实际上有机制可以阻止。
- **虚假的两难选择谬误**：在多种选择存在时，假装只有两种选择。
- **追求完美解决方案谬误**：因为某方案不能完全解决问题，就主张不应采用。
- **循环论证谬误**（begging the question）：用结论来证明结论，只是措辞不同。
- **乱扣帽子谬误**：给某种行为起个名字，就以为解释了它的原因。
- **叙述谬误**：因为能讲出一个貌似合理的故事，就以为找到了正确的因果解释。
- **计划谬误**：对完成工作所需时间过于乐观，忽视过去的失败先例。
- **粉饰谬误**：用模糊但引发积极联想的词语（"民主""自由""进步"）代替具体论证。

## 第六步：评估证据质量

结论能否成立，取决于证据是否可靠。主要证据类型及其局限：

### 个人经历与典型案例

个人经历生动具体，但样本极小，极易导致**以偏概全谬误**。单一案例能说明某种结果的可能性，但不能说明其代表性或概率。

### 当事人证言

需要追问：
- 证言是如何被选出来的？（选择性偏差）
- 提供证言者有没有个人利益？
- 证言省略了哪些信息？

### 专家意见

评估专家意见的标准：
1. 专家在该领域是否有真正的专门训练和经验？
2. 专家是否有第一手信息渠道？
3. 专家是否存在利益冲突或情感偏见？
4. 专家意见是否有其他同行的重复验证？

互联网时代，虚假权威泛滥，尤其要审查信息来源的可信度、论证结构质量、是否与其他高信誉来源相互印证。

### 调查和研究报告

调查的常见问题：
- **措辞偏差**：问题的表述方式影响回答（"你支持增税来改善教育"和"你反对让纳税人承担更多负担"可能测量同一政策却得到相反结果）
- **语境偏差**：前后问题影响对某一问题的回答
- 调查对象不愿如实回答

科学研究的优势在于可重复性、控制变量、语言精确性。但需要注意：
1. 研究质量参差不齐，发表不等于质量保证
2. 研究结果常常相互矛盾
3. 研究只能"支持"结论，不能"证明"结论
4. 研究人员也有偏见和利益
5. 资助来源可能影响研究结论
6. 研究发现会随时间改变

评估研究的关键问题：**样本够大吗？样本有代表性吗？取样是否随机？测量方法是否合适？**

## 第七步：寻找替代原因

当论证涉及因果关系时，必须寻找**替代原因**（rival causes）——同样合理、能解释相同现象的其他原因。

**相关性不等于因果关系**。两个变量同时变化（甲和乙有关联），至少有四种解释：
1. 甲是乙的原因
2. 乙是甲的原因（因果方向反转）
3. 第三个因素丙导致了甲和乙（共同原因）
4. 甲和乙相互影响

**事后归因谬误**（post hoc）：因为乙在时间上紧随甲之后发生，就认为甲导致了乙。

**过度简化因果关系谬误**：将复杂的多因多果归结为单一原因。在涉及人类行为的领域，多因共同作用是常态，而非例外。

**基本归因错误**：在解释他人行为时，过高估计个人性格因素，过低估计环境因素。

**确认偏误**：倾向于寻找、注意、记住与自己既有信念一致的证据，忽视不一致的证据。

寻找替代原因是一种创造性工作，需要多视角思考：社会学家、心理学家、经济学家、生物学家看到的原因可能截然不同。

## 第八步：识别数据欺骗

统计数据貌似精确客观，实则容易误导。常见的数据欺骗手法：

**平均值混淆**：平均数（mean）、中位数（median）、众数（mode）三种平均值往往差异巨大。收入、房价等偏态分布的数据中，平均数会被极端值拉高，中位数更能反映典型水平。

**缺少分布信息**：只知道平均值不够，还需要知道全距和分布。例如，某病存活中位数为10个月，但也可能部分患者活到了80岁——这对患者的决策至关重要。

**测量误差**：统计依赖测量，测量本身存在误差。用来测量的工具是否经过校准？不同测量者的标准是否一致？

**用A的数据证明B的结论**：论证者使用的数据实际上证明的是与结论不同的事情。应先想"需要什么数据才能支持这个结论"，再与实际提供的数据比较。

**省略信息欺骗**：仅呈现绝对数字（不给比率）或仅呈现百分比（不给绝对数字），都可能造成误导。

评估数据的核心习惯：追问数据怎么得来、缺少了什么比较参照、平均值类型是什么、数字背后的分布是什么样的。

## 第九步：追问省略的信息

任何论证都是不完整的。立论者总是选择性呈现对其有利的信息，省略不利信息。省略可能是无意的，也可能是有意的。

重要的省略信息类型：
1. 常见的**反驳论证**（对方会提出哪些理由？）
2. 与论证相冲突的**研究或证据**
3. 关键词的**替代定义**
4. 不同的**价值偏好或视角**
5. 事实断言的**来源和质量**
6. **程序细节**（如何得到这些数据？）
7. **省略的或不完整的数字**（比率？绝对数？）
8. 行动的**负面后果**（特别是长期后果）

面对任何有力的论证，暂停一下，问："写作者可能没有告诉我什么？如果知道这些信息，我对这个论证的评价会改变吗？"

遇到表示大小或程度的词（"更多""更快""更安全""降低了"），务必追问具体数字，因为"比之前好了10倍"和"比之前好了0.001%"对决策的意义截然不同。

## 第十步：得出合理结论

理由很少只指向一个唯一正确的结论。**二分式思维**（非此即彼、非黑即白）是常见的认知陷阱，它假设一个问题只有两种答案，从而遮蔽了大量更合理的可能性。

**灰度思维**是更成熟的替代方案：承认大多数重要问题有多种合理答案，结论往往取决于条件、语境和前提假设。

处理二分式思维的三个工具性问题：
1. 这个结论**在什么时候**成立？
2. 这个结论**在什么地方**成立？
3. 这个结论**为了什么目的**成立？

**条件句**是表达有限度结论的技术手段。"如果……，那么……"的表述既保留了合理性，又承认了不确定性，体现了批判性思维者应有的谦卑。

## 批判性思维的障碍

即便掌握了工具，应用过程中仍有多种"减速带"：

**正确提问带来的不适**：批判性问题可能让被问者感到被质疑甚至被威胁，需要在策略上注重语气和方式，避免破坏关系。

**快思考（系统1思维）**：大脑默认模式是根据有限信息快速做判断。系统2思维（慢思考）需要刻意启动，能否约束自己放慢速度是关键。

**晕轮效应**：因一个人在某方面的优点或缺点，便推断其在所有方面都同样优秀或糟糕，导致对其观点的不公平评价。

**信念固着与确认偏误**：对已有信念的保护本能使我们选择性接受信息，倾向于寻找支持已有信念的证据，拒绝不一致的证据。承认自己可能错了需要真正的勇气。

**可得性启发法**：只依据手边最容易获得的信息做判断，而非收集做出更好决定所需的信息。加之近因效应，最近发生的事件会被过度重视。

**答非所问**：被问及某问题时，回避真正的问题，用一个更容易回答的问题代替，将讨论引向无关方向。

**自我中心**：将自己的视角、需求、经历置于中心，难以真正进入他人的思考框架。知识的诅咒（忘记自己曾经不懂某事时的状态）使得和不同背景的人沟通特别困难。

**一厢情愿**：相信某事是真的，因为希望它是真的，而非因为有证据支持。这是批判性思维最大的敌人——我们希望世界是某种样子，便宣布它就是那种样子，用信念来塑造事实而非用事实来修正信念。

## 如何将批判性思维应用于写作和表达

批判性思维不只是评价他人论证的工具，也是构建自己论证的标准：

1. **明确论题**：将任务表述为一个具体问题，聚焦论证方向
2. **识别并澄清关键词的歧义**，尤其是结论和理由中的核心术语
3. **找出自己论证中的价值观假设和描述性假设**，主动说明
4. **研究反驳论证**，在论证中承认并回应最有力的反对意见
5. **使用高质量证据**：科学研究优于个人经历，有据可查优于权威断言
6. **避免省略重要的负面信息**——有意的信息省略会降低论证可信度
7. **使用合适的语气**：咄咄逼人的语气会让读者关闭对话渠道；谦逊、开放的语气更有助于说服

## 核心框架总览

| 问题 | 目标 |
|------|------|
| 论题和结论是什么？ | 找到讨论的焦点和立场 |
| 理由是什么？ | 了解支撑结论的依据 |
| 词语有歧义吗？ | 确保理解一致 |
| 隐含哪些假设？ | 发现看不见的逻辑前提 |
| 有没有谬误？ | 识别欺骗性推理 |
| 证据可靠吗？ | 评估事实断言的基础 |
| 有替代原因吗？ | 避免简化的因果解释 |
| 数据有欺骗性吗？ | 识别统计误导 |
| 缺少什么信息？ | 补足论证的完整性 |
| 能得出什么结论？ | 超越非黑即白，寻找最合理的立场 |

这十个问题是一套可以应用于任何领域、任何层次读者的通用工具。批判性思维的最终目标不是否定一切，而是建立一种自主、理性、对证据负责的思维方式——对自己诚实，也对他人公正。
