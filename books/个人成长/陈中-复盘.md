# 复盘

## 什么是复盘

复盘源自围棋术语，指下完一局棋后，重新在棋盘上走一遍，考察哪步下得好、哪步下得差，以及各种可能的不同走法。通过这个过程，棋手能发现棋路的变化、总结新的套路，甚至形成棋谱，从而提升棋力。

引入工作领域后，复盘的定义是：**在头脑中对过去所做的事情重新"过"一遍**，通过对过去的思维和行为进行回顾、反思和探究，找出原因，找到规律，从而指导我们解决问题，帮助我们提升能力。

四个动作缺一不可：
- **回顾**——回顾过程（what 层面）
- **反思**——反思原因（why 层面）
- **探究**——探究规律（假设层面）
- **提升**——提升能力（最终目的）

### 复盘与总结的本质区别

复盘不等于总结。总结是对已发生事件的描述、分析和归纳，是静止的、平面的；复盘还包含对**未发生行为的虚拟探究**——推演，是动态的、立体的。

推演是复盘与总结最显著的区别。推演让我们能审视不同路径的可行性和后果，像下棋一样看清"如果那步换另一种走法，局面会如何演变"。沙盘是事前推演，复盘是事后推演；事后推演有了实践经验作参照，得出的结论不再只是想象中的可能性，而是具有更高确定性的方法。

### 复盘的对象与时机

理论上，任何发生过的事情都可以成为复盘对象——自己做的、他人做的，大事、小事，皆可。联想总结的三条原则：

1. **小事及时复盘**——因为小，容易过去就过去，所以要及时。
2. **大事阶段性复盘**——不能等全部完成再复盘，要在关键节点检验是否偏离目标。
3. **事后全面复盘**——整件事完成后，有了完整画卷再全盘回顾。事后全面复盘是"做事的真正完成"，没有它，事情只算做完了一半。

## 复盘的心态

### 不自欺：区分"我"与"我的表现"

复盘中最大的障碍是自欺——不愿无情地审视自己。

根本原因在于：人们常把"我某个方面有问题"等同于"我这个人有问题"，把对具体做法的技术性质疑偷换为对人格的全面否定。

破解方法是把**"我"和"我的表现"区分开**。身体生病不代表整个人坏掉，某个做法出错也不代表品性不行。就像刘翔跑不赢姚明打篮球，但这不否认刘翔是110米栏世界冠军。

区分后，可以像看待他人一样看待自己的过去，获得"旁观者视角"，看问题更清晰。

还有一个实用框架：**学习区域与表现区域**。

- **表现区域**：竞技状态，目标是减少失误，最大化绩效。
- **学习区域**：训练状态，目标是改善自己，期待犯错，因为错误指出了改进方向。

复盘属于学习区域。在学习区域里，错误和问题是受欢迎的——它们是提高的机会。当在复盘中发现自己开始自我美化时，对自己说"现在是在学习区域，发现问题没有任何风险"，可以打破自欺的冲动。

柳传志对此的要求是："不给自己留任何情面地把这个事想清楚，把事情想明白。"

### 有胜心：胜己而非胜人

"有胜心"是双刃剑：

- **正向**：挑战自己潜能，不断突破，这是对的——"胜己之心"。
- **反向**：总想着胜过别人，则进入防御模式，只会批驳对方、巩固自己，失去吸收他人长处的机会。

复盘他人时，若带着否定态度，有两重误区：
1. 否定的可能只是自己以为的别人的观点（沟通漏斗：你听到的可能只是别人想表达的 40%）。
2. 别人的观点是动态的，你否定的很可能是他很久之前的阶段性想法。

**禀赋效应与损失规避效应**解释了为何人们难以放弃自己的观点：一旦拥有某个看法，就会高估其价值；放弃它，在心理上相当于承受损失，而人对损失的痛苦感大于等量收益的喜悦感。

因此，复盘时发现自己在评判复盘对象，应立刻停下。如果复盘对象真的很差，有两种做法：一是反求诸己，看看自己是否有同样的问题；二是挑战自己，尝试从对象身上找到哪怕一点值得学习的东西。

## 复盘的六步操作

联想总结的原始四步为：回顾目标→评估结果→分析原因→总结规律。作者在此基础上扩展为六步：

### 第一步：回顾目标

复盘的出发点是目标。目标既是行动方向，也是评判成败的标准。

关键注意事项：**警惕将手段当作目标**。比如，老板让秘书"买机票"，真正目标是"准时到达客户公司做培训"，坐飞机只是手段。秘书若只盯着买机票，而不是确保准时到达，就犯了目标替换的错误。

回顾目标时要多问：这是当时做事的真正目的吗？是最终目标吗？有没有用手段替代了目标？

实操技巧：将目标展示在显眼位置（白板或投影），在整个复盘过程中随时可见，防止讨论偏离主轴。

### 第二步：叙述过程

将做过的事构建为一个显性的"盘"，为后续分析提供素材。合格的过程叙述需满足三条标准：

1. **真实客观**——不主观美化，不有目的地筛选，实事求是。这是首要条件，虚假信息会导致南辕北辙的复盘结论。
2. **全面完整**——横向覆盖所有相关方面（全面），纵向从头到尾不掐头去尾（完整）。
3. **细节丰富**——魔鬼藏在细节中，细节让叙述真实可信，也让复盘更有切入点。

方法：用文字记录，而非口头叙述。动手即动脑，写的过程本身就是梳理逻辑、训练思维的过程，也能帮助发现记忆中的遗漏。

### 第三步：评估结果

将实际结果与目标对比，找出差异。比对有五种情况：

| 情况 | 说明 |
|------|------|
| 结果 = 目标 | 达成目标 |
| 结果 > 目标 | 超额完成 |
| 结果 < 目标 | 未达目标 |
| 结果中有新增项 | 执行中临时增加，原目标为 0 |
| 目标中有消失项 | 原计划项目未执行，结果为 0 |

评估结果的目的不是发现差距本身，而是为"分析原因"提供切入点——在与目标不符的地方，问出第一个"为什么"。

除了与目标比对，还可与行业平均水准或标杆对比，验证目标本身是否合理，发现更深层的差距。

### 第四步：分析原因

这是复盘的核心步骤，分析质量决定复盘价值。

**两个入手处：**

1. **从"与预期不一致"的地方入手**：结果好于预期、差于预期、结果为零——都是问"为什么"的起点。

2. **从"事情的关键点"入手**：任何事情都有决定成败的关键因素，如电影的票房由电影质量、宣传推广和渠道排片决定。抓住这几个关键点分析，等于抓住了成败的根本。

**追问方法——丰田 5Why 分析法：**

对问题连续追问"为什么"，通常 5 次左右可以穿透表象找到根本原因。例如机器停转：保险丝断→超负荷→轴承润滑不足→润滑泵吸不上油→轮轴磨损→**没有安装过滤器，混入杂质**。解决方案是安装过滤器，而非更换保险丝。

追问时需从三个层面递进：信息层面（what）→逻辑层面（why）→假设层面（前提是否成立）。

**还需反思"发心"：**

很多失败的根本原因不是方法错了，而是方向错了。TCL 并购汤姆逊差点破产，根本原因是并购动机来自"成为世界彩电第一"，而非"满足消费者需要"——发心偏离了企业本质。

**同时反思自身：**

除了分析事情本身的规律，还需反思行为主体——自己。
- **做事的态度**：是积极主动还是消极被动？是"想要"还是等别人推动？
- **做事的方式**：是埋头闷干还是抬头看路？是闭门造车还是广泛听取意见？

### 第五步：推演规律

分析原因后得到的结论，还需经过推演才能确保可靠。轻易或迅速总结出来的规律很可能是假的。推演的四个验证标准：

**标准一：能经受逻辑检验**

复盘结论不能建立在偶发性因素上，必须经过逻辑推导，而非自以为是。最常见的错误是**将相关关系当作因果关系**：

- 相关关系：A 之后出现 B（在此之后的关系）
- 因果关系：出现 A 必然有 B（因此之故的关系）

斯金纳的鸽子实验：鸽子在某个姿势时恰好得到食物，就以为那个姿势"有效"，反复摆出这个姿势——这是相关关系被误认为因果关系的典型。"小鲜肉 = 高收视"也属此类，因为"小鲜肉自带流量"才是有逻辑支撑的因果链条，但它并非必然的充分条件。

**标准二：经过交叉验证**

用其他案例验证复盘结论，类似法庭上"孤证不算数"。要有证据链——不只找能印证结论的案例，更要**刻意寻找反例**。找到反例就追问"为什么不一样"，再进一轮探索，认知就此提升。

**标准三：可用来指导实践**

复盘结论必须指向行动，才能指导后续实践。若结论归因于不可控、不可预测的外部因素（如"司机水平太差导致迟到"），则对自身成长毫无意义。

可用**可控性指标**筛选：
- **可控**：时间和质量都可自己掌握——重点复盘。
- **半可控**：部分由自己决定——关注可控部分。
- **不可控**：完全由外部决定——复盘结论若只落在这里，就需反思归因方向。

**标准四：指向抽象共性而非具体个案**

复盘应从一个具体案例中提炼出能适用于某一类问题的方法和规律。只针对某个特定案例的结论，等个案结束结论就失效，价值有限。

例：同为企业家背书的水果——褚橙稳定畅销，柳桃和潘苹果逐渐没落。原因不在于"企业家代言"本身，而在于褚橙承载了褚时健 70 岁再创业、10 年磨砺的真实故事，品牌人格与产品深度融合；而柳桃、潘苹果只是冠以企业家之名，并无故事支撑。抽象共性的结论是：**个人品牌要发挥产品背书作用，需要与产品有真实的情感或价值关联**，而非仅仅是名字。

**推演还需延伸到"运用结论的后果"：**

得到结论不是终点，还要推演在实践中运用该结论会产生的连锁反应。如制作方得出"小鲜肉 = 高收视"后，还应推演：粉丝群体能持续买单吗？非粉丝观众会反感吗？高片酬会压缩制作预算吗？"小鲜肉"档期能保证吗？推演这些后果，才能在实践中做出有效决策。

### 第六步：形成文档

将复盘中得到的认识和结论以文本形式固化下来，是整个复盘流程的最后一步。

形成文档的价值：
1. **留下准确记录**：记忆会随时间衰减和被修饰，文档可对抗遗忘，随时还原真实情境。
2. **知识化显性化**：散在脑中的认识没有保存价值，写成文档才成为可查阅、可传播的知识，节省后续认知资源。
3. **提供对比学习**：翻阅历史文档可以学习，将现在的事情与过去文档比对，用当下认知重新审视过去，有可能得出新的认识。

联想集团在十多年间累积了 240 多个复盘文档，成为重要的组织知识库，也是培训员工的核心材料。

## 复盘的三种类型

### 自我复盘

最简单、最具操作性的复盘方式，不受时间地点限制，可随时进行——一闪念、一回想、一反思，都是复盘。

曾国藩是自我复盘的典型案例。丁忧在家的一年多里，他反复回想过去几年在官场屡屡碰壁的原因，最终认识到：用儒家直接、法家强权的方式硬碰硬，虽表面胜利，实则埋下更大隐患。悟到"柔弱胜刚强"的道理后，复出后行事风格大变——遍拜长沙官场，以谦恭礼让彻底收服人心，反而奠定了此后事功的基础。

**自我复盘的技巧**：当出现与原来预期不一致的情况时，就进行事后复盘。

### 复盘他人

从他人做过的事情中获得经验教训，是一种高性价比的成长方式——别人付出了成本做"演练"，自己只需复盘。

两种形式：
1. **纯粹复盘他人**：看他人某件事做得好或差，自己复盘找出原因和规律，以便借鉴。类似围棋中的"打谱"。
2. **对比复盘**：自己与对手做了同类事情，对比双方的思维方式、着力点和最终效果，找到行业关键成功要素，获得"直觉和本能"。

**复盘标杆**是最有效的形式。联想通过复盘标杆（外国计算机厂商的定价策略）发现了摩尔定律的市场效应，率先打出价格战，一举占领中国个人电脑市场第一。

注意：标杆可以是正面的（学习优秀做法），也可以是负面的（研究典型失败案例，如《大败局》）。

### 团队复盘

多人共同对某件事进行复盘，需要协调场地、时间等，成本较高，因此应选在项目结束后、关键节点，或出现重大疑问时进行。

柳传志的核心观点：**团队复盘的主要受益者是团队领导人**。领导的工作是分配任务、调动积极性、管好全局，团队复盘正是帮助领导了解自己的工作方式和团队特性的机会。

团队复盘需要健康的复盘文化，否则容易变成：
- 秋后算账大会（指责追责）
- 强调客观、推卸责任大会
- 寻找替罪羊批斗大会

真正有效的团队复盘应是：**探寻真相求知求真的大会，观点和思路交锋的大会，验证逻辑的大会**。每个参与者都是安全的，复盘的目的是得出规律性认识，以便今后更好地工作。

三种角色分工：
- **主持人**：保证复盘顺利推进，避免偏离方向。
- **设问人**：通过提问引导思考。
- **叙述人**：叙述事件情况，回答问题。

**联想建立团队复盘文化的做法**：
1. 领导者以身作则，带头复盘，给下级传承。
2. 管理者承上启下，先掌握工具方法，带领团队实践。
3. 普通员工在实际运用中养成习惯。

其中，领导者做好榜样和提出要求是关键——领导没有复盘习惯，员工也不会有。

## 柳传志环：PDF 方法论

了解复盘之后，可以将视野拓宽，形成完整的做事框架——**沙盘推演（Preview）→ 执行（Do）→ 复盘（FuPan）**，即 PDF 方法，又称**柳传志环**。

这相当于**让人三次做同一件事**：
- 沙盘推演：事前在头脑中模拟，形成预案，减少陌生感，保持全局感。
- 执行：实际经历，积累第一手经验。
- 复盘：事后重来，审视执行与预演的差距，发现新的路径和假设。

与管理学经典的 PDCA 戴明环相比，PDF 的本质差异在于：PDCA 是同一过程的不同阶段；PDF 是对同一件事进行三次推演，视角和目的不同，尤其是复盘环节能发现在执行阶段看不到的规律。

一件事只有经过复盘，才算真正完成；未经复盘，只完成了一半，付出的成本没有完全产生效益。

随着 PDF 方法的持续运用，沙盘推演水平不断提高，执行与预演越来越吻合，从蒙着打变成瞄准打，这就是能力真正成长的轨迹。

## 核心原则总结

复盘的本质是**系统性地向自己的过去学习**，是随时随地随事都可以使用的成长工具。掌握复盘，就意味着随时可以修正错误、提炼规律、校验方向。

几个关键提醒：

1. **复盘不是秋后算账**，目的是成长，不是惩罚。
2. **自欺是最大的敌人**，不自欺要求区分"我"和"我的表现"，像对待别人一样对待自己。
3. **有胜心会阻断学习**，复盘他人时放下评判，先接纳，再吸收。
4. **结论要经过推演验证**，警惕相关关系伪装成因果关系，坚持交叉验证和反例检验。
5. **形成文档是复盘的完成式**，不写下来，大多数复盘认识会随时间消散。
6. **自我复盘是一切复盘的基础**，没有个人复盘习惯，团队复盘也无从谈起。
