# 从优秀到卓越

## 研究背景与方法

本书的核心问题来自一个直接的挑战：大多数关于卓越公司的研究，研究的都是从一开始就卓越的公司。那些原本普通、后来实现跨越的公司，到底做对了什么？

柯林斯团队历时五年，从1965年至1995年出现在《财富》500强的公司中，筛选出11家满足以下条件的公司：在转折点前15年业绩平平（与市场持平或以下），转折后15年累积股票收益率至少是市场的**3倍**。最终入选的11家公司包括：金佰利-克拉克、吉列、联邦国民抵押协会、克罗格、纽柯钢铁、电器城、菲利普·莫里斯、皮特尼·鲍斯、富国银行、雅培、沃尔格林。

研究方法的关键在于**系统对比**：每家"实现跨越"的公司，都配有一家相同行业、相近起点却未能实现跨越的"直接对照公司"，以及几家短暂实现跨越但无法持续的"间接对照公司"。研究核心问题不是"这些成功公司有什么共同点"，而是"这些公司和对照公司有什么本质不同"。

研究发现了一系列**违反直觉**的结论：
- 外聘明星CEO对从优秀到卓越的跨越往往起反作用
- 薪酬结构与公司业绩没有系统性关联
- 技术不是启动跨越的原因，只是加速器
- 合并与收购不能促成跨越
- 实现跨越的公司并不刻意制造变革与激励

这些发现最终凝练为一个框架：**训练有素的人 → 训练有素的思想 → 训练有素的行动**，贯穿飞轮的持续转动。

## 核心框架二：先人后事

### 颠覆传统认知

传统管理理论认为：先确定方向和战略，再找合适的人去执行。研究发现，实现跨越的公司做的恰好相反——**先把合适的人放到车上，不合适的人请下车，然后再决定把车开向哪里**。

三条简单理由：
1. 世界在变化，方向会改变；但如果选对了人，换方向很容易。
2. 有合适的人，激励和管理问题自然消失——合适的人靠内在驱动力工作。
3. 再好的战略，人不对，也无济于事。

富国银行的迪克·库利从70年代开始，在没有具体职位的情况下就广招天才，"这就是你构建未来的方式"。银行业取消管制时，没有人能预见所有变化，但库利的团队有足够的判断力和灵活性去应对一切。对照公司美洲银行奉行"弱将强兵"模式，管理者都不敢在会议上发表意见，最后危机来临时不得不从富国银行挖人救场。

### "谁"重于"什么"

联邦国民抵押协会的大卫·麦克斯韦上任时公司每天亏损100万美元，但他的第一件事不是制定战略，而是约谈26名高管，明确告知：这份工作要求极高，如果不想全力以赴，现在离开没有问题。最终14人离开，随即被金融界最优秀的人填补。

**报酬的核心原则**：关键不在于如何支付，而在于给谁支付。合适的人不会为钱折腰，他们工作是因为无法想象自己还能做别的事。薪酬设计的目的，不是让不合适的人做出正确的行为，而是让合适的人愿意留在车上。研究发现实现跨越的公司和对照公司在薪酬结构上没有系统性差异，实现跨越的公司高管薪酬总额甚至略低于对照公司。

### 严格，不等于冷酷

**严格（rigorous）**与**冷酷无情（ruthless）**截然不同。严格意味着对所有层级一贯地执行高标准；冷酷无情意味着不分情况的大规模裁员。优秀的人才不必担心自己的地位，可以全力投入工作——这才是严格文化的核心价值。

## 核心框架三：直面残酷的现实

### 斯托克代尔悖论

越战战俘吉姆·斯托克代尔将军是最长期的美军战俘之一。被问到谁没能从战俘营活着回来时，他说："那些乐观主义者。"——那些相信"圣诞节前一定能获救"的人，当圣诞节来了又去，复活节来了又去，最终在绝望中死去。

斯托克代尔悖论：**永远不失去最终会获胜的信念，同时直面当下最残酷的现实。**

这不是乐观主义，也不是悲观主义，而是一种清醒的双重坚持。实现跨越的公司都具备这种特质：对长期成功充满信念，但对短期困难绝不回避。

### 事实胜于美梦

A&P曾是世界最大零售商，克罗格在50年代名不见经传。到1998年，克罗格股票累积收益是市场的10倍、A&P的8倍。

两家公司在60年代都看到了消费行为的变化，都知道传统杂货店模式已经落伍。区别在于：克罗格面对残酷事实，推翻了占公司收入100%的旧模式，对每一家门店进行彻底改革，历时30年完成系统转型。A&P则一再逃避：新模式试验成功后，把试验结果压在箱底；采取焦土降价策略，导致服务质量恶化，陷入恶性循环。

### 构建让真相被听见的环境

让事实能够浮出水面需要四个机制：

1. **多提问，少要求答案**。电器城的艾伦·沃兹尔在公司几乎破产时，面对董事们追问"你有什么高招"，坦然说"我不知道"，然后用不断提问的方式引导团队自己找到答案。纳科尔的肯·艾弗森让高管们自由争吵，"争吵就是我们的战略制定过程"。
2. **对话与争论，但不强制**。在鼓励激烈争论的同时，不把问题当成操控手段，只为弄清真相。
3. **做彻底事后复盘，不互相指责**。菲利普·莫里斯收购七喜失败后进行了系统复盘，并将经验制度化，有效防止了同类错误。
4. **建立危机预警机制**。丘吉尔在二战期间专门设立"统计局"，绕过正式渠道直接获取未经修饰的真实战报，因为他知道自己的强硬个性会让人对他隐瞒坏消息。

个人魅力强的领导者尤其危险：当人们更担心领导会怎么看，而不是担心外部现实时，公司就开始走向衰败。

## 核心框架四：刺猬理念

### 刺猬与狐狸

衣赛亚·伯林的比喻：狐狸知道很多事情，刺猬只知道一件大事。但这件大事是一个统摄一切的核心原则，使刺猬在与狡猾的狐狸的对抗中屡战屡胜。

实现跨越的公司本质上都是刺猬：把复杂世界简化为一个深刻的核心理念，所有战略、行动、资源配置都以此为参照系。对照公司往往是狐狸：同时追逐多个目标，战略分散，从未凝练成真正的核心。

### 三环模型

刺猬理念来自三个核心问题的交叉点：

**第一环：你能在什么方面成为世界上最优秀的？**
注意：不是你现在从事的，不是你擅长的，而是你有潜能真正做到最好的。这比"核心竞争力"更严苛。仅仅因为你做了某件事很多年，不代表你能在这件事上成为世界第一。

雅培公司在1964年意识到，以自己的规模，成为最好的制药公司已不可能（默克已经建立了媲美哈佛的研究中心）。但他们有可能在"制造有成本效益的保健产品"方面做到最好——医疗营养品和诊断仪器。雅培放弃制药主业，转型成功。而对照公司普强始终幻想打败默克，结果在1995年被收购。

**第二环：是什么驱动你的经济引擎？**
找到那一个"每X所获利润"指标，对公司经济影响最大的。实现跨越的公司对自己的经济机制有深刻洞察，并据此分配资源。

**第三环：你对什么充满激情？**
不是说如何激励员工，而是发现让公司天然充满热情的事业领域。

沃尔格林的刺猬理念极其简单：**最好、最便利的药店 + 单位顾客光顾利润最大化**。他们系统地把所有不便利的店址换到拐角，率先发明顾客开车进店买药，在旧金山1英里内聚集9个药店，每一项资本投入都指向这个理念。而爱克德公司是狐狸：哪里有增长机会就收购哪里，甚至买了美国家庭电视集团进入录像带市场，最终亏损3100万美元并以贱价卖出。

### 刺猬理念的关键特征

- 它是一种**理解**，不是目标、意图或策略
- 它需要时间发酵，平均需要四年才能形成清晰的刺猬理念
- 一旦形成，它就成为"符咒"——决策时的终极参照

## 核心框架五：训练有素的文化

### 官僚制度的替代品

大多数公司建立官僚制度来弥补员工能力和纪律的欠缺。但官僚制度会排挤优秀员工，导致优秀员工比例下降，又需要更多官僚制度，形成螺旋式衰退。

解法：用**训练有素的文化**取代官僚制度。

雅培公司1968年引入"责任财务"制度：每一种产品的成本、收益和投资都明确落实到负责人，每个经理对自己的投资回报负责，严格程度如同投资者要求创业者。但这套纪律不是压制创新，而是在纪律框架内给予充分的企业家自由——"有自由，但却是框架内的自由"。

### 训练有素的文化 = 训练有素的人 × 训练有素的思想 × 训练有素的行动

训练有素的文化有一个关键悖论：它要求在**刺猬理念**范围内的事情上**极其灵活、富于创造力**，但对于**刺猬理念之外**的诱惑则**绝对严格地说不**。

最典型的体现——**"停止做什么"清单**：实现跨越的公司不仅关注做什么，同样关注停止做什么、不做什么。纽柯钢铁的肯·艾弗森面对行业衰退，砍掉了所有与炼钢无关的业务，把资源高度集中；沃尔格林在互联网泡沫期间抵制住了开设纯互联网药店的诱惑，坚持在实体门店中整合互联网功能，与刺猬理念保持一致。

## 核心框架六：技术加速器

### 技术不是原因，是加速器

互联网泡沫时期，许多人相信技术将颠覆所有传统公司。研究发现恰好相反：**技术本身既不是从优秀到卓越跨越的原因，也不是主要驱动力；技术是已经处于转变中的卓越公司的加速器。**

对照公司往往将技术视为"跳过艰苦过程直接实现跨越"的捷径，结果往往是技术投入打水漂。如医药电商DrugStore.com，仅开盘当天股价翻三倍，但没有合适的人、没有刺猬理念，技术只是在一个空洞的框架上搭建了华丽的外壳。

沃尔格林在七八十年代就率先建立了全国连锁互联互通的Intercom网络，投资4亿美元（含1亿美元的卫星系统）。但这项技术投入完全服从于刺猬理念——"便利的药店，提高单位顾客光顾利润"。沃尔格林的首席信息官是注册药剂师出身，而不是技术专家，这不是巧合。

**三个问题框架**：
1. 这项技术是否符合我们的三环理念？
2. 如果是，我们要如何成为这个领域的先驱？
3. 如果不是，为什么要投资？

实现跨越的公司对技术呈现出的典型反应是：沉着、冷静，有选择地跟进，先理解技术与刺猬理念的关系，再决定是否以及如何使用。对照公司要么恐慌跟风（怕被淘汰），要么完全无视（闭目塞听）。

## 核心框架七：飞轮与厄运之轮

### 飞轮效应

想象一个直径30英尺、重5000磅的重型飞轮。启动时要使出全力，轮子才开始缓缓转动。坚持推，一圈、两圈、十圈，飞轮越转越快，最终进入自我加速的惯性状态。

这是实现跨越的过程的真实写照。**没有奇迹时刻，没有单一决定，没有宏大宣言**，只是在正确方向上，一个紧接一个的举措持续推进，积累到临界点后实现突破。

一个关键发现：当研究者问那些实现跨越公司的管理者，"你们是在什么时刻意识到自己实现了跨越"时，没有一个人能说出具体的时间节点。他们的感受是，"我们只是一直在做对的事情，然后有一天回头看，发现已经到了一个完全不同的地方。"这对外部观察者来说却可能看起来像是"突然的革命性突破"。

飞轮的每一圈都建立在之前的积累上：合适的人 → 直面现实 → 刺猬理念 → 训练有素的文化 → 技术加速器 → 飞轮持续加速。

### 厄运之轮

对照公司陷入"厄运之轮"的模式：

1. 没有积累，试图跳跃——直接寻求"杀手级举措"或重大变革
2. 发动轰轰烈烈的"变革运动"或"激励计划"
3. 短期内没有突破性结果，失去信心，放弃
4. 转向新的方向或外来救世主，又一轮循环

A&P在零售业的衰落历程是典型：不断推出新计划（"金钥匙"超市、焦土降价策略、各种主管更迭），却从不坚守任何一个方向足够长的时间来积累动力。管理层每次看到对手有好的想法就模仿，同时不断否定前任方案。大量被研究文章的记录显示，A&P在30年内的公告和计划多达数十次，而克罗格只是安静地推进同一件事。

### 收购与媒体的双重陷阱

飞轮效应揭示了两个常见误区：

**收购无法创造跨越**：两个平庸的公司合并，得到的只是一个更大的平庸公司。实现跨越的公司在飞轮已经转动起来之后进行收购，是为了加速已有动量，而不是试图通过收购启动动量。

**媒体关注会扭曲认知**：飞轮转动是一个无声的过程，但媒体需要戏剧化的"转折点"叙事。外部观察者倾向于将卓越公司的成功归因于某个明星CEO的到来、某次并购或某项宏大战略——而研究显示，这些都不是真正的原因。

## 从优秀到卓越，再到基业长青

《从优秀到卓越》和《基业长青》是两个互补但不同的研究：

- **《基业长青》**研究的是"如何从零开始建立一家能基业长青的公司"——研究对象是从创业期就卓越的公司
- **《从优秀到卓越》**研究的是"如何让一家普通公司实现跨越"

两者并不冲突，而是可以叠加：先用"从优秀到卓越"的原则实现跨越，再用"基业长青"的原则构建能够持续百年的核心意识形态。

一个关键联系：**第五级经理人**与《基业长青》中"造钟而非报时"的理念高度一致——卓越的领导者建立能够自我运转的系统，而不是依靠个人英雄主义的即兴发挥。

## 核心洞见汇总

| 主题 | 直觉想法 | 研究发现 |
|------|----------|----------|
| 领导力 | 需要外部明星CEO带来变革 | 第五级经理人大多从内部提升，低调、谦逊 |
| 战略 | 先确定方向，再找人执行 | 先找对人上车，再确定方向 |
| 激励 | 需要宏大愿景激励员工 | 合适的人内在驱动，关键是别让他们失望 |
| 技术 | 技术是变革的推动力 | 技术是加速器，不能替代刺猬理念 |
| 变革 | 需要重大变革宣言 | 飞轮效应，没有奇迹时刻 |
| 薪酬 | 薪酬结构决定业绩 | 关键是给谁付，不是如何付 |
| 收购 | 大规模收购能创造卓越 | 两个平庸公司合并还是平庸 |

**最根本的原则**：优秀是卓越的大敌。正因为公司已经足够好、日子过得去，才会缺乏驱动力去实现真正的卓越。卓越既不是环境的结果，也不是运气的结果，而是有意识的选择与纪律的结果。
