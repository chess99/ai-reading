# 基业长青

## 研究背景与方法

《基业长青》是柯林斯与波勒斯历时六年的比较研究成果，研究方法严谨而罕见：向700位企业执行长发问卷，选出18家"高瞻远瞩公司"（包括惠普、索尼、默克、沃尔玛、波音、3M、迪士尼、诺斯壮、嬌生、花旗银行等），再为每家公司匹配一家起步条件相似的"对照公司"（如德州仪器、建伍、辉瑞、艾美斯百货、麦道、诺顿、哥伦比亚电影），系统分析两组公司从创立到1990年代的完整历史——平均每家公司追踪超过90年。

核心问题：**为什么有些公司能跨越世代、产品生命周期和领导人更替，持续卓越数十年乃至百年？**

股票投资数据显示：假设1926年各投入1美元，到1990年，大盘是415美元，对照公司组是955美元，而高瞻远瞩公司组是6356美元——约是对照组的6倍、大盘的15倍。

## 一、造钟，而非报时

### 核心比喻

"报时"指提供答案——依赖伟大的产品构想或魅力型领导人。  
"造钟"指建立一个能超越任何领导人和产品生命周期、持续产出答案的组织。

**高瞻远瞩公司的创建者，多半是造钟的建筑师，而非报时者。他们最重要的创作是公司本身，而非任何产品。**

### 伟大构想的迷思

惠普（HP）、索尼、沃尔玛的创业故事说明，这些公司起步时根本没有"伟大构想"：

- 惠普最初卖保龄球犯规检测器和马桶冲水器，靠试错起家
- 索尼公司创立时，员工花了几周时间讨论"该做什么生意"，第一个产品是失败的电饭锅
- 沃尔顿只是接手了一家普通的加盟便利店

相比之下，对照公司（德州仪器、建伍、艾美斯百货）在起步时反而更有清晰的创业构想——但长期却落后了。

结论：高瞻远瞩公司在创业初期比对照公司成功的比例反而**更低**。最后长跑赢得胜利的是乌龟，不是兔子。

### 建筑师vs.领袖

分析显示对照公司同样有卓越的领导人——两者的真正差异在于导向：

- **对照公司领导人**：以个人英雄形象驱动（报时）——增你智的"司令"麦当诺、哥伦比亚的柯恩
- **高瞻远瞩公司领导人**：以组织建构为导向（造钟）——3M的麦克奈特（"轻声细语、谦虚"）、摩托罗拉的盖爾文（"他不是发明家，而是建筑师"）

### 兼容并蓄（阴阳哲学）

高瞻远瞩公司拒绝"非此即彼"，能同时持守看似矛盾的两极：

- 追求超越利润的目标，**又能**务实追求利润
- 固定的核心理念，**又能**积极推动变革
- 保守固守核心，**又能**勇于设定大胆目标
- 教派般紧密的文化，**又能**拥有营运层面的高度自主权

## 二、不只是为了赚钱——核心理念

### 核心理念的两个层次

**核心价值**：组织恒久不变的根本信念，不因财务压力或时代潮流改变。通常只有3-6个，绝不超过6个。

**核心目的**：超越赚钱之上，组织存在的根本原因。好像地平线上的星星，永远追寻却永远达不到；正因为永远无法完全实现，才能持续激励进步。

### 务实的理想主义

高瞻远瞩公司并非纯粹理想主义者，也非功利主义者，而是**两者兼具**：

- 默克："医药是为了治病，利润顺带而至。我们越牢记这点，赚的钱反而越多。"——同时坚持向第三世界免费提供河盲症药物，并在日本市场收获巨大回报
- 福特："让汽车平民化"——以每日5美元工资（行业均值2倍）+ 不断降价，当时被称为"业界最愚蠢的举动"，最终改变了美国社会

研究发现：18组中有17组高瞻远瞩公司比对照公司更受核心理念影响，而非纯利润导向。

### 没有"正确"的核心价值

高瞻远瞩公司的核心价值各不相同，甚至截然相反（默克救人vs.菲利普莫里斯卖香烟），但两者都是有强烈核心理念的高瞻远瞩公司。

**关键不在于价值内容，而在于是否真诚信奉，并协调一致地贯彻。**

### 核心理念与做法的区别

必须严格区分：

- **核心理念**（恒久不变）：惠普的"尊重每位员工的个别价值"
- **营运做法**（可随时改变）：每天上午十点供应水果甜甜圈

IBM在1990年代遭遇困境，部分原因是将"蓝色西装白衬衫""大型主机优先"等做法误认为核心理念，因而无法及时变革。核心价值中没有任何一条提到大型主机，但IBM却以守护核心理念之名拒绝改变。

## 三、保存核心／刺激进步

这是本书最重要的发现，也是高瞻远瞩公司能持久卓越的根本机制。

**保存核心**：以几乎宗教般的虔诚守护核心理念，不随潮流或短期利益而妥协  
**刺激进步**：在核心理念以外，永不满足现状，驱策公司不断向前，改变其他的一切

两种力量**相互强化**：核心理念提供稳定基础，让进步不失方向；持续进步则让核心理念在不断变化的世界中得以延续和发扬。

这不是"求取平衡"，而是两者都要做到最好——既是鲜明的"阴"，又是鲜明的"阳"。

## 四、膽大包天的目标（BHAG）

### 定义与特征

**Big Hairy Audacious Goal** 像攀登珠穆朗玛峰或登月任务：

- 清晰动人，毋需委员会反复字斟句酌
- 超出舒适圈，成功率约50-70%，但组织相信"我们一定办得到"
- 即使领导人更迭，目标本身也持续驱动组织前进
- 必须与核心理念相符——错误方向的大胆目标只会加速偏离

### 经典案例

| 公司 | BHAG | 背景 |
|------|------|------|
| 福特（1907年） | 让汽车变成大众化产品 | 30家汽车公司中排名第15，市占率仅15% |
| 索尼（1950年代） | 改变"日本制造=低质量"的世界印象 | 员工不到1000人，海外毫无知名度 |
| 波音（1952年） | 进入商用客机市场，引领噴射机时代 | 从未造过商用客机，80%订单来自军方 |
| 花旗前身（1890年代） | 成为有史以来最无远弗届的世界金融机构 | 只有1位出纳和几个行员的地区性小银行 |
| 菲利普莫里斯（1960年代） | 成为烟草业的通用汽车 | 当时行业第6名，市占不到10% |
| IBM（1924年） | 将公司改名为"国际商业机器公司" | 卖磅秤和打孔机的中型小公司 |

### 波音的造钟vs.麦道的报时

波音对七○七、七四七的决策：企业在财务上全押，"即使要耗尽整个公司的资源也在所不惜"。七四七研发期间几乎毁了波音，最终改变了全球航空业。  

麦道每次都等波音先走，DC-8比七○七晚了几年，DC-9比七二七晚了两年——从此再也追不上。

### 警示：抵达终点症候群

一旦达成BHAG，组织极易自满停滞。福特在T型车成功后就犯了这个错误，没有设定新BHAG，眼睁睁看着通用汽车以新的大胆目标反超。

建议：在达成目标之前就预先思考下一个BHAG。

## 五、教派般的文化

### 四个"教派特质"

高瞻远瞩公司比对照公司明显更强烈地展现：

1. **狂热信奉**：员工对核心理念的认同达到近乎宗教的程度
2. **强烈灌输**：通过新人训练、内部大学、同事社会化，让理念从入职第一天就渗透
3. **紧密契合**：要不完全融入，要不如病毒般被排斥，没有中间地帶
4. **菁英意识**：员工深以参与"与众不同的使命"为荣

### 三个典范案例

**IBM**：公司歌曲、墙上标语、严格的行为规范、主管培育中心（"直到置身忙碌教室前，你可能还以为这是所修道院"）——IBM的教派文化最强烈时，也是IBM最成功和最能适应变化的时期。

**迪士尼**：员工叫"演员"，顾客叫"宾客"，所有人必须参加"迪士尼传统"训练课程，学习特定语言体系；严格的仪容规定，甚至创立迪士尼大学——这套机制在华特过世后数十年仍运作良好。

**寶鹼**：只从基层招募年轻人，所有高管必须从基层升起；员工入股计划（1892年率先推行）、利润分享（1887年启动）让员工心理上完全认同公司；一页式备忘录、严格保密文化共同强化着"寶鹼人"的独特身份。

### 矛盾中的自由

**关键发现**：教派般的文化并不压制自主，反而释放了更大的自主空间。

诺斯壮员工手册只有一条规定：  
*"无论碰到任何情况，都请善用良好的判断力。除此之外，别无其他规定。"*

理由：当核心理念已经内化，员工自然会做出符合组织方向的判断，不需要细碎的规则束缚。高度理念控制与高度营运自主，完全可以并存。

## 六、多方尝试，汰弱择强

### 演化式进步

高瞻远瞩公司许多重大策略突破，并非来自精心规划，而是来自意外：

- **嬌生**：因一封顾客抱怨信意外发明婴儿爽身粉，成为核心事业线（占营收44%）；OK绷由员工为频繁割伤的妻子自制，后成最畅销产品
- **沃尔玛**：迎宾员制度源于一家分店经理自行对抗盗窃的临时尝试
- **美国运通**：从快捷货运 → 汇票 → 旅行支票（意外发明"浮存金"概念） → 旅游服务；总裁本人曾明令"绝不跨入旅游业"，但组织文化的惯性把他们带进去了

### 3M：突变机器

3M的六个演化机制形成完整系统：

| 机制 | 内容 |
|------|------|
| 十五%规则 | 技术人员可将15%工作时间用于自己选择的研究 |
| 新产品规定 | 年销售额须有30%来自过去五年的新产品 |
| 创世纪基金 | 资助未获本部门支持的创业性内部项目 |
| 双轨升迁 | 科学家不必转管理职也能获得高薪 |
| 卡尔顿协会 | 表彰技术上有原创贡献的"技术英雄" |
| 容忍失败 | "不妨试试看——而且要快一点试！" |

防水砂纸、思高牌透明胶带、利贴便条纸——都源于意外的实验。  

**核心洞察：利贴便条纸的发明或多或少是偶然，但营造能容许意外出现的环境绝非偶然。**

对照公司诺顿虽然起步更好，却因为高度集权、"只要产品是圆的上面有个洞就好"的保守文化，最终被3M远远甩开，沦为恶意收购的目标。

### 有目的的演化

与纯达尔文式演化的区别：高瞻远瞩公司的变异和选择都是有目的的——

**选择的双重标准**：  
1. 这行得通吗？（实用性）  
2. 是否符合核心理念？（方向性）

## 七、自家培育的领导人

### 惊人数据

在18家高瞻远瞩公司合计**1700年的历史**中，**只有4位执行长直接从外部引进**（占3.5%）。  
对照公司中，外部引进的执行长比例高达22.1%。

高瞻远瞩公司拔擢内部人才的可能性是对照公司的6倍。

### 为何内部升迁

内部培育管理人才是**保存核心的关键机制**：

- 经过多年浸淫，他们天然了解并认同核心理念
- 避免空降部队侵蚀核心文化
- 形成"领导力延续环路"：完善的培育制度 → 内部产生优秀领导人 → 核心价值得以延续 → 公司持续卓越

奇异的威尔许在公司工作了20年才当上执行长。接班规划始于他就任前7年，从96个候选人逐步筛选，最终入选者都是纯正的奇异自家人。

### 领导断层的悲剧

高露潔、增你智（Zenith）、梅维爾、道格拉斯飞机公司——都因接班计划失败而引发：

1. 领导断层，被迫从外部引进"救星"
2. 外部人才破坏核心价值（高露潔的皮爾斯把总部搬离创始地，对经销商采取强硬手段，得罪核心渠道）
3. 企业长期落后，甚至被收购

### 实践建议

即使是小公司，也应及早培育接班人：  
- 蓋爾文在摩托罗拉还很小时，就让儿子从16岁开始从基层学起，父子共同掌舵了三年后才完成交接  
- 惠普在只有500名员工时，就已推行严谨的主管培育和轮调计划  
- 如果必须引进外部执行长，关键是寻找**发自内心认同公司核心理念**的人，而非单纯的管理能力

## 八、永远不够好

### 持续改善的内在驱动力

高瞻远瞩公司的关键问题不是"我们目前表现如何"，而是：  
**"我们明天要怎么样才能做得比今天更好？"**

这不是临时性项目，而是**制度化的生活方式**。寶鹼早在1850年代就推行持续改善；麥瑞特临终前几天仍在与分店经理讨论销售数字。

### 建立"不安机制"

为了主动抵抗自满，高瞻远瞩公司刻意创造让组织持续感到"不够好"的内部机制：

| 公司 | 不安机制 |
|------|----------|
| 寶鹼 | 品牌之间内部竞争，各品牌像不同公司一样互相争夺资源 |
| 摩托罗拉 | 主动停产尚有销量的成熟产品，逼自己推出新品（董事长桌上摆着最后一台摩托罗拉汽车收音机以自警） |
| 奇异 | 员工小组直接向高管反馈问题，当场决策，不得拖延和逃避 |
| 沃尔玛 | "打败昨日"帐簿，每天追踪并与去年同日比较 |
| 诺斯壮 | 每小时销售业绩全员公开排名，随时可见自己相对位置 |
| 惠普 | "量入为出"政策（永不举长债），强制内部资金纪律，训练出超强的营运效率 |

### 兼顾短期与长期

高瞻远瞩公司不在短期绩效与长期投资之间做选择——**两者都要做到最好**：

- 持续投入更高比例的营收于研发、设施与人才培育
- 同时维持严苛的年度绩效标准

万豪vs.豪生酒店：两家公司同样的起跑线，豪生二代开始享受既有成就、削减投资、忽视服务质量，最终被万豪远远甩开。1979年豪生被收购时，帝国集团总结："他们忽视再投资的重要，拚命压榨人力，藉着不再投资而榨取利润。"

## 九、协调一致——高瞻远瞩的终极要素

### 什么是协调一致

将核心理念与追求进步的驱动力，融入组织的**每一个细节**：

- 目标与策略
- 薪资制度、升迁标准、奖惩机制
- 办公室设计、语言体系、仪式与庆典
- 人才招募与培训流程
- 日常行为习惯与故事传说

高瞻远瞩公司不单仰赖任何一个机制，而是让数百个大小细节协调一致，形成整体效应。

### 惠普案例："十支喇叭"

"在惠普工作就好像置身于音乐室中，十支喇叭前后左右相互呼应、彼此强化。"

惠普每一个细节都传达一致的信息：

- 量入为出政策 → 传达纪律，抑制过度扩张的冲动
- 开放式办公室（所有主管无私人有门办公室）→ 传达平等与开放沟通
- "鄰座同事症候群"策略 → 工程师解决自己想解决的问题，技术贡献优先于市场分析
- 严禁人事部门介入人事决策 → 强迫每位主管亲自承担培育部属的责任
- 即使不流行，坚拒"学习曲线/市占率"战略 → 只做技术上有贡献的产品

### 消除不一致

协调一致不只是增加新机制，更需要**主动清除与核心理念相悖的做法**：

- 如果你们说核心价值是团队合作，薪酬制度却奖励个人表现 → 必须改薪酬制度
- 如果你们说要鼓励试验，却惩罚无心之过 → 必须停止惩罚失败
- 如果策略让公司偏离了根本目的 → 必须修改策略

"高瞻远瞩公司唯一的金科玉律就是核心理念，其他的一切都可以改变或放弃。"

## 建立愿景的完整框架

### 愿景 = 核心理念 + 展望的未来

**核心理念**（恒久不变，保存核心）：
- 核心价值：3-6个真正信奉的根本信念
- 核心目的：存在的根本原因，永远追寻的星星

**展望的未来**（激励进步，刺激进步）：
- 愿景层次的BHAG：10-30年才能达成的大胆目标
- 生动的描绘：具体描绘达成目标后的景象，传达热情与感召力

### 釐清核心价值的方法

**时间测试**：如果外在情势改变，坚持这个价值会受到惩罚，你们还会坚持吗？若否，它不是核心价值。

**火星任务小组**：假设只有5-7个席位去另一个星球重建组织，你会选谁去？他们就是最能体现核心价值的人，让他们来参与釐清和阐述核心理念。

### 釐清核心目的的方法

**五个为什么**：不断追问"为什么这很重要"，直到找到根本意义。

例：一家砂石公司 → "我们制造砂石" → 为什么重要？→ "基础建设质量影响安全与生活" → **"藉着提升人造结构的质量而改善人类生活"**（花岗岩建材公司因此获得美国国家品质奖）

**"随机企业杀手"测试**：假设有人出价买下公司后要彻底关闭它，你们会卖吗？如果回答"不卖"，为什么？那个"为什么"就是你们的核心目的。

## 核心洞见总结

### 四个关键概念

1. **造钟，而非报时**  
   将建立卓越组织本身（而非产品、构想或个人）视为最重要的创作。执行长更换了，产品过时了，但时钟仍在走。

2. **兼容并蓄**  
   拒绝"非此即彼"，同时持守核心理念与大胆追求进步；理想主义与务实主义并存；短期绩效与长期投资并重。

3. **保存核心／刺激进步**  
   核心理念（价值+目的）恒久不变；核心以外的一切——策略、产品、结构、文化表现——必须随时代演化，甚至激进地改变。

4. **协调一致，始终如一**  
   通过数百个协调一致的细节与机制，将核心理念与进步驱动力融入组织每一个层面，让员工不可能接收到矛盾的信息。

### 对创业者与经理人的实践建议

- **不要等待"伟大构想"**：先建立组织，产品构想之后会浮现；公司才是你最重要的创作
- **不要期待成为魅力型领导**：成为建筑师，而不是英雄；打造能在你离开后仍持续运作的时钟
- **及早釐清核心理念**：不是因为有用，而是因为真诚信奉——要"发现"而非"设计"
- **区分核心与非核心**：核心不变，其余皆可改；勇敢更新非核心的一切，不要以"我们一向都这样做"为借口
- **创造有机的进步机制**：BHAG、多方尝试、"不安机制"——制度化而非依赖运气或个别领导人
- **悉心培育接班人**：组织的延续性比任何个别领导人更重要；从员工还是小公司时就开始

本书的研究以美国公司为样本，但核心原则已在全球多种文化中得到验证。高瞻远瞩公司之所以成为高瞻远瞩公司，并非因为他们的领导人更有天赋，或他们拥有更好的构想——而是因为他们选择了"造钟"而不仅仅是"报时"，并以极大的耐心和纪律，长期在组织内部实现了保存核心与刺激进步的完整协调。
