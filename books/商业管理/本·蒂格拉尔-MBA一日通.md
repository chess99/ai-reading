# MBA一日通

《MBA一日通》系统覆盖顶级商学院 MBA 课程的核心知识，全书分为四大板块：人员与管理、资金与经济、市场与战略、系统与流程，共 14 章。本书适合没有系统商业教育背景的职业人士，以及需要快速建立商业认知框架的管理者和创业者。

### 二、组织行为学

组织行为学研究个人与群体在组织中如何协同运作，核心问题是：如何激励人？如何设计组织结构？

**七大激励理论**

| 理论 | 核心要点 |
|------|---------|
| 马斯洛需求层次 | 生理→安全→社交→尊重→自我实现，满足低层次才会追求高层次 |
| 赫茨伯格双因素 | 保健因素（薪酬、工作环境）防止不满；激励因素（成就、认可）才能正向激励 |
| 麦格雷戈 X/Y 理论 | X：员工厌工需控制；Y：员工自主愿担责。管理者假设直接影响管理方式 |
| Z 理论 | 借鉴日本管理，强调参与式决策与宽泛职业路径 |
| 期望理论（Vroom） | 激励 = 努力→绩效的期望 × 绩效→奖励的期望 × 奖励的吸引力 |
| 公平理论（Adams） | 员工横向比较投入/回报比；感知不公平会引发消极行为 |
| 强化理论 | 正强化/负强化/惩罚/消退四种手段，奖励应在期望行为出现后立即给予 |

**实践启示**：薪酬需与贡献匹配、透明公开；提供可实现目标；允许弹性工作制；设立员工参与计划（工作扩大化、轮岗、开卷管理、授权）。

**组织结构五要素**

- **分工**：将工作拆分为具体任务
- **部门化**：按职能、产品、流程、客户或地域分组
- **管理层级**：层级越多，组织越"高"
- **管控幅度**：单一管理者直接管辖的人数
- **集权 vs. 分权**：集权利于控制，分权利于速度与创新

机械式组织（高专业化、窄幅管控、集权）适合稳定环境；有机式组织（低专业化、宽幅管控、分权）适合动态环境。

### 三、领导力与团队建设

**领导 vs. 管理**（德鲁克："管理是把事做对，领导是做对的事"）

管理者聚焦执行与维护；领导者聚焦愿景与变革。最佳组织培养"领导型管理者"贯穿各层级。

**四种领导风格**

- **独裁型**：适合低技能员工或危机情境；会压制创造力，损害信任
- **民主型**：适合高技能员工及复杂问题；易导致决策冗长
- **放任型**：适合高度自律的专业团队；管理者须保持实质性沟通
- **变革型 vs. 交易型**：变革型领导激发愿景与成长；交易型领导通过奖惩管控行为，两者可互补

**企业文化六特征**：关怀、挑战、风险管控、伦理、聚焦、信任。领导风格塑造文化，文化塑造组织命运。

**团队发展四阶段（塔克曼模型）**

1. **形成期**：礼貌客套，厘清目标与角色
2. **风暴期**：冲突暴露，需要领导者提供调解与沟通
3. **规范期**：建立团队规范，分配责任与风险
4. **执行期**：高效协作，成果涌现

有效团队的标志：自主决策、开放沟通、角色清晰、"教练型"领导而非自上而下的命令。

### 四、商业伦理与企业社会责任

安然（Enron）与世通（WorldCom）的崩塌说明：没有伦理，任何业务增长都是沙上建塔。

**创建伦理标准的实践**

- 制定书面伦理守则，覆盖内部行为（平等就业、反骚扰）与外部关系（股东、消费者、环境）
- 设置伦理投诉热线（可将欺诈损失降低 50%）
- 定期开展伦理培训，将伦理表现纳入绩效考核
- 设立首席伦理官（Chief Ethics Officer）

**企业社会责任（CSR）与"三重底线"**

传统底线只有财务绩效；三重底线增加了**社会影响**和**环境影响**。世界经济论坛研究表明，良好的企业公民身份在声誉管理、风险降低、人才吸引、资本获取、运营效率等八个维度均能带来可量化收益。

### 五、谈判

**谈判的本质**：通过非暴力方式让双方都感到赢得了某些东西——而非零和博弈。

**三种谈判风格**

- **强硬型**（positional/competitive）：坚持立场，威胁施压；关系代价高，适用于一次性交易
- **软化型**（relational/cooperative）：以关系为先，易让步；常感到被占便宜
- **原则型谈判**（Fisher & Ury，哈佛谈判项目）：推荐做法

**原则型谈判四原则**

1. **将人与问题分开**：攻击问题，而非对方人格
2. **关注利益而非立场**（橙子案例）：问"为什么要这个"而非仅听"要什么"
3. **创造多种选项**，探索互利方案
4. **坚持客观标准**：用市场价值、行业惯例等外部标准而非意志力决定结果

**谈判前准备清单**

- 确定己方 BATNA（最佳替代方案）：这是谈判的底线
- 研究对方成员性格与偏好
- 列出假设清单，在谈判中逐一澄清
- 收集支持己方立场的客观数据
- 预判对方真实利益（而非表面诉求）

常见对方战术及应对：最后期限压迫（评估真实性）、"好人坏人"组合（识别策略）、有限授权（要求决策者在场）。

## 第二部分：资金——经济、财务与会计

### 六、会计与财务

**三张核心财务报表**

- **资产负债表**：Assets = Liabilities + Owners' Equity，记录某时点的财务状况
- **利润表（损益表）**：收入 − 费用 = 净利润/净亏损，记录某期间的经营成果
- **现金流量表**：经营/投资/融资活动的现金变动，揭示真实流动性

**成本类型**（管理决策的基础词汇）

| 成本类型 | 说明 |
|---------|------|
| 固定成本 | 与产量无关，如租金、保险 |
| 变动成本 | 随产量变化，如原材料、销售提成 |
| 增量成本 | 特定决策引发的边际变化 |
| 机会成本 | 选择某方案放弃的最优替代收益 |
| 沉没成本 | 已发生不可回收的历史成本，决策中应忽略 |

**作业成本法（Activity-Based Costing，ABC）**：将成本追溯到具体活动，而非按部门笼统分摊，为外包决策、定价决策提供精准依据。

**现金 vs. 权责发生制**：小型零售企业常用现金制（收到即确认）；持有库存或赊账的企业须用权责发生制（发生即确认），这是 GAAP 标准。

---

### 七、宏观与微观经济学

**供需定律**：价格是供求力量均衡的结果。需求曲线向下倾斜（价格越高需求越少）；供给曲线向上倾斜（价格越高供给越多）。

**经济周期四阶段**：繁荣（Boom）→ 衰退（Recession）→ 萧条（Depression）→ 复苏（Recovery）。管理者需要根据所处周期调整招聘、库存和资本支出策略。

**宏观经济三大指标**

- **GDP**：衡量国家总产出；持续下滑两个季度即为技术性衰退
- **通胀率（CPI）**：货币购买力的变化；需区分需求拉动型通胀与成本推动型通胀
- **失业率**：完全就业下仍有摩擦性失业（约 4–5%）存在

**政策工具**：财政政策（政府支出与税收）由国会和总统操作；货币政策（利率与货币供应量）由央行（美联储）操作。两者组合使用影响经济周期。

**汇率风险**：国际业务需关注汇率波动对盈利的影响；多元化市场可分散单一国家政治或经济风险。

## 第三部分：市场与战略

### 八、营销、战略与竞争分析

**营销的本质**：不是广告费用，而是以客户为中心创造价值的哲学与系统。"现金是王，但营销是一切"（Vessenes）。

**营销组合 4P**：产品（Product）、定价（Price）、渠道（Placement）、推广（Promotion）。围绕 4P 建立价值链，从原料采购到售后服务形成完整闭环。

**市场细分**：将整体市场拆解为同质性更强的子群体。万豪（Marriott）的案例：费尔菲尔德针对家庭游客，庭院旅馆针对商旅中层，丽思卡尔顿针对顶级高管——同一品牌族下不同的定位、价格与体验。

**PEST 分析**（环境扫描）

- **政治（Political）**：法规、政策、许可门槛
- **经济（Economic）**：消费能力、利率、经济周期阶段
- **社会/人口（Sociological/Demographic）**：人口结构、文化态度、消费趋势
- **技术（Technological）**：数字化程度、基础设施、技术扩散速度

**波特五力模型**（Porter's Five Forces）——评估行业吸引力

1. **进入壁垒**：规模经济、品牌差异化、资本需求、独特成本优势、分销渠道控制、政府管制
2. **替代品威胁**：功能相近但形式不同的产品都是潜在替代
3. **供应商议价力**：供应商数量少、产品独特、切换成本高时，供应商强势
4. **买方议价力**：购买量大、产品同质化、切换成本低时，买方强势
5. **现有竞争者的竞争烈度**：以上四力共同决定竞争激烈程度

**SWOT 分析**：内部优势（Strengths）、内部劣势（Weaknesses）、外部机会（Opportunities）、外部威胁（Threats）。需定期更新，且应同步对竞争对手做 SWOT，寻找可攻击的薄弱点。

**竞争对手分析七步法**

1. 列出直接与间接竞争对手
2. 识别各竞争对手的战略
3. 判断竞争对手的目标与价值排序
4. 对每个竞争对手做 SWOT
5. 预估竞争对手的反应模式
6. 选择攻击目标与回避目标
7. 绘制定位图，可视化竞争格局

**战略与战术的区别**：战略是长期方向（如面向 30–65 岁女性的健身中心），战术是落地步骤（选址郊区、雇用女性教练、推出针对成熟女性的健康课程）。

### 九、广告与推广

**整合营销传播（IMC）**：确保广告、公关、销售促进、直销等所有触点传递一致的品牌信息。

**推广组合**

- **广告**：电视、广播、平面、直邮、户外、网络——覆盖范围广，但互动性弱
- **销售促进**：优惠券、返利、采样、抽奖、捆绑促销——短期刺激购买，但易削弱品牌溢价
- **人员销售**：适合高价值、高复杂度、B2B 场景；关键是"跟进"维护长期关系
- **公关与宣传**：正面报道比付费广告更具可信度；负面危机需快速响应
- **忠诚度计划**：吸引高价值客户重复购买；奖励须可及、限制须合理

**获客成本原则**：留住一个现有客户的成本平均只有获取一个新客户的 1/6。以"客户份额"而非"市场份额"为增长目标，是更高效的战略。

### 十、沟通与演讲

**演讲准备公式**：每 1 分钟演讲需 30–60 分钟准备。

**演讲前需厘清的参数**：主题与主旨、时长、议程顺序、是否录制、听众背景与期望、场地条件。

**四种演讲目的**：说服（Persuasion）、传授（Instruction）、激励（Inspiration）、娱乐（Entertainment）。在准备内容前先明确主要目的，再设计结构。

**演讲结构原则**：开场建立连接，中间分三个核心要点，结尾提炼行动呼吁。视觉辅助（PPT）应简洁，每张幻灯片不超过一个核心信息，演讲者是主角而非念稿机器。

## 第四部分：系统与流程

### 十一、项目管理

项目管理的本质是风险管理——识别、控制并最小化不确定性对交付的影响。

**项目生命周期**：定义范围 → 制定计划 → 执行 → 监控 → 收尾

**范围管理**：项目失败最常见原因是"范围蔓延"（Scope Creep）。每次变更需经过正式变更控制流程：评估可行性 → 判断对计划的影响 → 形成变更单 → 获得批准后方可执行。

**项目调度工具**

- **甘特图**：可视化任务时间线与并行关系，直观但不显示依赖关系
- **关键路径法（CPM）**：找出决定项目最短完成时间的任务链；关键路径上任意任务延误均导致整体延误
- **PERT**：CPM 的变体，对每项任务给出最乐观、最可能、最悲观三个时间估算

**预算编制**：内部人力成本（需用"负担劳动率"含薪资+福利+管理费用）、设备摊销成本、外部承包成本、材料成本依次叠加。

**项目估算三种方法**

- **分阶段估算**：逐阶段明确成本，适合不确定性高的项目
- **自上而下（摊分法）**：基于历史数据按比例分解，速度快但精度低
- **自下而上**：逐任务估算后汇总，精度最高但耗时最多

**收尾与复盘**：项目完成后的总结汇报往往被忽视，但"挣值分析"（Earned Value Analysis）能比较计划成本与实际成本，是管理经验积累的重要来源。

### 十二、管理信息系统（MIS）

MIS 的核心价值：让正确的信息在正确的时间到达正确的人，辅助高质量决策。

**三类管理支持系统**

| 类型 | 使用层次 | 功能 |
|------|---------|------|
| 事务处理系统（TPS） | 操作层 | 记录日常交易（订单、工资） |
| 决策支持系统（DSS） | 中层管理 | 分析结构化问题，提供情景模拟 |
| 高管信息系统（EIS） | 高层 | 战略仪表板，汇总关键指标 |

**信息安全**：黑客攻击、病毒、内部盗窃是 MIS 的主要威胁。防护措施：防火墙、访问控制、定期备份、员工安全培训。

**局域网（LAN）vs. 广域网（WAN）**：企业内部用 LAN；跨地域连接用 WAN；互联网是全球性 WAN。

---

### 十三、电子商务

**电子商务的三大价值**

1. 全天候触达客户，打破地理限制
2. 降低营销与交易成本
3. 实现精准的客户行为数据采集

**建立电子商务战略的关键步骤**：确定目标受众 → 分析竞争对手网站 → 定义网站功能（展示/交易/服务）→ 设计用户体验 → 建立域名与品牌一致性 → 规划 SEO 与付费引流 → 持续分析用户行为数据

**内网（Intranet）**：企业内部的私有互联网，用于知识管理、HR 自助服务、跨部门协作，是现代组织的"神经系统"。

### 十四、质量管理体系

**质量运动的历史脉络**

- **戴明（W. Edwards Deming）**：将统计过程控制引入日本制造业，奠定全面质量管理基础
- **朱兰（Joseph Juran）**："适用性"（fitness for use）是质量的本质；质量问题 80% 源于管理系统而非工人
- **ISO 9000**：国际标准化组织的质量体系认证，要求文件化流程和持续改进

**全面质量管理（TQM）的核心要素**

- 以客户满意为最终目标
- 全员参与，质量是每个人的责任
- 持续改进（PDCA 循环：计划 → 执行 → 检查 → 行动）
- 统计过程控制（SPC）——"不能测量的，就无法管理"

**控制图（Control Chart）**：设定上控制限（UCL）与下控制限（LCL），监控流程变异。点落在控制限外 = 特殊原因异常，需立即干预；点在限内但呈趋势 = 系统性问题，需流程改造。

**戴明 14 条管理原则（精选核心）**

1. 建立改善产品与服务的持续目的
2. 建立领导力，督导应帮人做好工作而非施压
3. 消除恐惧，让每个人都能有效工作
4. 打破部门壁垒，鼓励跨职能协作
5. 废除纯数字目标管理，代之以领导力
6. 建立全员持续学习与自我提升的文化

**服务业质量的"冰山原则"**：服务企业通常只能听到不满客户中不足 10% 的声音——剩余 90% 选择沉默离去。每一个投诉背后有超过 20 名不满意但未发声的客户；每一个未被解决的投诉，平均会被传播给 8 个以上的潜在客户。解决投诉并让客户满意，其重返率接近 100%。

## 综合要点

《MBA一日通》贯穿始终的核心逻辑：**人是战略的执行者，数字是战略的语言，客户是战略的终点**。

- 人力资源、激励理论、领导力、团队建设——决定组织能否将战略转化为行动
- 会计、财务、经济学——提供度量与决策的共同语言
- 营销、战略分析（PEST + 五力 + SWOT）——帮助组织找到可持续的竞争位置
- 项目管理、MIS、质量管理——确保战略在执行层面高效、可控地落地

任何规模的组织，只要将这四个维度融合贯通，便拥有了一套可自我校正、持续进化的经营系统。
