# 助推

## 核心命题：自由主义的温和专制主义

本书的核心论点是：人不是教科书里的"经济人"（有爱因斯坦的智商、计算机的记忆力、圣雄甘地的意志力），而是"社会人"——有限理性、有限意志力、有限自私。既然人们经常做出对自己不利的选择，那么选择设计者就有责任在**不强制、不剥夺自由**的前提下，通过巧妙设计决策环境来帮助人们做出更好的选择。这种方法叫作"自由主义的温和专制主义"（libertarian paternalism），其操作工具就是"助推"（nudge）。

**助推的定义**：在选择体系中不采用强制手段，而以一种可预期的方式改变人们的行为，同时让人可以轻易选择退出。将水果放在视线齐平的位置是助推，禁止垃圾食品则不是。

## 第二部分：选择体系设计原则

### NUDGES框架

书中提炼出好的选择体系的六项原则，首字母恰好拼出"NUDGES"：

1. **N（iNcentives，动机）**：设计时问"谁使用、谁选择、谁掏钱、谁受益"，确保激励相容。显著性非常重要——人们容易忽略机会成本（买车后忘了那笔钱可以用于其他地方），却容易注意到出租车计价器跳动。

2. **U（Understand mappings，理解权衡）**：帮助人们将抽象指标转化为可感知的含义。相机像素不直觉，但"可打印4英寸×6英寸照片"就清晰了；养老储蓄多少可以用退休后能住什么房子来呈现。RECAP（记录、评估和可选价格比较）原则：要求金融机构每年向客户寄送详细的费用清单和电子数据文件，便于第三方比价和自我评估。

3. **D（Default options，默认选项）**：最强大的助推工具。现状偏差使大多数人停留在默认选项。自动续订利用默认选项赚钱；自动加入养老金计划则利用默认选项造福员工。关键是要根据"大多数人若仔细考虑会做什么"来设计默认选项，而不是随机设置。

4. **G（Give feedback，提供反馈）**：帮助人们改进行为最好的方式是及时反馈。数码相机拍完后立即可见效果；小便池里刻苍蝇图案使飞溅量降低80%；会自动跑走的Clocky闹钟迫使人起床；芝加哥湖滨大道弯道前逐渐加密的白线给驾驶员制造加速幻觉从而减速。

5. **E（Expect error，预计错误）**：好的系统应对可预见的用户错误保持宽容。巴黎地铁卡正反均可插入；自动取款机要求先取卡再给现金（避免遗忘银行卡）；药品每日一片包装降低漏服率；避孕药28片包装（其中7片是安慰剂）维持习惯节律。

6. **S（Structure complex choices，简化复杂选项）**：面对大量选项时，人们使用"逐步淘汰策略"，设计者应帮助结构化。油漆店按色系排列两千余种颜色；Netflix用"协同过滤"帮助用户发现影片；处理大量养老金方案时提供"目标成熟基金"（按退休年份命名，随时间自动调整风险配置）。

## 第三部分：核心应用案例

### 储蓄助推："明天储蓄更多"

美国人储蓄率长期过低，根本原因是养老金固定缴款计划（401(k)）对社会人要求太高——需要自主计算、选择、持续执行。

**自动加入**：将默认选项从"不加入"改为"自动加入（可退出）"，新员工参保率从20%直接跳至90%，3年后达98%。

**"明天储蓄更多"（SMarT）方案**：基于五项心理认知设计——人们愿意"将来"改变而不是"今天"改变；损失厌恶使人不接受到手工资减少；货币错觉忽视通胀；惰性大。方案设计：员工承诺在每次涨薪时将缴存比例提高3%，直至达到上限。结果：参与者3年半后缴存比例从3.5%提升至13.6%，远超接受"立即提高5%"建议的员工（最终停留在9%）。

### 投资助推：避免幼稚多样化

**1/n原则的危害**：面对n种选择时，人们倾向于平均分配。面对"全股票基金+全债券基金"会选50:50；面对"全股票基金+股债各半基金"也会选50:50，但此时实际股票占比达75%。方案提供的股票基金越多，人们买入股票越多。

**本公司股票陷阱**：安然公司员工将超过60%退休金投在安然股票上，公司破产后血本无归。据估算，持有单只公司股票的1美元相当于多元化共同基金中不到0.5美元的价值。解决方案：默认投资多元化"目标成熟基金"，将本公司股票与其他投资一视同仁。

### 医疗助推：器官捐献

全美有超过9万人等待器官移植，每年约有6万人在等待中死去，但可供捐献的器官严重不足。

**明确同意 vs. 推定同意**：现行多数州采用"明确同意"（opt-in）——你必须主动登记才算捐献者。改为"推定同意"（opt-out）——默认所有人愿意捐献，不愿意者需主动登记退出。实验数据显示，opt-in情形下同意率42%，opt-out情形下同意率82%。德国（opt-in）同意率12%，奥地利（opt-out）同意率99%。切换规则可使一国器官捐献率提高约16%，每年可多拯救数千条生命，且完全尊重个人自由选择权。

### 环保助推：信息公开与激励机制

**《毒性物质释放清册》**：要求企业公开有毒化学品排放量，不强制任何改变，却因媒体和NGO形成的"黑名单"效应，显著降低了排放量。同理，《温室气体排放清册》可产生类似效果。

**总量管制与交易**：比命令控制效率更高，让污染者有降低排放的经济动机，而非强制规定具体技术手段。酸雨控制项目证明此法可行：20年节约200亿美元，避免近万人过早死亡。

**燃油经济性标签**：将抽象的MPG数字改为"每年预计燃油成本XX美元"，让消费者直观感知，推动购车时的节能选择。

**能源使用可视化**：当南加州家庭能看到实时能耗指示灯（红色=超标，绿色=正常）后，高峰期用电量下降40%。能耗不可见是过度消耗的主因之一。

## 第四部分：对抗批评

### 对"干涉自由"的回应

反对者认为助推是家长制干预。作者回应：
1. "不干预"本身也是一种选择——食堂必须有食物摆放方式，养老金必须有默认投资，没有中性的设计。
2. 助推不禁止任何选择，只是改变选择的呈现方式，退出成本极低。
3. 市场经常利用人们的弱点（延长保修期、诱惑利率、默认续订），助推只是让这种力量朝有利于人们的方向发挥。

### 对"恶意助推"的警惕

好的助推必须有章可循：透明、可验证、有退出选项，且目标是帮助选择者实现其自己的目标，而非操纵其为他人牟利。政府助推应公开可查、可问责。

## 核心洞见总结

| 偏差/障碍 | 助推工具 |
|-----------|----------|
| 惰性/现状偏差 | 设计有利的默认选项 |
| 过度自信/乐观 | 提前承诺装置 |
| 注意力有限 | 及时、简明的反馈 |
| 复杂选择无从下手 | 结构化简化、协同筛选 |
| 社会规范偏差 | 公开正确规范数据 |
| 损失厌恶 | 将收益框架为"避免损失" |
| 措辞/锚定影响 | 标准化信息格式（RECAP） |

助推的本质是：**承认人的局限，而不是惩罚人的局限**。好的选择体系像一位好建筑师——不能设计出完美的建筑，但可以让楼梯在人们需要的地方出现。
