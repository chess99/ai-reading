# 生理学

## 一、绪论：内环境与调节

**内环境（internal environment）**：细胞外液（血浆、组织液、淋巴液）构成机体内环境，约占体重 20%，细胞内液约占 40%。内环境的理化性质（渗透压、温度、pH、离子浓度）保持相对恒定即**稳态（homeostasis）**。

**三种调节方式：**
- **神经调节**：反射弧为基本单位，速度快、精确、短暂
- **体液调节**：激素等化学物质经血液运输，速度慢、弥散、持久
- **自身调节**：器官/组织不依赖神经和体液、对局部刺激的固有反应，调节幅度小

**控制系统：** 负反馈（维持稳态，如血压调节、体温调节）；正反馈（加速完成某一过程，如分娩宫缩、凝血级联）；前馈（预先适应，如条件反射提前分泌消化液）。

## 三、血液

### 血液组成与理化性质

- **血细胞比容（hematocrit）**：男性 40%~50%，女性 37%~48%
- **血浆渗透压**：约 290~310 mOsm/（kg·H₂O）= 晶体渗透压（280 mOsm，主要由 NaCl 决定）+ 胶体渗透压（1.3 mOsm，主要由白蛋白决定，调节水分在血管与组织间的分布）
- **血浆 pH**：7.35~7.45，由碳酸氢盐缓冲系统（HCO₃⁻/H₂CO₃ = 20:1）维持

### 血细胞

**红细胞：** 正常成年男性 (4.5~5.5)×10¹² /L，女性 (3.8~4.6)×10¹² /L，血红蛋白男性 120~160 g/L，女性 110~150 g/L。促红细胞生成素（EPO，主要由肾脏产生）调节其生成；寿命约 120 天，在脾脏破坏。

**白细胞：** 正常 (4~10)×10⁹ /L，中性粒细胞占 50%~70%（吞噬细菌），嗜酸性粒细胞增高提示过敏/寄生虫感染，淋巴细胞参与特异性免疫。

**血小板：** (100~300)×10⁹ /L，参与初期止血（黏附→激活→聚集形成血小板栓子）。

### 生理性止血与凝血

**凝血过程：**
- **外源性途径**：组织损伤释放组织因子（TF/FⅢ）→ 与 FⅦa 结合 → 激活 FX
- **内源性途径**：FⅫ 接触损伤面激活 → 级联激活 FⅪ → FⅨ → FⅧ → 激活 FX
- **共同途径**：FXa + FVa（凝血酶原酶复合物）→ 凝血酶（FⅡa）→ 纤维蛋白原 → 纤维蛋白网；Ca²⁺（FⅣ）参与多个步骤

**抗凝机制：** 抗凝血酶（AT-Ⅲ，被肝素激活1000倍，灭活凝血酶和 FXa）；凝血酶调节蛋白（TM）-蛋白质 C 系统（灭活 FⅤa/FⅧa）；TFPI（灭活 TF-FⅦa 复合物）。

**纤维蛋白溶解（纤溶）：** t-PA/u-PA 激活纤溶酶原 → 纤溶酶降解纤维蛋白 → 维持血管通畅。

### 血型与输血

**ABO 血型：** A 型（红细胞有 A 抗原，血清含抗-B）；B 型（有 B 抗原，含抗-A）；AB 型（有 A、B 抗原，无抗体）；O 型（无 A、B 抗原，含抗-A 和抗-B）。天然抗体为 IgM，不能通过胎盘。

**Rh 血型：** Rh 阴性者初次输入 Rh 阳性血不发生溶血，再次输注则因免疫性 IgG 抗体（可通过胎盘）导致严重溶血或胎儿溶血病。

## 四、血液循环

### 心脏电活动

**工作心肌（快反应细胞）：** 静息电位 -90 mV；0 期 Na⁺内流（400 mV/s）；2 期（平台期）L 型 Ca²⁺内流与 K⁺外流平衡，维持 200~300 ms，为心肌不应期长的关键；3 期 K⁺外流复极。

**窦房结（慢反应自律细胞）：** 无稳定静息电位，4 期自动去极化（If电流：Na⁺内流；ICa-T：T 型 Ca²⁺内流），自律性约 100 次/分（受迷走神经减慢至 60~100 次/分）。

**兴奋传导途径：** 窦房结（起搏点）→ 心房肌（0.4 m/s）→ 房室结（0.02 m/s，延搁 0.12~0.20 s，保证心房先于心室收缩）→ 房室束 → 浦肯野纤维（4 m/s）→ 心室肌（1 m/s）。

### 心脏的泵血功能

**心动周期（心率 75 次/分时约 0.8 s）：**
- 收缩期：等容收缩期（主动脉瓣未开，室内压急剧升高）→ 射血期（主动脉瓣开放）
- 舒张期：等容舒张期 → 充盈期（二尖瓣/三尖瓣开放，大部分血液靠负压被动充盈）

**关键参数：**
- 每搏量（SV）约 70 mL；心率（HR）约 75 次/分；心输出量（CO）= SV × HR ≈ 5 L/min
- 射血分数（EF）= SV/舒张末容积 ≈ 55%~65%（反映收缩功能）
- **Frank-Starling 定律**：在一定范围内，前负荷（心室充盈量）增大 → 心肌初长度增加 → 收缩力增强

### 血管功能与血压调节

**动脉血压：** 收缩压 90~139 mmHg，舒张压 60~89 mmHg；脉压 = 收缩压 - 舒张压（正常约 30~40 mmHg）。决定因素：SV（影响收缩压）、心率、外周阻力（影响舒张压）、大动脉弹性。

**微循环：** 毛细血管前括约肌决定开放数量（受局部代谢产物调控）；组织液生成 = 毛细血管流体静压 + 组织胶体渗透压 - 血浆胶体渗透压 - 组织静水压（Starling 定律）。

**神经体液调节：**
- 颈动脉窦和主动脉弓**压力感受器反射**（减压反射）：血压升高 → 迷走神经兴奋/交感抑制 → 心率减慢、血管扩张 → 血压降低（负反馈）
- **肾素-血管紧张素-醛固酮系统（RAAS）**：肾血流减少 → 肾素 → 血管紧张素 Ⅱ（强烈缩血管）→ 醛固酮（促肾小管留 Na⁺ 排 K⁺，升高血容量）
- **ADH（血管升压素）**：血浆渗透压升高或血容量下降 → 下丘脑释放 → 促远曲小管/集合管重吸收水

## 五、呼吸

### 肺通气力学

**呼吸驱动力：** 膈肌和肋间外肌收缩使胸腔扩大 → 肺内压降低 → 气体流入。

**顺应性（compliance）：** 肺顺应性 = ΔV/ΔP，肺表面活性物质（磷脂酰胆碱，由 Ⅱ 型肺泡上皮细胞分泌）降低表面张力、防止肺泡萎陷，新生儿呼吸窘迫综合征即因表面活性物质不足。

**肺容量：** 潮气量（TV）约 500 mL；补吸气量（IRV）约 1500 mL；补呼气量（ERV）约 1500 mL；残气量（RV）约 1200 mL；肺活量（VC）= TV+IRV+ERV ≈ 3500 mL；功能残气量（FRC）= ERV+RV ≈ 2700 mL（缓冲呼吸间 O₂/CO₂ 分压波动）。

**解剖死腔**约 150 mL（上呼吸道和主气道，不参与气体交换）；肺泡通气量 = (TV - 死腔量) × 呼吸频率 ≈ 4.2 L/min。

### 气体交换与运输

**Fick 扩散定律：** 扩散量 ∝ 扩散系数（与分子量负相关，与溶解度正相关）× 分压差 × 交换面积 / 扩散距离。CO₂ 扩散系数约为 O₂ 的 20 倍，尽管 CO₂ 分压差仅为 O₂ 的 1/10，两者扩散量相近。

**O₂ 运输：** 97% 与血红蛋白（Hb）结合为 HbO₂（氧合血红蛋白，每克 Hb 可结合 1.34 mL O₂），3% 溶于血浆。氧解离曲线呈 S 形；pH 降低、PCO₂ 升高、温度升高、2,3-DPG 升高 → 曲线右移（波尔效应，促进组织释 O₂）。

**CO₂ 运输：** 70% 以 HCO₃⁻形式（CO₂ + H₂O ⇌ H₂CO₃ ⇌ H⁺ + HCO₃⁻，碳酸酐酶催化）；23% 与血红蛋白结合为氨基甲酰血红蛋白；7% 溶于血浆。

**呼吸节律：** 延髓（背侧呼吸组 DRG 和腹侧呼吸组 VRG）产生基本节律；脑桥呼吸调整中枢（PRG）调整节律深度。外周化学感受器（颈动脉体、主动脉体：对 PO₂、PCO₂、pH 敏感）和中枢化学感受器（延髓腹外侧面：主要对脑脊液 H⁺浓度敏感，即 PCO₂ 变化最重要的感受部位）共同调节呼吸。

## 六、消化与吸收

### 胃肠运动

**食管蠕动：** 食管下括约肌（LES）防止胃食管反流，迷走神经 VIP/NO 引起舒张。

**胃运动：** 容受性舒张（迷走神经介导，接纳食物）、蠕动（3次/分，推进食糜）、紧张性收缩（维持胃内压）；幽门括约肌控制食糜进入十二指肠。

**小肠运动：** 分节运动（环形肌有节律收缩，混合食糜、与消化液充分接触）、蠕动（推进食糜）；消化间期出现 MMC（移行性复合运动，清除残留食物）。

### 消化液分泌

**唾液：** pH 6.6~7.1，含唾液淀粉酶（分解淀粉为麦芽糖）、溶菌酶。

**胃液：** pH 0.9~1.5，1.5~2.5 L/d；主要成分：
- **盐酸（HCl）**：壁细胞质子泵（H⁺-K⁺-ATPase）分泌；激活胃蛋白酶原、杀菌、促进 Fe²⁺ 和 Ca²⁺吸收；基础分泌 0~5 mmol/h，最大分泌量 20~25 mmol/h
- **胃蛋白酶原**：主细胞分泌，HCl 激活为胃蛋白酶（pH<2 最适），水解蛋白质
- **内因子**：壁细胞分泌，与维生素 B₁₂ 结合，促其在回肠末端吸收

**胰液：** pH 7.8~8.4，1~2 L/d；碳酸氢盐（中和胃酸）+ 蛋白酶（胰蛋白酶、糜蛋白酶，以无活性酶原形式分泌，肠激酶激活）+ 脂肪酶 + 淀粉酶。

**胆汁：** 0.8~1 L/d，含胆盐（乳化脂肪、形成微胶粒促进吸收）；肝细胞持续分泌，胆囊浓缩储存。

**胃肠激素：** 促胃液素（G 细胞，促胃酸和胃蛋白酶分泌）；促胰液素（S 细胞，HCl 刺激，促胰液 HCO₃⁻分泌）；缩胆囊素（CCK，I 细胞，脂肪/蛋白触发，促胰酶和胆囊收缩）。

### 吸收

小肠是主要吸收部位（绒毛和微绒毛使面积达 200 m²）。
- **糖**：消化为单糖（葡萄糖、半乳糖由 Na⁺-葡萄糖共转运体 SGLT1 主动吸收，果糖由 GLUT5 易化扩散）
- **蛋白质**：消化为氨基酸和小肽，多种转运体吸收
- **脂肪**：胆盐乳化 → 脂肪酶水解 → 甘油一酯 + 脂肪酸形成微胶粒 → 被动扩散入肠上皮 → 再合成甘油三酯 → 乳糜微粒 → 淋巴管
- **维生素 B₁₂**：回肠末端；脂溶性维生素（A、D、E、K）随脂肪吸收

## 七、泌尿

### 尿液生成三过程

**肾小球滤过：** 每天约 180 L 原尿；肾小球滤过率（GFR）≈ 125 mL/min；滤过膜由毛细血管内皮、基底膜、足细胞裂孔膜组成（屏障：机械屏障 + 电荷屏障，阻止蛋白质滤过）。影响因素：有效滤过压 = 毛细血管流体静压 - 血浆胶体渗透压 - 囊内压（45 - 25 - 10 = 10 mmHg）；系膜细胞收缩调节滤过面积。

**肾小管重吸收（99%以上）：**

| 部位 | 主要重吸收 |
|------|-----------|
| 近端小管 | 葡萄糖/氨基酸（100%）、Na⁺（65%）、水（65%）、HCO₃⁻（85%）；等渗重吸收 |
| 髓袢降支细段 | 水（通透，不吸 Na⁺）|
| 髓袢升支粗段 | Na⁺-K⁺-2Cl⁻ 协同转运（呋塞米作用靶点），对水不通透 |
| 远曲小管/集合管 | 受醛固酮（促 Na⁺ 重吸收 / K⁺分泌）和 ADH（促水重吸收）调控 |

**肾小管分泌：** H⁺（酸碱平衡）、K⁺（高 K⁺时增多）、NH₃/NH₄⁺、肌酐、某些药物（青霉素、丙磺舒竞争）。

### 尿液浓缩与稀释

**逆流倍增机制：** 髓袢升支粗段主动转运 NaCl（对水不通透）→ 外髓组织间液高渗；尿素在内髓循环积累 → 内髓组织间液高渗梯度（皮质→乳头，300→1200 mOsm）。

**逆流交换（直小管）：** 维持髓质高渗梯度（防止因血流将溶质冲散）。

**ADH 的核心作用：** ADH 与集合管 V₂ 受体结合 → cAMP → AQP2 水通道插入管腔膜 → 水重吸收 ↑ → 高渗尿（可达 1200 mOsm）。ADH 缺乏/靶器官不敏感 → 尿崩症（每天尿量可达 20 L）。

### 肾的内分泌功能

分泌 EPO（促红细胞生成）；1α-羟化酶（活化维生素 D₃）；参与 RAAS（肾素分泌）。

## 八、神经系统

### 突触传递

**化学突触（主要类型）：** AP 到达突触前末梢 → Ca²⁺ 内流 → 囊泡与前膜融合 → 递质释放入突触间隙 → 与后膜受体结合 → 产生兴奋性突触后电位（EPSP）或抑制性突触后电位（IPSP）。

**主要递质与受体：**
- 乙酰胆碱（ACh）：N 受体（N₁ 骨骼肌、N₂ 自主神经节）、M 受体（心脏、腺体、平滑肌）
- 去甲肾上腺素（NE）：α 受体（缩血管）、β 受体（心率加快、支气管扩张）
- 多巴胺：参与运动协调（黑质-纹状体通路）、奖赏系统；多巴胺不足 → 帕金森病
- 5-羟色胺（血清素）：情绪、睡眠调控
- GABA：中枢最主要抑制性递质
- 谷氨酸：中枢最主要兴奋性递质；NMDA 受体参与突触可塑性（LTP）

### 脊髓与脑

**脊髓反射：** 牵张反射（肌梭感受肌肉被拉伸 → α 运动神经元激活 → 同一肌肉收缩，维持姿势）；腱反射（膝跳反射为单突触反射）；屈肌反射（保护性，痛觉刺激 → 同侧屈肌收缩 + 对侧伸肌加强）。

**脑干：** 基本生命中枢（呼吸、心血管调节在延髓）；脑干网状结构调控觉醒与睡眠。

**小脑：** 维持身体平衡、协调随意运动、调节肌张力；损伤 → 共济失调。

**基底核（基底神经节）：** 调控运动的幅度和精确性；黑质-纹状体多巴胺能通路受损 → 帕金森病（静止性震颤、肌强直、运动减少）。

**大脑皮层：** 初级运动皮层（4 区）的躯体定位倒置（头面部在下）；皮层运动功能区面积与精细运动能力正相关（手和面部最大）。

### 感觉系统

**视觉：** 视网膜视锥细胞（6~7×10⁶，分辨颜色和细节，集中于中央凹）；视杆细胞（1.2×10⁸，感受弱光，含视紫红质）。对光反射（瞳孔括约肌受副交感调节，用于评估脑干功能）。

**听觉：** 基底膜按频率不同部位振动（高频→底部，低频→顶部）；毛细胞纤毛偏转 → 离子通道开放 → 神经冲动；气传导（主要途径）> 骨传导（Weber/Rinne 试验用于鉴别传导性耳聋和感音性耳聋）。

## 九、内分泌

### 下丘脑-垂体轴

下丘脑释放/抑制激素经垂体门脉系统调控腺垂体，腺垂体激素调控外周靶腺，靶腺激素负反馈抑制下丘脑和腺垂体。

**生长激素（GH）：** 促蛋白质合成、脂肪分解、血糖升高；主要通过 IGF-1（胰岛素样生长因子-1，肝脏产生）发挥促生长作用。慢波睡眠时分泌最多；低血糖是最强促分泌刺激。GH 过多 → 巨人症（儿童）/ 肢端肥大症（成人）。

**催乳素（PRL）：** 促乳腺发育和泌乳；由多巴胺（PIF）持续抑制。哺乳时婴儿吸吮刺激 → 神经-体液反射 → 多巴胺减少 → PRL 升高。高 PRL 血症 → 抑制 GnRH → 闭经、不孕。

**促甲状腺激素（TSH）→ 甲状腺激素（T₃/T₄）：** 促进氧化磷酸化、提高基础代谢率（BMR）；促生长发育（婴儿缺乏 → 呆小症/克汀病）；提高心率和心输出量；碘是合成原料。

**促肾上腺皮质激素（ACTH）→ 皮质醇：** 皮质醇升高血糖（糖异生）、抗炎、免疫抑制；应激时大量分泌（HPA 轴激活）；昼夜节律（清晨最高）。

### 胰腺

**胰岛素（B/β 细胞）：** 降低血糖（促葡萄糖摄取/利用、糖原合成、脂肪/蛋白质合成）；分泌受血糖浓度直接调控（葡萄糖 → 关闭 K⁺通道 → 去极化 → Ca²⁺内流 → 胰岛素释放）。1 型糖尿病：自身免疫破坏 B 细胞；2 型：胰岛素抵抗。

**胰高血糖素（A/α 细胞）：** 升高血糖（糖原分解、糖异生、脂肪分解）；低血糖和氨基酸刺激分泌；与胰岛素拮抗，共同维持血糖稳态（正常空腹 3.9~6.1 mmol/L）。

### 甲状腺与甲状旁腺

**甲状腺激素：** 促进骨和神经发育（儿童期缺碘 → 智力低下）；BMR 升高；T₃ 活性约 T₄ 的 4 倍，T₄ 在外周脱碘转化为 T₃。

**甲状旁腺素（PTH）：** 促骨钙/磷释放、促肾小管重吸收 Ca²⁺、促维生素 D 活化 → 升高血钙；低血钙是最强促 PTH 分泌刺激。降钙素（甲状腺 C 细胞）与 PTH 拮抗，降低血钙。

### 肾上腺

**皮质（ACTH 调控）：** 束状带分泌糖皮质激素（皮质醇）；球状带分泌盐皮质激素（醛固酮，由 RAAS 调控）；网状带分泌雄激素。

**髓质（交感神经支配）：** 分泌肾上腺素（Epi，主要通过 β 受体作用）和去甲肾上腺素（NE，主要 α 受体），应激时大量释放，参与"战斗或逃跑"反应。

## 十、生殖

### 男性

**精子发生：** 精原细胞（2n）→ 初级精母细胞 → 减数第一分裂 → 次级精母细胞 → 减数第二分裂 → 精子细胞 → 精子（1n）；全程约 64 天，在睾丸曲精小管（35℃，低于体温）内完成。

**睾酮（Leydig 细胞）：** LH 调控；促精子发生（与 FSH 协同）、男性第二性征、蛋白合成。FSH 促曲精小管发育和 Sertoli 细胞（支持细胞）功能。

### 女性

**卵巢周期（28 天）：**
- **卵泡期（1~14 天）：** FSH 升高 → 卵泡发育成熟 → 雌激素↑ → 子宫内膜增殖
- **排卵（14 天）：** LH 峰（正反馈机制：雌激素在一定浓度时对下丘脑-垂体产生正反馈，触发 LH 峰）→ 卵泡破裂排卵
- **黄体期（15~28 天）：** 黄体分泌雌激素 + 孕激素（孕酮）→ 子宫内膜分泌转化；若未受孕，黄体退化 → 激素下降 → 月经来潮

**妊娠：** 人绒毛膜促性腺激素（hCG，由滋养层细胞分泌，妊娠早期诊断指标）维持黄体功能；胎盘后期接管分泌雌激素和孕激素；分娩时缩宫素（催产素）正反馈促进子宫收缩。

**乳汁分泌：** PRL 启动泌乳，缩宫素（吸吮反射触发）促使乳腺肌上皮收缩使乳汁射出（泌乳反射）；哺乳期高 PRL 抑制排卵（不可靠的避孕方式）。
