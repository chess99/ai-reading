# 预期投资

股价包含了投资者对企业未来经营表现的集体判断。预期投资先问：一家企业必须实现怎样的销售增长、利润率、投资效率，以及多长时间的超额收益，才能支持今天的价格？得到这组价格隐含的预期后，再研究哪些判断可能改变、改变幅度有多大、发生概率有多高，最后决定买入、卖出或持有。

企业经营得好，股东仍可能得到平庸的回报，因为价格可能已经包含了这些成绩。经营处境较差的企业也可能带来较好的投资结果，前提是实际前景比价格包含的预期更有利。企业管理者要通过投资赚取超过资本成本的回报；股票投资者要判断实际经营前景与价格隐含预期之间的差距。

这套方法使用现金流折现模型来反推预期，随后结合竞争分析、经营因果关系和概率判断。分析依然可能出错，市场修正价格的时间也不确定。作者明确承认持续战胜市场很困难；接受市场回报的投资者可以选择低成本指数基金，预期投资为主动选股提供的是一套有纪律的决策程序。

## 一、把预期变成可以检查的经营条件

### 三步决策程序

第一步是**估计价格隐含预期**。收集市场对销售增长、营业利润率、投资需求的共识，估计资本成本，计算这些条件要持续多少年才能得到当前股价。这一步先尽量还原市场的判断，暂缓加入自己的乐观或悲观看法。

第二步是**识别预期修正机会**。检查企业的历史表现、竞争位置与经营变化，找出对股东价值影响最大、又可能发生变化的因素。为它建立有依据的高低情境，研究销量、价格、成本和投资之间的连带影响。

第三步是**比较价格与概率加权价值**。把各情境的估值乘以发生概率，得到预期价值；再考虑安全边际、价格收敛所需时间、税负及替代投资。价格与预期价值之间的差距足够大，才构成采取行动的理由。

“隐含预期”是支持当前价格所必需的一组经营条件，未必等于某位分析师公开发表的预测。相同价格可以由不同的增长、利润率和持续时间组合支持，因此反推结果必须放回企业和行业中检验。

### 短期盈余与市盈率会遗漏什么

会计利润不扣除股东资本的机会成本，也不完整反映支持增长所需的营运资本和固定资本支出。会计方法的选择还会改变利润的确认时间。企业可以在新增投资回报低于资本成本时继续增加利润，股东价值却减少。

附录A给出一个简化例子：一家无债务、无新增投资需求的企业，每年赚取1200万美元，资本成本为8%，价值为1.5亿美元。它投资1500万美元，永久增加每年120万美元的现金流，新增回报率正好为8%。利润增长10%，但新增现金流的现值恰好抵消投资，企业价值仍为1.5亿美元。

如果它投资3000万美元，每年仅增加160万美元现金流，利润提高到1360万美元，增幅为13.3%；价值却变为：

`1360万美元 ÷ 8% − 3000万美元 = 1.4亿美元`

利润增长不足以弥补投入资本的成本。

市盈率也缺乏独立的估值能力。“每股利润×合理市盈率”仍要求分析者先知道什么价格合理。市盈率压缩了增长、利润率、投资需求、风险和竞争优势持续时间等假设，倍数本身不能解释这些条件。

市场会迅速回应季度业绩，因为季度数据可能改变长期现金流预期。投资者持股时间很短，也能对企业长期前景进行交易。判断市场的估值期限，应检查当前价格需要多少年的现金流支持，不能用交易周转率代替。

## 二、用现金流建立股东价值模型

### 销售、利润与再投资

对非金融企业，书中使用以下关系：

`营业利润 = 销售收入 × 营业利润率`

`税后净营业利润（NOPAT）= 营业利润 − 营业利润对应的现金税`

`自由现金流（FCF）= NOPAT − 固定资本增量投资 − 营运资本增量投资`

自由现金流是经营活动产生、可供债权人和股东分配的现金，因此计算时尚未扣除利息，折现率应同时反映债务与股权的资金成本。

**增量投资率**衡量每增加一元销售收入需要追加多少投资。固定资本增量投资率以“资本支出减折旧”除以销售增加额；营运资本增量投资率以营运资本增加额除以销售增加额。它们与投资额占总销售收入的比例有不同含义。

例如，销售收入原为1亿美元，次年增长10%，营业利润率15%，现金税率25%。次年NOPAT为1237.5万美元。固定资本增量投资率15%、营运资本增量投资率10%，意味着对新增的1000万美元销售额分别投入150万和100万美元，FCF约为987.5万美元。

营运资本主要包括应收账款与存货，减去应付账款、应计费用等不付息流动负债，排除超出经营需要的现金。销售已确认但货款未收，会占用现金；应付账款增加则可以推迟现金支付。亚马逊先收客户货款、后付款给供应商，增长曾成为营运资金的来源。

书中的固定资本处理保留了营业利润中的折旧，再扣除“资本支出减折旧”，与先加回折旧再扣除全部资本支出得到相同现金流。折旧接近维持现有产能的支出是一项需要检查的假设。收购无形资产的摊销、经营租赁内含利息等项目也要调整，以避免重复扣减或把融资成本混入经营成本。

现金税与利润表所得税可能有时间差异。计算NOPAT时，税负应对应营业利润，消除利息抵税及非经营收支的影响；不能直接照搬净利润的实际税负。

### 无形投资与金融企业

研发、品牌建设、获客和培训常被计入当期费用；厂房和设备则通常先资本化，再逐期折旧。两种处理会改变利润和账面资产，却不改变支付现金这一事实。分析者应区分维持当前业务的费用与为未来增长进行的投入，并判断这些投入的经济回报。

金融企业的负债常参与日常价值创造，直接把债务当作普通融资项目剥离不够直观。书中建议银行、保险和券商优先采用股权现金流模型，以股权资本成本折现股东可得现金。不同金融业务还需使用与自身经营方式相适应的模型，反推预期的程序仍然适用。

### 资本成本与权利归属

资本成本是投资者在同等风险下可获得的回报，代表使用资金的机会成本。企业自由现金流使用加权平均资本成本（WACC）：

`WACC = 债务市值权重 × 税后债务成本 + 股权市值权重 × 股权资本成本`

权重使用市场价值，因为今天的投资者承担的是当前市值对应的机会成本。税后债务成本通常按当前长期债务收益率乘以`（1−税率）`估计，但利息抵扣受到税法与企业纳税状况限制。

书中以资本资产定价模型估计股权成本：

`股权资本成本 = 无风险利率 + β ×（预期市场回报率 − 无风险利率）`

β表示股票回报对整体市场变化的敏感程度。市场风险溢价应尽量采用前瞻估计，不能假定历史平均值永远适用。作者承认CAPM受到持续质疑，准确使用这一特定风险模型并非预期投资法成立的先决条件。

得到经营价值后，还要分清股东的实际权利：

`企业经营价值 = 明确预测期内FCF的现值 + 持续价值的现值`

`普通股股东价值 = 企业经营价值 + 非经营资产价值 − 债务及其他优先索偿权价值`

非经营资产包括超额现金、有价证券、部分非合并投资等；它们产生的现金未包含在经营FCF中，因此需要加回，并考虑潜在税负。扣除项除债券外，还可能包括优先股和养老金资金缺口。债务和优先股应尽量按市场价值计算。

## 三、竞争优势持续多久，决定多少增长值得付钱

### 市场隐含预测期

市场隐含预测期又称价值增长期或竞争优势持续期，表示市场预期企业的**新增投资能够赚取超过资本成本回报的年数**。预测期结束后，企业可以继续存在和增长，只是模型假定新增投资的回报降至资本成本，额外增长不再增加经济价值。

反推时，先给定现金流和资本成本假设，逐年延长预测期，直到每股价值达到当前价格。如果需要12年，则当前假设对应的隐含预测期为12年。它衡量的是价格包含的价值创造期限，不能直接当作企业未来能够兑现的竞争优势期限。

竞争者进入、技术替代、客户议价和产品过时会削弱超额收益。人为固定五年或十年的估值期限，可能把真正包含在价格中的长期预期遗漏。书中研究显示，美国股票常见的隐含期限约为5至15年，企业之间可能有更大差异。

### 附录B：持续价值的四种处理

持续价值表示明确预测期结束后的现金流价值。设末年NOPAT为`N`、资本成本为`k`、通胀率为`i`，以下价值均位于预测期末，还需折现回今天：

| 方法 | 期末持续价值 | 所需经营假设 |
| --- | --- | --- |
| 永续法 | `N / k` | NOPAT名义金额保持不变，实际购买力下降 |
| 永续通胀法 | `N×(1+i)/(k−i)` | 企业能保持购买力，现金流随通胀增长 |
| 部分通胀法 | `N×(1+p×i)/(k−p×i)` | 企业只能转嫁通胀的一部分，`p`为可转嫁比例 |
| 永久衰退法 | `N×(1−d)/(k+d)` | 企业以衰退率`d`持续缩减 |

这些方法按书中相应假设表达。前三者假定竞争使新增投资回报降至资本成本；永续法使用NOPAT作为分子，是因为增长投资的现值被新增现金流的现值抵消，同时折旧近似维护产能所需支出。对无法持续经营的企业，清算价值可能更合适。

NOPAT为1美元、资本成本8%时，永续价值为12.50美元；能完全转嫁2%通胀时为17美元；只能转嫁一半时约14.43美元；每年衰退2%时为9.80美元。不同处理包含了截然不同的定价权和竞争判断。给持续价值分配得越高，支持同一股价所需的明确预测期就越短，二者必须一起检查。

## 四、沿经营因果关系寻找预期修正

### 三层分析：触发因素、价值因子、模型输入

预期修正可以按以下顺序分析：

`销售、经营成本或投资发生变化 → 经营机制改变 → 销售增长率、营业利润率、增量投资率改变 → 股东价值改变`

销售、经营成本和投资是三类**触发因素**。销售增长率、营业利润率、增量投资率是模型最后使用的**经营价值驱动因素**。连接二者的六个价值因子解释了经营变化如何进入估值：

| 价值因子 | 需要检查的机制 |
| --- | --- |
| 数量 | 出售多少产品或服务；市场增长、份额、客户流失怎样改变销量 |
| 价格与产品组合 | 相同商品价格变化，或高低利润产品占比变化；同时影响收入和利润率 |
| 经营杠杆 | 已投入的产前成本分摊到更多销量，利润率上升；新一轮投入可能中断这种改善 |
| 规模经济 | 规模使采购、生产、广告、配送等活动本身更有效率，降低单位成本 |
| 成本效率 | 在既定销售水平下改进活动，或重新配置、外包活动，降低经营成本 |
| 投资效率 | 用更少固定资本或营运资本，获得同样的收入和营业利润 |

经营杠杆来自产前成本的分摊，规模经济来自执行活动的效率改善，不能混为一谈。假设产前成本固定为1700万美元、其他成本占收入68%，销售收入连续增长10%，利润率可以由15%升至16.55%、再升至17.95%。如果产能耗尽、必须再次投入固定成本，利润率就未必继续上升。

销售下降也可能伴随利润增加。固特异轮胎在书中所述时期减少低利润产品，转向高利润轮胎，销售额下降而营业利润增加。单看收入增长无法理解产品组合的效果。

### 增长的价值取决于增量回报

销售变化通常值得先研究，因为它可能同时改变数量、价格与组合、经营杠杆、规模经济，修正幅度也往往大于单纯节约成本或资本。但增长只有在新增投资回报超过资本成本时才增加价值。

书中称刚好维持股东价值所需的营业利润率为**门槛营业利润率**。它取决于新增投资需求、税率、资本成本及相关估值假设。

- 预期利润率明显高于门槛时，增长上调通常增加较多价值。
- 利润率接近门槛时，单纯增长的价值有限；增长若同时提高利润率，结论可能变化。
- 利润率低于门槛时，增长可能扩大价值损失，除非成本或投资效率足以改善回报。
- 每一元新增销售所需投资越多，达到经济盈亏平衡所需的利润率越高。

因此，分析者应先解释经营变化及其连锁反应，再修改模型。随意把利润率上下调几个百分点的敏感性表，无法说明企业为什么可能实现这些结果。

## 五、用竞争分析约束估值假设

### 先了解行业，再比较企业

历史分析可以辨认哪些经营变量波动最大、在什么条件下发生变化，以及管理层过去如何执行策略。稳定行业的历史更有参考价值；技术和商业模式迅速变化时，过往平均数的可靠性下降。

书中建议先画**产业地图**：把企业、供应商、客户、潜在进入者及其他影响利润的参与者放在同一张图中，检查交易关系、相对规模和外部风险。再做**价值池分析**，用横轴表示企业规模，纵轴表示营业利润率与门槛利润率之差，观察价值由谁创造、集中在哪里、历年怎样转移。

比较相隔三至五年的市场份额，并计算平均绝对变化，可以粗略判断行业稳定程度。份额频繁大幅变动，说明维持竞争地位较难；稳定份额与持续超额回报一起出现，才更能支持较长的竞争优势判断。

五力分析检查替代品、买方议价、供应商议价、进入障碍和现有竞争。它对边界清楚、相对成熟、依赖有形资产的行业尤其直接。分析进入威胁时，还应问：

- 最低有效规模需要多少资本与份额，新进入者能否达到？
- 既有资产能否转作其他用途，还是只能在本行业使用？专用性越强，既有企业越可能激烈保卫市场。
- 行业是否已有过剩产能，参与者的目标和激励是否一致？
- 竞争者会怎样回应降价、扩产或新产品？如果所有企业在景气高峰一起扩产，低谷时可能共同承受产能过剩。

### 破坏式创新与价值链

破坏式创新常先服务主流企业不重视的低端或新市场。最初产品的性能可能较低，却提供价格、尺寸或便利性上的不同价值。技术进步快于客户需求增长后，这些产品逐渐进入主流市场。既有企业若只听取高利润客户的要求、维持现有利润率，就可能忽视这种威胁。

百视达依赖门店租片和滞纳金；Netflix先改善寄送DVD的便利性并取消滞纳金，再进入流媒体，后来制作内容。判断这类竞争，要检查客户得到的服务及整个经营方式如何变化，不能只比较原有产品上的性能。

企业创造价值的经济基础是客户愿意支付的金额超过提供产品的机会成本。它可以提高支付意愿、降低相对成本，或同时做到两者。**价值链分析**把设计、采购、制造、营销、配送和服务等活动拆开，比较本公司与竞争者的做法，找到价格溢价或成本优势的来源。技术变革可能使垂直整合的部分活动适合交给专业企业，也可能使原来依赖某项活动获利的企业失去优势。

### 信息商品、平台与客户价值

软件等知识产品往往前期开发成本高，复制和交付的边际成本低。网络效应使更多用户提高其他用户的使用价值；转移技能、数据、标准和合作关系的成本则可能锁定客户。这些特征可以支持快速增长和较高利润，但也可能产生赢家通吃、许多企业无法收回前期投入的结果。

书中区分聚合商和平台。聚合商拥有直接用户关系，整合丰富供给，以很低的边际成本服务新用户，并可能通过正反馈降低获客成本。平台向第三方提供经营工具和基础设施，促成供应商与用户之间的关系，从生态系统创造的价值中取得一部分。两者的客户控制权、转换成本和竞争威胁需要分别研究。

**基于客户的企业估值（CBCV）**提供了另一条检查收入预期的路径。客户价值是客户关系期间产生的现金流现值减去获客成本，现金流要扣除相关服务成本。分析需要获客速度、客户留存、购买频率和每次购买金额四类模型。

这些模型可以先产生销售预测，再进入现金流折现。用于预期投资时，可以反问：支持当前价格需要多少新客户、多低的流失率、多高的客单额？这些客户指标能否与企业竞争位置和历史记录相容？数据不足时只能作有依据的估计，不能把不可见的客户经济性当作确定事实。

## 六、达美乐：完整执行三步分析

### 第一步：还原418美元包含的经营要求

书中使用2020年8月的达美乐披萨作为案例，约3930万股、每股418美元。根据当时公开预测，采用以下条件：

| 输入 | 假设 |
| --- | --- |
| 年销售增长 | 7% |
| 营业利润率 | 17.5% |
| 现金税率 | 16.5% |
| 固定资本增量投资率 | 10% |
| 营运资本增量投资率 | 15% |
| 加权平均资本成本 | 5.35% |

超额现金及有价证券约3.919亿美元，债务等负债约41.70亿美元。作者采用永续通胀法处理持续价值。延长明确预测期后，八年模型的每股价值为417.71美元，约等于市场价格。因此，上述增长、利润率和投资条件组合对应八年的市场隐含预测期。

这一步建立比较基准，还没有证明股票便宜或昂贵。

### 第二步：解释增长来自哪里

达美乐主要依靠加盟商销售收取特许经营费，并通过供应链业务提供原料。加盟商的财务健康影响开店意愿、门店销售及母公司收入。母公司账面资本需求较低，部分原因是门店投资由加盟商承担，因此研究母公司时必须同时看加盟商。

它选择外送与外带，减少堂食面积和操作复杂度；采购、广告、技术系统形成规模优势。加密已有区域门店的“堡垒”策略改善送达速度、提高配送密度，也扩大外带需求。供货体系追求加盟商经营条件，部分利润回馈加盟商。数字订单、PULSE系统和客户资料帮助安排劳动、库存和促销。

风险包括其他快餐选择，以及DoorDash、Uber Eats等平台重组客户接触和配送关系。品牌规模和低成本对新进入者形成优势，但这种优势必须落实到加盟商收益和持续增长上。

作者建立销售年增长3%、7%、11%的低、中、高情境。考虑经营杠杆和规模效应后，分别配合16.5%、17.5%、18.5%的营业利润率，在相同八年期限下得到约290、418、586美元的每股价值。高低情境体现了销售与利润率的联动。

接着检查其他因素是否更值得研究。单靠成本效率，需要营业利润率改变超过四个百分点，才能产生与销售情境相近的价值影响；投资率也需极端变化。结合商业模式与历史记录，这些变化的可能性较低，因此销售被选为“涡轮触发因素”：最值得投入研究时间、对价值影响最大的一项经营因素。

继续追踪的领先指标是加盟商盈利与关系、国内外门店增长、同店销售。它们比单纯等待母公司下一次利润公告，更直接对应增长假设。

### 第三步：用概率区分持有、看跌与看涨

三个估值情境需要配上概率，才能形成可比较的预期价值：

| 判断 | 低情境概率 | 中情境概率 | 高情境概率 | 预期价值 |
| --- | --- | --- | --- | --- |
| 市场共识较可能实现 | 25% | 55% | 20% | 约419美元 |
| 有依据地偏悲观 | 80% | 15% | 5% | 约324美元 |
| 有依据地偏乐观 | 5% | 15% | 80% | 约546美元 |

419美元与418美元相近，缺乏明显行动空间；另外两组概率分别支持看跌和看涨判断。表中的概率是演示假设，实际投资需要证据支持。企业优点再多，也不能替代“市场对未来哪些结果估错了、为什么”的判断。

## 七、怎样使用概率、安全边际和卖出纪律

### 预期价值与外部观点

预期价值是所有情境价值的概率加权和：`Σ（情境价值×发生概率）`。情境不应只根据公司内部故事建立，还应参考相似规模、行业和经营条件下企业的历史分布，这就是外部观点或基准率。

当可能结果分布很宽时，即使当前共识仍是最可能发生的单一结果，右侧大幅上行的可能性也能使预期价值高于价格。例如，10、42、90美元三个结果的概率为15%、50%、35%，预期价值为54美元，高于42美元市场价格。

结果范围缩为35、42、55美元，维持相同概率，预期价值只有45.50美元，折价较小。如果要形成明显投资机会，就需要更有把握地判断共识概率偏低。基准率能扩展视野，但公司分布会改变，参考类也未必完全匹配，不能机械套用历史频率。

### 安全边际与等待时间

安全边际是价格相对预期价值的足够折价，用于承受估计误差和不利结果。预期价值略高于股价，还不足以自动构成买入依据。作者同时考察价格差距和市场修正所需时间：相同折价越快收敛，年化超额回报越高。

假设当前预期价值100美元、股价80美元、股权成本6%。若两年后收敛，届时预期价值按6%增长为112.36美元；80美元增长至112.36美元的年化回报约18.5%，超过股权成本约12.5个百分点。这里同时假定估值正确、预期按设定发展、价格如期收敛，计算结果不能当作收益承诺。

若市场预期没有修正，投资者通常只能期待与风险相称的回报。连续一年保持四年竞争优势期，相对于时间自然流逝后应剩三年，已经包含新增一年价值创造机会；期限表面不变也可能是预期改善。

### 卖出、换仓与税负

卖出主要有三类理由：当前股价已经超过最新估计的预期价值；存在更有吸引力、风险和组合约束相适合的替代机会；新证据迫使自己下调预期。达到旧目标价时应重新估值，目标价过时可能导致过早卖出。

换仓还需支付税和交易成本。书中用美国应税账户举例：100美元买入的股票升至121美元，卖出时若对21美元收益缴20%税，只剩116.80美元再投资。继续持有若能获得6%，一年后约为128.26美元；替代投资需要接近10%的回报，才能弥补卖出时的税款并达到同样财富。递延纳税账户和其他税制不能直接照搬这一结论。

判断应以今天的价格、预期价值和机会为基础。已经付出的成本无法收回，不能用“摊低成本”替代重新分析。把盈利当作可以随意冒险的“赌场筹码”、为了回避确认亏损而继续持有、只阅读支持原判断的资料，都可能削弱买卖纪律。

## 八、实物期权：为可选择的未来投资估值

### 哪些弹性具有价值

企业可以先作小额投入，再按需求决定是否扩张、进入邻近市场或放弃项目。管理层拥有继续投资的权利，同时能够拒绝不利项目，这种弹性称为实物期权。研发分阶段投入、能够扩建的配送设施、支持未来业务的平台投资都可能产生这种价值。

正常业务增长已经进入现金流模型，期权分析只处理尚未计入其中的可选机会，避免重复估值。对预期异常高的新企业，不能只因现有业务模型难以解释价格就断言高估；也不能把任何想象中的新业务都计为有价值的期权。

扩张机会可以类比买权。书中使用五个输入：

- `S`：项目未来现金流在今天的现值。
- `X`：未来行权时必须支付的投资额。
- `σ`：项目价值的波动性。
- `T`：还能推迟决策、又不丧失机会的时间。
- `r`：相应无风险利率。

在模型适用的条件下，项目价值相对投资成本越高、可等待期限越长、项目结果波动越大，期权价值越高。波动提高期权价值的原因是管理层可以保留有利结果、放弃不利投资；这不代表经营风险越大越值得投资。现实中的竞争、执行能力和融资约束决定这些选择能否兑现。

书中的配送中心例子为`S=3000万美元、X=4000万美元、σ=50%、T=2年、r=0.15%`。直接投资的条件欠佳，但查书中期权表，价值约为S的18.2%，即约540万美元。表格强调期权价值有限，不能高于对应的标的项目价值。

### 先看市场已经为机会支付多少

实物期权分析分两面：企业是否拥有较多可选机会，以及股价是否已经包含较高的期权价值。

| 潜在机会 | 价格推算期权价值 | 分析处理 |
| --- | --- | --- |
| 低 | 低 | 通常使用标准现金流预期分析即可 |
| 高 | 低 | 可能存在低估，仍需确认差距足够大 |
| 低 | 高 | 可能存在过高预期 |
| 高 | 高 | 详细检查项目规模、投资与执行条件 |

价格推算的期权价值等于市值减去现有业务价值。此时需要为现有业务另设合理预测期，再估计剩余部分。如果把全部价格硬塞进现有业务，模型可能只能通过延长竞争优势期来凑数，导致期限失真。

较高的期权潜力通常要求结果有较大不确定性、管理层能迅速辨识并执行机会，以及企业已有品牌、客户、技术或市场地位等资源。没有资金或无法取得融资的机会，不能视为随时可以行使的资产。

### Shopify：把一百美元差额转换成项目规模

书中分析2020年9月每股900美元的Shopify，按十年现有业务假设估值得到每股800美元，剩余100美元约对应110亿美元的期权价值。现有业务估计本身已相当乐观：前五年销售年增长约38%，后五年约35%，并包含营业利润率达到10%至15%的假设。

作者假定新项目`S/X=0.75`、波动率50%、期限三年。期权表给出的价值约为S的25%，因此支持约110亿美元期权价值，需要约450亿美元的项目现金流现值，以及约600亿美元的追加投资。若`S/X=1`，则两者约为340亿美元。

接下来的工作是检验：企业有什么额外电商业务和海外机会？能利用商家关系提供哪些服务？市场能否容纳这些项目？三年内能否取得并有效投入这么多资金？大规模投入是否仍能维持假定回报？这种逆推把模糊的增长愿景变成可质疑的资本与经营要求。

### 反身性：股价也会改变经营条件

年轻企业可能依赖高股价进行股权融资、股票并购和股权薪酬。股价下跌会提高融资成本、削弱并购能力、降低员工报酬吸引力，继而阻碍原有增长计划，进一步压低股价。供应商、客户和合作伙伴信心受损，也会加剧困难。

股权薪酬可理解为企业发股融资，再把所得支付给员工。股价因而影响实际获得人才和资本的能力。估计这类企业的悲观情境时，要检查低股价是否会使增长计划失去资金，不能只把股价下跌视为与经营无关的报价变化。

## 九、不同企业应检查不同的增长约束

| 企业类型 | 主要投入与扩张约束 | 容易影响预期的因素 |
| --- | --- | --- |
| 实物产品企业 | 厂房、设备、门店、库存；增加产量常需扩充有形资产 | 产能利用、扩产纪律、营运资金、采购与配送效率 |
| 服务企业 | 人员及其生产力；收入增长常需增加员工或提高产出 | 招聘、人才保留、人员效率、自动化和流程重组 |
| 知识企业 | 人才开发初始产品，随后低成本复制；产品过时促成下一轮投入 | 标准形成、网络效应、获客留存、产品更新与知识产权保护 |

一家企业可以同时具备几类特征，分类用于辨认现金流机制。知识产品可以多人同时使用，具有非竞争性，但保护使用权可能困难；专利、版权、技术和转换成本影响企业能否收回投入。低复制成本并不消除研发失败和过时风险，AOL与雅虎的衰退说明早期领先地位未必持久。

规模经济还要与**学习曲线**区分：前者来自当前经营规模，后者来自累积经验。销售下降可能使规模优势消失，却不一定抹去已学会的生产方法。**范围经济**则来自不同业务共同使用资源或研发成果，例如一个研究项目的发现被另一个项目采用。

成本改善可能被竞争通过降价转给客户。率先实现自动化的银行可以短期领先，但同行普遍采用后，较低交易成本往往表现为更低服务价格。估值应判断企业能保留多少节省，而非将全部节约永久计入利润。

投资效率对资本密集企业尤其直接。书中麦当劳通过标准化、采购和设计简化，在不降低新店预期销售与利润的前提下削减建店成本；Walgreens改善物流和补货，使现金循环期缩短。相同NOPAT需要的投资减少，自由现金流便增加。反之，景气高点集体扩产、只为扩大规模而开店，可能让增长损害价值。

## 十、并购：算清协同、溢价和谁承担风险

### 每股收益增厚不能证明交易创造价值

高市盈率企业用股票收购低市盈率企业，即使经营毫无改善，也可能增加合并后的每股收益。书中买方有5000万股、EPS4美元，发行4000万新股购买EPS10美元的卖方，合计利润6亿美元除以9000万股，EPS升至6.67美元。这种会计结果没有说明收购价格是否合理。

买方增加的股东价值按以下关系分析：

`并购价值增量 = 协同效应的现值 − 收购溢价`

溢价是报价高于卖方独立经营价值的部分。若股价已包含被收购预期，应先排除原有收购溢价。协同来自新增销售、经营杠杆、采购效率、裁撤重复活动、资产重组、税务或融资改善，需扣除实现这些收益的成本。

例如，税前每年节约1亿美元、税率20%、资本成本8%，按永久节约假设得到10亿美元协同现值。溢价高于这个数额，交易就需要其他收益支持。收入协同通常比成本协同更难实现，管理层过去的可信度、竞争者反应和整合成本均需检查。

收购前双方的价格已包含未来经营改善，溢价又增加一层要求。整合可能分散管理层注意力、促使员工离职，竞争者也会复制优势。并购往往一次先付全部价款，分阶段调整和退出的余地少，不能随意用“战略意义”免除回报检验。

### 股东风险值与卖方的溢价风险

**股东风险值（SVAR）**衡量在没有协同的假设下，买方市值有多大比例面临损失。现金收购时：

`SVAR = 收购溢价 / 公告前买方市值`

设买方市值50亿美元，卖方独立价值28亿美元，报价40亿美元，溢价12亿美元。现金交易的SVAR为24%。这是对溢价风险的度量；如果原有业务价值也受损，实际损失可能更大。

股票支付会让卖方分担风险。按本例固定股票交易，买方原股东持有合并公司约55.6%，其SVAR约为`24%×55.6%=13.3%`；卖方持股约44.4%，因此其溢价也有相应比例暴露于协同未兑现的风险。书中称后者为卖方的“风险溢价”，用途是检查已经承诺的溢价有多少仍需依赖合并后的表现。

固定股数交易会使卖方收到的价值随买方股价变化；固定价值交易则在交割前通过调整股数保护约定金额，把相应价格风险留给买方原股东。现金卖方主要承担交易未完成或买方无法支付的风险，股票卖方则继续参与合并公司的经营风险。

### 用交易结构与价格反应更新判断

现金支付让买方保留全部协同收益，也承担全部风险；股票支付分享风险与收益。股票支付可能暗示管理层认为本公司股价偏高，或对协同缺乏把握，但融资能力、卖方税务偏好等因素也会影响选择，不能单凭支付方式下结论。

交易类型也提供参考：较弱企业卖给较强同行、业务模式接近的运营整合，一般比跨入陌生产业的变革型交易更容易成功；扩大份额的交易则常受高溢价影响。

公告后可以用“买方市值变化加收购溢价”推算市场认可的协同。仍用本例，若买方市值跌5亿美元，市场剩余认可的协同风险约为7亿美元；按新的45亿美元市值计算，现金SVAR约为15.6%。过去的跌幅已经发生，新买家和继续持有者面对的是当前价格中的剩余风险。股价上涨也可能提高后续需要兑现的协同要求。

## 十一、回购：低价和资金用途共同决定得失

### 回购黄金法则

公司应在股价低于预期价值、而且没有更好投资机会时回购。判断包括两个问题：购买本公司股票是否便宜，以及同一笔钱用于经营投资是否能得到更高回报。管理层相信股价便宜的说法需要核验，过度自信也会发生在经营者身上。

回购改变退出股东与留下股东之间的财富分配。假设公司价值10万美元、1000股，每股价值100美元，拿2万美元回购：

- 以200美元回购100股，余900股对应8万美元，留下股东每股价值降至88.89美元。
- 以50美元回购400股，余600股对应8万美元，留下股东每股价值升至133.33美元。
- 发放每股20美元股利，剩余每股价值80美元，股东获得20美元现金；忽略税务差异时，股东受到相同对待。

低价回购把价值转给留下的股东，高价回购则让他们受损。什么都不做也会增加在剩余公司中的持股比例，持有者仍需评估这次资金配置。

### 四种常见动机

**传达低估信号。** 公告和实际执行要区分。公开市场回购弹性最大，表达信心的约束较弱；荷兰式拍卖和固定价格要约往往承诺更明确。回购规模、相对市价的溢价、内部人持股及是否一起卖出，都影响信号可信度。仍须查明具体哪些经营预期被低估。

**管理每股收益。** EPS增厚取决于益本比与税后资金利率的比较。益本比高于放弃的税后利息收益或新增债务成本时，回购可能提高EPS，反之可能降低。这个关系与股票相对预期价值是否便宜相互独立。抵消股权薪酬稀释、达到奖金门槛或维持股数，也不能自动证明回购合理。

**返还现金。** 在书中讨论的美国应税情境下，回购允许未卖出者延迟纳税，卖出者通常只对资本利得纳税，可能比股利更有税务效率。税收好处仍不足以支持高价回购，也不能替代对更好经营投资的比较。

**增加财务杠杆。** 债务可以带来税盾，约束管理层把多余现金投入低回报项目；债务过多则产生法律、行政、客户流失和供应商信心等财务困境成本。提高杠杆可能一次性增加价值，却仍需要比较实施方式，股票已被高估时回购可能代价过高。

回购还可能表示管理层已经缺少可创造价值的投资。如果价格仍包含大量增长机会，这种返还现金的决定可能反映未来机会少于市场预期。投资者应同时检查经营前景与资本配置动机。

## 十二、把新消息转化为可检验的判断

### 用概率记录、反馈与路标改善判断

分析者应写出明确概率，例如“明年增长超过10%的概率为70%”，避免仅说“很可能”。不同的人对相同词语会有不同理解，含糊措辞也让事后检验失去标准。长期追踪后，可以检查被赋予70%概率的事件是否约有七成发生，这叫概率校准。

事前验尸要求假设投资或交易已经失败，再独立写出可能原因，用来扩大原来过窄的情境范围。过度精确容易让分析者遗漏极端结果，确认偏误则使人只搜集支持已有持仓的材料。保留原始判断、主动找反证、听取不同意见，有助于及时纠正。

每个投资判断还应对应经营路标：客户留存、开店进度、产品发布时间、交货周期、加盟商利润等。新结果偏离预设路径时，触发重新估值和概率更新；无需等到股价证实损失后才承认原假设有问题。

### 常见事件的检查方法

| 事件 | 应进入分析的内容 |
| --- | --- |
| 宏观冲击 | 用产业地图追踪需求、原料、融资与供应链变化，再计算销售、成本、投资的联动；蒙特卡洛模拟可帮助探索多个结果 |
| 高管更换 | 检查新管理者的资本配置、业务组合和执行能力，及其经验是否适合新企业；高声誉不保证技能可迁移 |
| 股票拆分与股利变化 | 拆分不增加总价值；信心、流动性或未来现金流波动的信号需要另查，单一事件通常不足以支持很大的预期修正 |
| 增发与大幅资产扩张 | 检查资金能否以超过资本成本的回报投入；历史上的后续低回报关系只提供参考，不能机械套个股 |
| 诉讼 | 按败诉概率、实际赔偿、保险补偿估计负债，同时估计声誉、销售限制、未来现金流和破产风险 |
| 补贴、关税、配额与监管 | 检查定价、成本与进入障碍如何变化，合规成本可能相对有利于资源更多的既有企业 |
| 出售资产与分拆 | 比较出售所得与资产在本公司内部的价值，检查是否释放低回报资本、提高管理专注度，以及所得资金后续用途 |

疫情案例显示，相同冲击在不同阶段会导致市场不断修正行业预期。高固定成本、较高负债与有限现金结合，可能把经营下降变为生存风险；大量现金则提供度过困难的能力。宏观预测本身很难，企业层面的情境与承受力更适合逐项研究。

### 极端股价波动后的清单

情绪激动时，按照事先写好的“先读后做”清单行动，更容易维持分析顺序：重新确认消息，估计长期影响，检查价格已经反映多少变化，更新概率与预期价值，再比较买卖和持有。

作者研究过单日相对市场涨跌超过十个百分点的案例，按是否属于业绩事件、此前动能、估值与投资质量建立参考类，再观察后续回报分布。平均结果可以作为起点，个股仍可能明显偏离。参考类越细，相似性越高，但可用样本也越少。

每次决策都应留下能够被后续事实检验的内容：当前价格需要哪些经营条件，自己与市场的分歧是什么，哪几个指标会验证或推翻判断，以及当前价格相对概率加权价值是否仍有足够空间。
