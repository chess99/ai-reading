# 有闲阶级论

## 一、作者与著作背景

### 1.1 凡勃伦其人

索尔斯坦·邦德·凡勃伦（1857-1929）是美国经济学和社会学的独特人物，被誉为**制度经济学之父**。他出生于威斯康星州的一个挪威移民家庭，在12个孩子中排行第四凡勃伦的学术轨迹颇为独特：大学期间师从古典经济学名家约翰·贝茨·克拉克（John Bates Clark），后进入约翰·霍普金斯大学攻读哲学，转学至耶鲁大学研究经济学，1884年获得博士学位。此后待业七年，直到1891年才在康奈尔大学获得教职。

1899年出版的《有闲阶级论》是凡勃伦最负盛名的著作，奠定了他在经济学和社会学领域的独特地位。这部作品从社会演进的角度系统探讨了有闲阶级及其相关社会心理现象，成为制度经济学和社会学批判理论的经典之作。

### 1.2 著作的理论定位

《有闲阶级论》被凡勃伦本人定位为"关于制度的经济研究"。在此书中，凡勃伦发展出一套独特的理论体系，用以解释现代社会中上层阶级的行为模式、消费习惯及其对社会文化的影响。尽管凡勃伦不属于马克思主义阵营，但他的阶级分析方法与马克思主义的立场有诸多契合之处，其批判精神同样深刻。

## 二、核心概念体系

### 2.1 有闲阶级（Leisure Class）

**有闲阶级**是全书的核心概念，指那些摆脱了劳役性工作的社会上层阶级。凡勃伦命名"有闲阶级"的关键在于：其本质特征是**脱离劳役**（而不仅仅是脱离生产）。

**劳役（Industry）**与**非劳役性**活动的区分是理解有闲阶级的关键：

| 劳役性职务 | 非劳役性职务（荣誉性） |
|------------|------------------------|
| 耕种、收割 | 政治 |
| 家务劳动 | 战争、军事 |
| 服侍工作 | 宗教信仰 |
| 生产性劳动 | 运动竞赛 |
| 日常体力工作 | 学术研究 |

**核心洞见**在于：区分两者的关键并非生产与否，而是前者所蕴含的**掠夺性成分**以及由此生发出来的功勋和荣誉。劳役性职务虽然为社会生产了众多必需品，却因缺乏掠夺性而为人所鄙视。

### 2.2 炫耀性休闲（Conspicuous Leisure）

**炫耀性休闲**是有闲阶级证明自身的两种主要方式之一。休闲即免于劳役，它是拥有财富和社会地位的明证。

**炫耀性休闲的特征**：

- 上层阶级的有闲并非无所事事，而是有专门的活动：文学、艺术、政治、战争、宗教、运动竞赛
- 确立了尊卑有序的礼仪体系，用以区分不同等级的身份地位
- 妻子和仆从也可以免于劳役，形成**代理休闲**
- 产生了**仪态（manners）**的概念——作为有闲生活的证明

**仪态的起源与功能**：

- 花费大量时间和精力用于非生产性活动
- 需要足够的闲暇时间来培养
- 成为身份地位的重要标志
- "仪态塑造个人"（Manners maketh man）

### 2.3 炫耀性消费（Conspicuous Consumption）

**炫耀性消费**是有闲阶级证明自身的第二种主要方式。其本质是一种**浪费**——从事奢侈的、不必要的消费。

**炫耀性消费的原则**：

- 必须是他人的消费，即**代理消费**
- 浪费必须在他人面前进行
- "凡博得好名声的消费和懒惰，都在证明财力雄厚"
- 消费的目的不是为了物质享受，而是为了证明社会地位

**炫耀性消费的演变**：

- 在野蛮文化时期，上层阶级主要依靠炫耀性休闲来证明自己
- 在现代社会中，**炫耀性消费的比重越来越大**
- 原因在于人类本性中存在**工作本能**，厌恶没有用处的活动

### 2.4 金钱攀比（Pecuniary Emulation）

**金钱攀比**是人类行为的重要动机，指通过金钱财富来进行的歧视性对比。

**金钱攀比的特征**：

- 财富赋予人们**歧视性的荣耀感**
- 所有制的根本动机是攀比，而非生存需要
- 追求财富是为了在与他人对比中获得优势
- "欲望在任何人那里都不可能得到满足"

**关键洞见**：攀比的目标是**相对优势**，不是绝对财富；因此无论生产力发展到多高的水平，人们也不会停下追逐财富的脚步。

### 2.5 歧视性区分（Invidious Distinction）

**歧视性区分**是凡勃伦理论的核心机制，指社会根据荣誉、价值、地位对不同职务和人进行分等分级的做法。

**歧视性区分的历史演变**：

1. **蒙昧时期**：平和的社会，缺乏歧视性区分
2. **野蛮时期**：出现掠夺性文化，形成功勋与杂役的歧视性区分
3. **现代工业社会**：歧视性区分以金钱荣誉为标准

## 三、社会演进理论

### 3.1 文化发展的三个阶段

凡勃伦将原始社会的发展划分为三个阶段：

**（一）蒙昧时期（Savage Era）**

- 极度平和的社会
- 工作区分非常含糊
- 缺乏有闲阶级
- 私有财产不发挥主导作用
- 成员温顺、不具有攻击性

**（二）野蛮时期（Barbarian Era）**

- 取而代之掠夺性文化
- 男女职能分化：男性从事战争、狩猎；女性从事劳役
- 出现私有制和有闲阶级
- **有闲阶级产生的必要条件**：
  1. 族群具有以掠夺为目的的生活习惯
  2. 维持生计的必需品充足，使大部分人免于日常劳务

**（三）现代工业社会**

- 从掠夺性活动转变为生产性活动
- 金钱攀比取代武力掠夺成为主要竞争方式
- 私有财产制度完善
- 炫耀性消费成为证明地位的主要手段

### 3.2 私有制的起源

凡勃伦提出了一个重要观点：**私有制与人类生存的目的毫无关系**，其真正动机在于攀比。

**私有制起源的机制**：

1. 野蛮人对外掠夺或打猎赢得荣誉
2. 个人利益与集体利益发生分歧
3. 个人认为战利品属于自己是一种荣誉
4. 个体之间的歧视性对比构成私有制的心理基础

### 3.3 功勋与劳役的区分

**功勋（Exploit）**指带有掠夺性的、需要勇武而非勤奋的活动：

- 战争
- 狩猎（与畜牧业时期不同）
- 政治活动
- 宗教信仰
- 运动竞赛

**劳役**指生产性、实用性的工作：

- 农业生产
- 家务劳动
- 手工艺制作
- 服务性工作

**关键区分**："功勋和杂役之间的差别和男女两性之间的差别是相同的"——这种区分是文化建构的，而非自然形成的。

## 四、消费理论

### 4.1 炫耀性消费的经济学分析

**炫耀性消费的动机**：不是效用或预算约束，而是**荣誉**。这是野蛮时期掠夺性文化传承至今的特质。

**炫耀性消费的特征**：

| 特征 | 说明 |
|------|------|
| 浪费性 | 超出必要需求的消费 |
| 可见性 | 必须在他人面前进行 |
| 代理性 | 通过他人（仆从、妻子）消费 |
| 歧视性 | 用于区分社会等级 |

**炫耀性消费与炫耀性休闲的选择**：

- 在社会发展的初级阶段，两者的效用大致相同
- 随着社会发展，**消费逐渐超越休闲成为礼仪的主要表现方式**
- 原因：通信工具和人口流动使个人置于大众观察之下

### 4.2 服装的消费心理学

凡勃伦专章讨论**服装作为金钱文化的重要表现**。

**服装消费的原则**：

1. **体面优先于实用**：人们穿衣服首先是为了体面，而非保暖
2. **不方便性**：好衣服必须令着装者不方便干活
3. **免于劳役的证明**：服装必须显示着装者不从事体力劳动

**女性服饰的特殊意义**：

- 高跟鞋、长裙使着装者无法从事体力劳动
- 紧身胸衣损害健康以展示柔弱
- 服装设计传达"免于劳动"的信息
- 欧美的紧身胸衣与中国的三寸金莲是典型例证

**服装时尚的演变**：

- 上层阶级创造时尚
- 下层阶级模仿
- 上层阶级设计新的式样以保持差距
- 形成无终止的"时尚之旅"

### 4.3 审美观念的金钱标准

凡勃伦提出了一个重要观点：**人们的审美观念本质上受到金钱荣誉准则的支配**。

**审美标准的例子**：

| 被认为不美观的 | 被认为美观的 | 原因 |
|----------------|--------------|------|
| 猪、羊、家禽 | 猫、狗、鸽子 | 后者花费多、无实用性 |
| 机器制品 | 手工制品 | 前者廉价、可及性高 |
| 实用的物品 | 装饰性物品 | 浪费性=荣誉性 |

**手工制品优于机器制品的原因**：

- 手工劳动是一种比较浪费的生产方式
- 手工制品具有荣誉的性质
- 手工制品含有"荣誉的粗率"——表明制作者不必从事生产

## 五、社会心理分析

### 5.1 有闲阶级的精神特征

凡勃伦总结了有闲阶级精神世界的四个重要特征：

**（一）保守性**

- 生而保守，抵制改革
- 原因：环境总是在变，穷人较容易屈从于压力；有闲阶级过度奢华使其不思改革
- 最穷的民众也是保守的，因为贫穷使其丧失幻想美好未来的能力
- 凡勃伦观点：**中产阶级神话**需要重新审视，上层有闲阶级才是真正保守的力量

**（二）掠夺性**

- 起源于野蛮时期的掠夺性文化
- 通过上层阶级准入和退出的优胜劣汰过程保持
- 比较平和友善的，早已被淘汰

**（三）尚武精神**

- 现代社会中大部分人已丧失，但上层阶级保存较多
- 最突出的表现：**体育竞赛**
- 体育竞赛精神是凶暴与狡诈，本质上不利于集体经济利益

**（四）信赖运气**

- 起源于万物有灵论
- 对"偶然的必然性"的意识
- 热衷赌博是突出表现
- 凡勃伦认为：**18世纪以来的自然法理论不过是一种淡化的拟人论**

### 5.2 代理休闲与代理消费

**代理休闲阶级**的功能是为原发性有闲阶级进行代理休闲：

- 妻子和仆从的休闲是为了主人更好地休闲
- 奴仆的休闲并非自身的休闲，而是"专业服务"
- 代理休闲的黄金发展时期已经消逝

**代理消费的承担者**：

- 妻子的消费
- 仆从的消费
- 礼物和宴会的消费

**代理休闲的现代形式**：

- 家务职责
- 社交活动（出访、旅行、参加俱乐部）
- 慈善活动

### 5.3 宗教信仰的经济分析

凡勃伦对宗教进行了独特的经济学分析：

**宗教消费的经济特征**：

- 宗教建筑、法衣等是炫耀性浪费项目
- 教职人员的生活是代理休闲
- 宗教消费的本质是**代理消费**

**宗教信仰与社会阶层的关系**：

- 上层有闲阶级保持宗教热忱
- 下层阶级中游手好闲之徒也保持宗教热忱
- 技术工人阶级对宗教最不热忱
- 原因：宗教与工业制度不相容，而与身份制相适应

## 六、制度与文化分析

### 6.1 有闲阶级与社会进步

**有闲阶级是社会保守力量的代表**：

- "凡存在的，都是对的"（Whatever is, is right）
- 制度是过往进程的产物，不能完全顺应现实需求
- 保守因素包括：社会惯性、心理惯性

**有闲阶级保守性的原因**：

1. **本能的保守倾向**：生活习惯和思维习惯的任何改变总是令人讨厌
2. **经济庇护**：能够避开经济形势的压力
3. **示范效应**：其生活方式成为其他阶级的规范

### 6.2 高级学识与金钱文化

**学识与有闲阶级的关系**：

- 学识起源于祭司代理休闲阶级的副产品
- 高级学识是有闲阶级的特权
- 学习高级学识的目的是**证明不用从事生产劳役**

**古典学（人文学科）的经济价值**：

- 古典学之所以被推崇，**主要因为它不实用**
- 学习古典语言需要大量时间，证明有闲暇
- 古典学服务于炫耀性浪费的目的
- 是获得荣誉的有效方式

**高等学校与有闲阶级**：

- 高等学校保持保守立场
- 对创新持怀疑态度
- 体育运动成为新的"学识"分支
- 与古典学争夺有闲阶级教育的地位

### 6.3 身份制与掠夺性文化

**身份制**是有闲阶级社会的基本特征：

- 人与人之间的关系是统治与服从的关系
- 基于所有权和财产的等级划分
- 与掠夺性文化相适应

**拟人论信仰**是身份制的精神表现：

- 神被视为一个主宰一切的傲慢好战的酋长
- 信徒对神的关系是服从关系
- 宗教仪式强化了身份意识

## 七、理论框架与核心命题

### 7.1 凡勃伦理论的核心命题

**命题一**：有闲阶级制度起源于野蛮时期的掠夺性文化，其本质是对劳役性工作的歧视性区分。

**命题二**：炫耀性消费和炫耀性休闲是有闲阶级证明自身地位的主要方式，其核心是**浪费**。

**命题三**：金钱攀比是人类行为的根本动机，财富追求的真正目的是**相对优势**而非绝对满足。

**命题四**：审美观念、道德观念、宗教观念等都受到金钱荣誉准则的支配。

**命题五**：有闲阶级是社会保守力量，阻碍制度变革和社会发展。

**命题六**：现代工业社会的发展趋向于消灭有闲阶级，但有闲阶级通过文化传递维持其影响。

### 7.2 理论的方法论特征

**制度经济学的方法论**：

- 强调**心理和习惯**在经济行为中的作用
- 从**社会演进**的角度分析制度
- 关注**非经济因素**（文化、心理）对经济的影响
- 采用**达尔文主义**的优胜劣汰框架

**与古典经济学的区别**：

| 古典经济学 | 凡勃伦的制度经济学 |
|------------|-------------------|
| 关注生产与效率 | 关注消费与浪费 |
| 理性人假设 | 强调习惯与心理 |
| 边际效用分析 | 歧视性对比分析 |
| 静态均衡 | 社会演进过程 |

## 八、理论应用与当代意义

### 8.1 对消费社会的预言

凡勃伦的理论有很强的**预言性**，对理解当代消费社会仍有意义：

**炫耀性消费的当代表现**：

- 奢侈品消费的增长
- 品牌象征意义的强调
- "凡勃伦效应"：商品价格越高越受欢迎
- 社交媒体时代的炫耀性消费

**凡勃伦效应的特征**：

- 消费的目的不在物质需求，而在社会地位
- 高价成为质量的证明
- 消费成为歧视性对比的工具

### 8.2 对阶级分析的理论贡献

凡勃伦的阶级分析方法对后来的社会学研究产生了深远影响：

**消费行为作为阶级标志**：

- 不同阶级有不同的消费模式
- 消费成为阶级身份的表达
- 上层阶级通过消费示范影响下层阶级

**阶级分化的心理机制**：

- 金钱攀比的普遍性
- 歧视性对比的心理满足
- 消费标准的社会传递

### 8.3 对道德与文化的批判

凡勃伦对现代社会的道德和文化进行了深刻批判：

**道德的阶级性**：

- "富与善"被等同
- 穷人思维被污名化
- 贫富差距合理化的意识形态

**文化工业的批判**：

- 古典教育是金钱文化的工具
- 审美标准被金钱荣誉准则支配
- 文化传承强化阶级壁垒

## 九、批判性评价

### 9.1 理论贡献

1. **开创性视角**：从消费和社会心理角度分析阶级问题
2. **深刻的洞察力**：预见了消费社会的发展趋势
3. **跨学科方法**：整合经济学、社会学、心理学和文化研究
4. **批判精神**：对资本主义社会进行深刻的社会学批判

### 9.2 理论局限

1. **过度强调心理因素**：可能低估物质生产关系的决定作用
2. **进化论框架的问题**：将人类社会简单类比生物进化
3. **阶级分析的简化**：忽视阶级内部的多样性
4. **忽视生产领域**：过度关注消费领域

### 9.3 与其他理论的关系

**与马克思主义的比较**：

- 两者都关注阶级问题
- 凡勃伦不认同马克思的革命理论
- 但在批判资本主义方面，两者有共通之处
- 凡勃伦的消费分析可补充马克思的生产分析

**与新古典经济学的关系**：

- 凡勃伦明确反对新古典经济学的理论框架
- 批评其将追求财富简单归结为效用最大化
- 强调社会心理因素的重要性

## 十一、阅读指南

### 11.1 本书结构

全书共14章，可分为以下部分：

**第一部分（第1-3章）**：理论基础

- 有闲阶级的起源与定义
- 金钱攀比的理论
- 炫耀性休闲的分析

**第二部分（第4-7章）**：消费分析

- 炫耀性消费机制
- 生活的金钱标准
- 品味的金钱准则
- 服装消费心理学

**第三部分（第8-14章）**：社会与文化

- 有闲阶级与保守主义
- 古代特质的保存
- 尚武精神
- 宗教信仰
- 非歧视性利益
- 高级学识

### 11.2 推荐阅读顺序

1. **初次阅读**：从第1章（绪论）和第2章（金钱攀比）开始
2. **核心概念**：重点阅读第3章（炫耀性休闲）和第4章（炫耀性消费）
3. **延伸理解**：第7章（服装）和第14章（高级学识）提供了具体例证
4. **理论深度**：第8章（保守主义）和第9章（古代特质保存）深化理论框架

**结语**

《有闲阶级论》是理解现代消费社会的一把钥匙。凡勃伦以锐利的眼光揭示了人类社会中的一个基本矛盾：物质生产的发展并未带来精神的解放，反而催生了以浪费和攀比为特征的有闲阶级文化。这部百年经典对于理解当代消费主义、阶级分化和文化生产具有持久的理论价值。凡勃伦提醒我们：在追求财富的道路上，人类往往迷失于相对比较的竞赛中，而忘记了生活的真正意义。
