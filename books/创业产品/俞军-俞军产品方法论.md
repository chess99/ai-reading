# 俞军产品方法论

本书由俞军与原滴滴快捷出行产品团队共同整理，将俞军在百度（2001—2009）和滴滴（2016—2019）两段实践中形成的方法论系统化。核心主张是：将经济学与心理学引入产品工作，用用户模型和交易模型驱动决策。

## 二、用户模型：理解用户的框架

### 用户的定义

**用户不是自然人，而是需求的集合。**

同一个人在不同情境下对应不同产品的"用户"。微信有11亿账号，但拆分成通信、支付、公众号等需求维度，用户数实际远超11亿。以自然人计用户会掩盖真实的需求分布，让企业自我满足于注册数字而忽视用户价值的深度。

### 用户的五个属性

| 属性 | 含义 |
|------|------|
| **异质性** | 每个用户的偏好、认知、资源各不相同，没有统一的用户画像 |
| **情境性** | 没有情境就没有用户，同一人在不同情境下行为迥异 |
| **可塑性** | 用户偏好与认知会随外界刺激变化，可被产品或营销影响 |
| **自利性** | 用户追求个人总效用最大化 |
| **有限理性** | 用户有追求理性的意愿，但能力有限，经常被偏误支配 |

### 用户行为机制

用户行为的产生遵循以下链条：

> **情境刺激** → 调用偏好与认知函数 → 经过感知、解读、选择集合、模拟推演、价值判断五步 → **期望效用** → 行为 → 产生结果 → 反馈修正偏好

关键洞察：促成用户行为最高效的方式是**选择合适的用户**（偏好和认知天然契合），而非在情境上做大量特殊设计。

### 双系统理论

- **系统1（快思考）**：本能、习惯驱动，自动启动，耗能少，受认知偏误支配
- **系统2（慢思考）**：逻辑与理性，被动启动，耗能高，有意识控制

人类90%以上的日常决策由系统1驱动。产品经理研究用户时要认识到：用户大多数情况下不会理性计算，产品设计应顺应系统1而非对抗它；而产品经理自己做决策时，则要强制启动系统2。

### 用户价值的特性

用户价值（主观效用）具备三个特性：
1. **认知依存**：用户的认知决定偏好
2. **情境依存**：离开情境就没有用户
3. **经验反馈演化**：随着经验积累，用户价值判断会变化

**衡量用户价值的核心公式：**

> **用户价值 = 新体验 − 旧体验 − 替换成本**

提升用户价值的三个方向：最大化新体验、最小化旧体验（找旧体验接近零的"完美新用户"）、降低替换成本。

## 三、产品定义与企业-用户-产品关系

### 产品的本质

**产品是约束条件下的一个效用组合，是企业与用户进行价值交换的媒介。**

企业卖的不是产品本身，而是产品背后的用户价值。产品每增加一个属性，都是在调整效用组合——有些用户被选择，有些被放弃。分析产品要看"利从何来、利往何去"，而非只看功能表面。

一个好产品必须同时满足三个属性：
1. **有效用**：对用户有使用价值
2. **有利润**：能让企业获利（可间接）
3. **可持续**：长期用户利益与商业利益统一

### 企业-用户-产品的关系

企业的本质只有两点：**发现市场获利机会**，以及**生产效率高于市场**。

发现机会的三条路径：洞察（信息不对称获利）、试错（不断迭代验证）、偶然性（尊重不确定性）。

企业之所以存在，是因为通过内部权威决策可以节约市场交易费用。企业的核心竞争力来源于显性知识与默会知识的积累——尤其是员工在岗位上沉淀的专业知识，是难以被复制和替代的。

创造价值的五大路径：**劳动、分工、交易、新技术、制度**。其中制度（产权保障）是最根本的，新技术是最显著的——工业革命之所以只能在英国发生，是因为英国王室势弱被迫授予国民产权保障，激励了几代人的商业冒险。

## 四、交易模型：产品经理的进阶框架

### 交易的本质

**产品即交易**。用户的每一次有意识行为，都可以看作他付出预期代价换取预期收益的交易。

世界上不存在等价交换：每次交易发生时，双方都主观判断自己获益了——否则不会成交。交换创造价值，同一物品换到更能发挥它价值的人手中，总价值增加了。

### 交易模型的核心

**交易模型 = 可持续交易的多边利益创造与分配机制**，本质是两个命题：
- **利从何来**（如何创造用户价值）
- **利往何去**（如何分配利益，使各方持续参与）

搜索、社交、阅读等免费产品也是交易——只是用户支付的是时间与注意力而非货币。

重要概念：
- **损失厌恶**：同量损失的负效用约为同量收益正效用的2.5倍，交换须让用户感到获益超过付出的2.5倍
- **选择增加福利**：提供更多选项（即使不用）能增加用户的主观效用
- **激励相容**：让追求个人利益的行为与整体价值最大化目标一致（赫维茨，2007年诺贝尔经济学奖）

### 效用的多样性

效用不止于货币，还包括：时间、身体需求（健康、美丽、安全）、心理需求（归属、尊重、自我实现）、信念（价值观一致性）、情绪、认知（减少认知失调）。

产品需求可分四类：
- **底线需求**：一票否决，不达标用户直接离开
- **够用就好**：边际效用递减，做到及格线即可
- **越多越好**：用户愿意为更多效用持续付费
- **惊喜**：超出预期的正效用，惠而不费，性价比极高

### 人间第一定律与相对价格

> **相对价格 = （直接成本 + 交易成本）÷ 效用组合**
>
> **其他条件不变时，相对价格降低，需求量必然上升**

这是比需求定律更完整的分析工具，因为它明确了：
1. 成本不只是钱，还包括各类交易成本
2. "商品"是用户视角的效用组合，而非客观属性

红海时代，产品增长的主要路径是：追加效用组合（上升用户价值）、降低直接成本、降低交易成本——三条路都能降低相对价格、转化更多边际用户。

## 五、交易成本：产品价值的深层逻辑

### 交易成本的本质

**交易成本 = 买方付出但卖方未得到的成本 + 卖方付出但买方未得到的成本**。

交易成本来源于信息的四种缺陷：
1. **信息不对称**：一方拥有另一方没有的信息
2. **信息不确定**：至少一方在做决策时信息尚未揭示
3. **信息不完全**：某些相关信息至少一方不知道
4. **信息有成本**：收集、处理、传播信息本身要花代价

市场型交易成本主要分三类：
- 搜寻成本 + 度量成本
- 寻价成本 + 决策成本
- 实施成本 + 保障成本

### 降低交易成本的典型手段

- **标准化**：把产品变成搜寻品（质量信息高确定性），大幅降低度量成本
- **信息透明化**：链家真房源本质上是承担高昂的保障成本以消除买方搜寻成本
- **线上化**：餐饮交易链路数字化，使收入可核查，大幅降低股东监督成本
- **个性化推荐**：降低用户的搜寻成本（信息找人，不是人找信息）

互联网产品之所以市值高，核心在于极大降低了某些交易成本，从而使原本无法成立的交易得以成立。

张五常估算：成熟社会的交易成本占国民收入超过50%，可见降低交易成本的价值空间极大。

## 六、决策框架

### 理性决策三要素（重要性排序）

1. **理性的信念**（第一重要）：信念与真实世界一致，即"对自我认知的认知"。要反思自己对某个决策的认知程度，意识到可能存在的偏差。人类最大的理性是理性地理解自身认知能力的局限性。

2. **理性的目标**（第二重要）：目标是约束条件下的价值（总效用）最大化。要批判性地审视既有目标：目标是否合理？约束条件是否已变化？

3. **理性的行动**（第三重要）：在给定目标下寻找最优方案。

实践中大多数人只做第三步，但目标错了，执行得越好损失越大。

### 常见决策方法与误区

**数据决策**：适合可控、快迭代的在线产品，AB测试是最重要的科学工具。但数据有局限：不是所有问题都适合AB测试；数据只能反映过去；过度依赖数据会减少深度思考训练（卢卡斯批判）。

**逻辑决策**：说理的有效前提是对方具备相应认知结构。产品经理需要认识到，并不存在客观的事实，只有对方认知框架内可接受的事实。

**主观判断决策**：最难，没有数据或逻辑支撑时，依靠用户模型和交易模型进行假设性推演，在脑中模拟不同行为路径及结果，选取最优解。

### 用户价值判断的九个视角

对任何价值判断，可用以下维度辅助提升质量：
1. **对自我认知的认知**：我的认知缺口在哪里？
2. **对给定目标的批判**：这个目标合理吗？
3. **参照系**：用户心里的参照基准是什么？
4. **成本**：谁只谈收益或只谈成本，不是骗子就是傻瓜
5. **不确定性**：尊重世界的不确定性
6. **概率**：预期效用 =（收益 − 成本）× 概率
7. **非货币价值**：效用需要跨属性权衡
8. **外部性**：一方的目标可能和他方冲突
9. **时间性**：短期对的，长期可能错

### 认知偏误（精选）

产品经理必须对以下偏误保持警觉：
- **归因偏误**：成功归自己，失败归环境（自利偏误）；三维归因（情境特殊性、他人一致性、个体一贯性）可减少错误
- **锚定效应**：用熟悉数值作为参照基准，严重影响估值
- **损失厌恶**：面对等量收益与损失时，损失感受是收益的2.5倍
- **证实偏见**：只关注能证实自己假设的信息
- **沉没成本谬误**：已投入的成本不能影响未来决策
- **幸存者偏差**：只看到成功案例，忽略沉默的失败数据
- **峰终定律**：体验记忆由峰值和终点决定，过程中的时长比例影响不大

## 七、产品经理的选拔

### ABC 天赋分类

**A类**（极少数）：具备深度思考能力或超常同理心。深度思考是指能习惯性思考事物本质，在同等条件下洞察更深更快。超常同理心是指准确察觉和判断他人感受，天生本能级别的"利他"驱动。

**B类**（大多数）：逻辑清晰且有产品心。产品心是真心喜欢做产品、能从产品工作中感受乐趣，而非功利性动机（高薪、权力、短期绩效）驱动。

**C类**（排除）：逻辑不清晰、同理心明显弱、功利心过重、不爱思考、缺乏实践精神、自我认知过高，均不适合从事需求型产品经理职业。

### 产品经理价值公式

> **产品经理的价值 = 经验等级 × 平台匹配度 × 智慧等级**

- **经验等级**：五年是分水岭，之后经验差距趋于稳定，靠其他要素拉开距离
- **平台匹配度**：与团队的互相磨合和共同知识积累；跨公司空降会大幅清零
- **智慧等级**：换领域后能快速重建认知、产生新洞察的能力；智慧等级高则跨域跳槽不贬值

高阶产品经理空降成功率低，根本原因是平台匹配度为零。只有四种情况下成功率较高：复制同类产品、做全新产品、灾后重建、有巨大新要素正在改变行业。

### 面试核心

两类问题：
1. **围绕他做过的事深入追问**：寻找"用同等分母（经历复杂度、时间投入）下的最大分子（洞察深度）"，而非简单看产品规模和职级
2. **问他不熟悉的事**：看他面对陌生问题时的思维框架——是如何拆解、推演、形成判断的

判断专业能力的四维度：批判性思维、同理心、用户模型掌握程度、产品技能熟练度。

判断潜力的三维度：**自省**（第一潜力）、学习意愿与能力、高成就动机。

## 八、产品经理的成长

### 两大里程碑

**用户模型**是合格线：能预判产品迭代后的用户行为变化，准确率较高。需要大量个体案例积累，无法靠培训速成，需在不断迭代和验证中建立。

**交易模型**是进阶线：超越单边用户视角，理解多方利益博弈和可持续分配机制，设计"创造有利可图的用户价值"的产品。

### 成长三支柱

**科学方法**：逻辑、概率、控制实验、理性决策、经济学方法。AB测试是当代最重要的产品工具；理性决策有方法可学。

**人文关怀**：同理心、心理学、进化论、博弈论。必须积累足够大的用户样本量（特定情境下的每次使用），才能减少偏差地理解用户。

**实践精神**：事实、数据、观察、实践、权衡、反馈、迭代、自省。产品工作以终为始，一切想法必须经受实践验证。

### 批判性思维

如果只学一件事来获取最大成长，那一定是**批判性思维**——对信息的目的、前提、结论进行合理分析和判断，要求证据与逻辑，反对诉诸权威，区分理性与情感。

从应试教育中长大的人普遍缺少批判性思维，一旦转变，是最显著的成长。

### 前五年：打基础

两个最重要原则：
1. **从大量产品迭代中验证和思考**：不是找大机遇一飞冲天，而是在反复实践中积累用户样本和洞察
2. **加入有产品心的小团队**：直接上级和身边同伴的产品文化，比大公司品牌更影响成长

### 进阶六能力

| 能力 | 价值 |
|------|------|
| **从0到1** | 经历想法发散收敛、资源从零获取的完整创业过程 |
| **做深做透** | 把一个细分场景打穿，理解极致迭代的路径 |
| **做宽做杂** | 建立全局观，避免一专独大的视野盲点 |
| **大用户量** | 学会理解用户的异质性和情境性，获得高灵敏度的迭代反馈 |
| **商业闭环** | 同时考虑用户价值和商业价值，才是完整的产品思维 |
| **团队建设** | 产品决策质量 > 人员数量，关键是识人用人 |

### 五年后的方向选择

- **专业路线**：天赋明显高者选此路，发展交易模型设计能力，创造有利可图的用户价值
- **管理路线**：天赋一般者可更早带团队，核心是识人用人，让优秀下属做业务决策
- **业务路线**：持续深耕一个领域，靠知识和经验积累持续升值，to B产品是求稳方向
- **新产品/出海**：机会成本低者适合冒险，优秀者应选后期（C/D轮）更确定的大产品

### 成长的不利环境

短期利益导向、搞个人崇拜、技术驱动、内部争斗、上级不会深度思考、产品迭代周期长、用户量少、分工过细、行业垄断……

产品经理要学会在约束条件下改变自己寻找最优解，而不是等待完美环境。

| 框架/公式 | 内容 | 用途 |
|-----------|------|------|
| **用户价值公式** | 新体验 − 旧体验 − 替换成本 | 衡量产品价值，指导迭代方向 |
| **相对价格公式** | （直接成本 + 交易成本）÷ 效用组合 | 分析需求量变化，找增长杠杆 |
| **产品经理价值** | 经验等级 × 平台匹配度 × 智慧等级 | 评估与招聘产品经理 |

| **理性决策三要素** | 理性信念 > 理性目标 > 理性行动 | 提升决策质量的优先级排序 |
| **用户行为机制** | 情境→偏好认知→期望效用→行为→反馈 | 理解并预测用户决策路径 |

## 十、精选核心观点

- "**用户不是人，是需求的集合。**"——用需求而非自然人作为分析单位，才能准确定义产品边界和用户价值。

- "**企业以产品为媒介与用户进行价值交换，交换的不是产品，而是价值。**"——一切产品决策的终点是促成交换，不能促成交换的设计没有价值。

- "**产品是约束条件下的效用组合。**"——每个产品决策都是对效用组合的调整，必然有取舍。

- "**创造有利可图的用户价值。**"——用户价值和商业价值不是对立的，可持续的产品必须同时满足两者。

- "**自省是产品经理的第一潜力。**"——发现并承认自己的短处，才能学习、合作、雇用或回避，持续进化。

- "**产品经理是做权衡的，不是做设计或创意的。**"——互联网产品做大后是平台，需要经济学思维而非设计师思维。

- "**天下熙熙，皆为利来。**"——影响力来自为他人创造价值的能力，推动决策落地的核心是让对方理解这件事对他的价值。
