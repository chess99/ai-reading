# 以交易为生

## 全书框架：成功交易的三大支柱

埃尔德把交易成功的条件归纳为三个支柱，并以"铁三角"贯穿全书：

1. **心理**——个体情绪管理与群体心理认知
2. **技术**——识别趋势、把握反转的分析方法
3. **资金管理**——风险控制的铁三角

三者缺一不可，如同凳子的三条腿。大多数新手只关注技术，却忽视心理与资金管理，这是失败的根源。

---

## 第一支柱：心理

### 交易失败的心理根源

大多数人在市场中亏损，并非缺乏知识或资本，而是源于三类心理幻觉：

- **智力误区**：相信存在某种"秘诀"或"神奇系统"
- **资本不足误区**：认为只要本金更多就能成功（实为逃避承认资金管理缺陷）
- **自动交易误区**：试图让机械系统替代人类判断

**自毁倾向**是失败最深层的原因。许多交易者潜意识中存在自我毁灭的模式，他们在职业、个人生活和交易中反复踏进同一条错误的河流。识别自己的重复失败模式，是改变的前提。

### 从匿名戒酒会（AA）学来的方法

埃尔德认为，失败的交易者与酗酒者行为高度相似——否认问题、追逐下一次赌注、隐瞒损失。AA的康复原则对交易同样适用：

- **承认失控**：承认自己对亏损无能为力，是改变的第一步
- **一次一天**：目标是今天不额外亏损，而不是试图一次扭转所有损失
- **交易日志**：记录每次进出场的理由，寻找成功和失败的重复模式

每天早上在交易前大声说：「我是某某，我是个失败者，我有让账户亏损的倾向。」这种谦卑的仪式能帮助保持冷静，避免因自负而情绪化交易。

### 情绪化交易：最致命的敌人

交易者面对市场，面临情绪的"过山车"：连胜后误以为自己是天才，连亏后失去信心。两种极端都会毁掉交易生涯。

专业交易者的标志是：**胜不骄，败不馁**，专注于正确执行流程，而非在意单笔盈亏。

减少情绪干扰的实践原则：
- 减小仓位规模——感到紧张或不确定时，先缩减规模
- 建立书面交易计划，在未持仓时（最冷静时）制定规则
- 不在交易时间做决定；有计划地交易，或权衡性地制订计划

### 胜利者与失败者的区别

胜利者在思考、感受和行动上与失败者截然不同：
- 胜利者把每笔交易看作长期系列中的一个样本，不为单笔交易过于兴奋或沮丧
- 失败者把每笔交易当作生死攸关，情绪随价格剧烈波动
- 胜利者迅速承认错误并离场；失败者固执地等待"市场回头"

## 第二支柱：群体心理与市场分析

### 价格的本质

每个成交价格，都是所有市场参与者——买方、卖方和观望者——在某一时刻对价值达成的**暂时性共识**。价格图表是群体心理的镜子，技术分析本质上是**应用型社会心理学**。

市场大部分时间处于混沌，秩序与结构只是偶尔出现。个体交易者的核心优势：**无需每天交易**，可以耐心等待清晰的信号出现。

### 负和游戏中的生存法则

交易是负和游戏（扣除佣金和滑点后赢家所得少于输家所失）。仅仅"好于平均水平"不够，必须**出类拔萃**。

- **佣金**：选择最低佣金的经纪商，减少交易频率
- **滑点**：尽量用限价指令；只有止损时才用市价指令
- **买卖价差**：永远在对你不利的一侧成交，构成隐性成本

核心法则：详细记录每笔交易的滑点，平均滑点成本往往是佣金的三倍。

### 群体行为的规律

勒庞《乌合之众》揭示：个体加入群体后，智力下降、冲动上升、寻找领导者的需求增强。

市场群体的特点：
- **趋势**由强势力量驱动——跟随趋势，永远不要与之对抗
- **反转**发生在极端情绪之后——贪婪和恐惧的极点是转折的信号
- **恐惧**比贪婪强烈约3倍（卡尼曼研究），这解释了为何跌势速度约是涨势的2倍

交易者与市场群体相处的原则：尊重群众的力量，但不要害怕它；利用独立判断决定何时加入、何时离开。

## 第三支柱：技术分析核心工具

### 图表基础：价格柱的含义

每根价格柱（蜡烛）包含四个关键信息：

| 数据 | 含义 |
|------|------|
| 开盘价 | 业余者的情绪（隔夜积累的指令） |
| 收盘价 | 专业者当日交易的结果 |
| 最高价 | 多方当日最强力量 |
| 最低价 | 空方当日最强力量 |

**关键规律**：收盘价高于开盘价，专业者比业余者更看多；收盘价低于开盘价，专业者更看空。跟随专业者方向操作更有利。

### 支撑位与阻力位

支撑和阻力由交易者的**记忆、痛苦和悔恨**构成：
- 被套的多头在解套价附近卖出，形成**阻力**
- 错过买点的交易者等待回调，形成**支撑**

支撑/阻力强度取决于三要素：
1. **持续时间**——震荡越久越强（两年 > 两月 > 两周）
2. **价格区间高度**——密集区越高越强
3. **成交量**——成交量越大越强

假突破识别：价格短暂突破后迅速返回密集区——专业者喜爱假突破，可以逆向操作，在假突破点附近设置止损。

### 袋鼠尾（Kangaroo Tail）

由**单根异常长线柱 + 两侧普通线柱**组成，是少数埃尔德认为可信的图表信号：

- **向上袋鼠尾**：多方推高价格的努力失败，是做空信号
- **向下袋鼠尾**：空方打压价格的努力失败，是做多信号

操作原则：逆袋鼠尾方向交易，止损设在尾巴中间位置（非顶端，否则风险过大）。

## 计算机化技术分析：核心指标

### 指数移动平均（EMA）

EMA比简单移动平均更优越：为近期价格分配更大权重，且不会因去除旧数据而突变。

**最重要的信息是EMA的斜率方向**：
- EMA上升 → 趋势向上，可做多
- EMA下降 → 趋势向下，可做空
- EMA走平 → 无趋势，不用趋势跟随方法

**双EMA价值区间**：使用2:1比例的两条EMA（如26日/13日），价值"存在于"两线之间。在上升趋势中，价格回落到价值区间是买入机会；在下降趋势中，反弹到价值区间是做空机会。

常用参数：日线图用22日/11日或26日/13日，一年52周正好以26为基准。

### MACD线与MACD柱状线

**MACD线**（12日EMA - 26日EMA）是趋势跟随指标，快线穿越慢线给出买卖信号，但信号较滞后。

**MACD柱状线**（MACD线 - 信号线）是更强大的工具：

- 斜率向上 → 多方力量增强（比位置正负更重要）
- 斜率向下 → 空方力量增强
- **背离**是最强信号：
  - **牛市背离**：价格创新低，但MACD柱底部抬高 → 做多信号
  - **熊市背离**：价格创新高，但MACD柱顶部降低 → 做空信号

有效背离的必要条件：两个顶部/底部之间，MACD柱状线必须穿越0值线。

### 趋向系统（Directional System）

**ADX（平均趋向指标）**：
- ADX上升 → 主导力量增强，趋势可能持续
- ADX下降 → 趋势减弱，避免使用趋势跟随工具
- **ADX最佳信号**：ADX从两条趋向线下方反弹向上（从低于20反弹），新趋势开始

**+DI13 vs -DI13**：哪条线在上，哪方主导市场。

### 随机指标（Stochastic）与相对强弱指标（RSI）

两者都是震荡指标，在区间震荡市效果好，但在趋势中会发出危险的假信号。

核心用法（结合三重滤网）：
- 仅在长期趋势向上时，采用日线随机指标/RSI的**买入**信号
- 仅在长期趋势向下时，采用日线随机指标/RSI的**卖出**信号

背离是两者最强信号，超买/超卖次之。

### 强力指数（Force Index）

```
强力指数 = 今日成交量 × (今日收盘价 - 昨日收盘价)
```

**2日EMA（短期）**：在上升趋势中，2日EMA降至0以下时买入；在下降趋势中，2日EMA升至0以上时卖出。

**13日EMA（中期）**：确认中期多空力量的改变；与价格出现背离是重要趋势转折信号。

## 成交量分析

成交量反映交易者的情感投入程度：

| 情形 | 含义 |
|------|------|
| 上涨 + 成交量增加 | 确认趋势，可继续持仓 |
| 上涨 + 成交量萎缩 | 燃料不足，趋势将反转 |
| 下跌 + 成交量暴增 | 恐慌性抛售，底部可能临近 |
| 下跌 + 成交量萎缩 | 抛压耗尽，跌势接近尾声 |

经验法则：**今日成交量高于昨日，则今日趋势更可能持续。**

下跌中的成交量暴增比上涨中的成交量暴增更可能意味着反转（恐惧比贪婪消退更快）。

## 市场指标

### 新高-新低指数（NH-NL）

被埃尔德视为**最佳股市领先指标**：
```
NH-NL = 当日创年内新高股票数 - 当日创年内新低股票数
```

主要信号：
- NH-NL创新高：市场领导者强大，买入持仓安全
- NH-NL下降同时价格新高：**熊市背离**，趋势即将终结
- 周度NH-NL跌破 -4000 后反弹：**"尖峰"买入信号**，极为强力
- 周度NH-NL升到 +2500 以上：确认牛市

## 三大交易系统

### 三重滤网交易系统

核心原则：**多时间周期联合分析**，时间周期比例约为5倍。

**第一重滤网（战略决策）**：
- 分析**长期图表**（如周线）的趋势跟随指标（EMA/动力系统）
- 确定方向：只允许顺趋势操作
- 周线EMA或动力系统显示牛市 → 只允许买入或观望
- 周线EMA或动力系统显示熊市 → 只允许卖出或观望

**第二重滤网（战术决策）**：
- 分析**中期图表**（如日线）的震荡指标（强力指数/随机指标/RSI）
- 寻找与长期趋势相反的短期调整作为入场机会
- 周线向上 + 日线2日强力指数降至0以下 → 买入机会
- 周线向下 + 日线2日强力指数升至0以上 → 做空机会

**第三重滤网（精确入场）**：
- 使用平均EMA下跌穿透法：在EMA减去平均穿透值的位置挂限价单
- 或用前一日高点上方一个最小报价单位挂买入指令（每日跟踪调整）

**止盈止损设置**：
- 盈利目标：在长期图表的价值区间（双EMA之间）
- 止损：在中期图表的近期极值附近

### 动力系统（Impulse System）

结合**EMA斜率**（惯性）和**MACD柱状线斜率**（能量）：

| 颜色 | 条件 | 含义 |
|------|------|------|
| **绿色** | EMA上升 + MACD上升 | 牛市全力推进，禁止做空 |
| **红色** | EMA下降 + MACD下降 | 熊市全力推进，禁止买入 |
| **蓝色** | 两者方向相反 | 中性，无限制 |

动力系统是**监测系统而非信号系统**：它告诉你不该做什么，而非该做什么。周线/日线任何一个显示红色，禁止买入；任何一个显示绿色，禁止做空。

### 通道交易系统

通道 = 以EMA为中心的两条平行线，包含过去100根K线中约95%的价格数据。

核心规则：
- **永远不要在上通道线之上买入**
- **永远不要在下通道线之下卖出**
- 最佳买入：价格回落到价值区间（双EMA之间）+ 指标背离
- 最佳做空：价格反弹到上通道线 + 熊市背离

## 资金管理：风险控制铁三角

### 2% 规则（核心铁律）

**单笔交易的最大风险不超过账户总资产的2%**。

若账户有30000美元，单笔最大风险 = 600美元。

这意味着即使连续亏损10笔，账户仅损失约18%，仍有翻本的机会。允许交易者在"一连串错误"中生存下来。

### 6% 规则（月度止损）

**当月亏损达到账户总资产的6%时，停止当月所有交易。**

目的：防止在状态不佳时持续交易，避免"越亏越赌"的恶性循环。

### 头寸规模计算

```
头寸规模 = 最大允许亏损金额 ÷ 每股（张）止损金额
```

例：账户10万，最大风险2%=2000元，股价50元，止损设在48元（差2元），则头寸 = 2000 ÷ 2 = 1000股。

头寸规模由风险控制决定，而非"感觉"。

### 止损设置原则

- **保护性止损**：进场时立即设置，不要等"看看走势"
- **禁止在整数价位设置止损**（积聚大量止损单）
- 止损位要超出"市场噪音"范围（至少1倍ATR距离）
- **绝不移动止损单使风险扩大**；可以顺趋势方向移动以保护盈利

### 盈亏比要求

潜在收益 : 潜在风险 > 2:1。若不满足，放弃该笔交易。

## 实践细节

### 交易日志：成功的基础

交易日志质量是交易成功最好的预测指标。记录内容应包括：
- 每次买入/卖出的价格、日期
- 滑点、佣金实际成本
- 入场理由、预期目标、止损位
- 最大浮盈、最大浮亏
- 入场前后的图表截图（"购买前和购买后"）

定期回顾日志，寻找成功和失败的重复模式。**不会向历史学习的人注定重复历史。**

### 交易时机的选择

- **波段交易**（持仓数日至数周）：最推荐初中级交易者，学习曲线最佳
- **长期投资**（持仓数月至数年）：需要极强的耐心，中途可能经历50%以上的回撤
- **日内交易**：节奏最快，需要最高水平的纪律和精力集中，不适合初学者

新手规则：**先成为能持续盈利的波段交易者，再考虑日内交易。**

### 选股原则

- 关注股票池规模：个位数到几十只，可管理即可
- 只选**日均成交量超过100万股**的品种（保证流动性）
- 波动性要足够（参考贝塔值）
- 建立"扫描器"寻找背离、假突破等模式
- 每周末复盘自选股，进行下周计划

## 交易工具的选择

### 股票的优势

- 容易理解，基本面可分析
- 无到期日压力
- 可充分利用个人交易者"等待最佳时机"的优势（机构必须交易）

### 期权的核心认知

**买入期权是失败者的游戏**（概率约1/3），**卖出期权是专业者的游戏**（概率约2/3）。

期权卖方策略要点：
- 卖出深度虚值期权（Delta值不超过0.1）
- 到期前2~3月开始卖出，利用时间价值加速衰减
- 亏损超过权利金100%时立即止损平仓
- 建立"保险账户"：每笔盈利的10%存入，应对极端事件

### ETF的隐患

ETF的追踪误差、管理费用和"二级市场"劣势使其对个人交易者并不友好，尤其是：
- 带杠杆的ETF长期持有必然亏损
- 商品/波动率ETF常常无法准确追踪标的

仅常见的大型指数ETF（如SPY、QQQ）相对可靠。

### 期货的特点

高杠杆是双刃剑：拙劣的资金管理是期货交易者失败的真正原因，而非期货本身。套期保值者（商业用户）是期货市场中记录最好的群体，跟随其方向有利可图。

## 核心行为准则

埃尔德给出的成功交易者行为清单：

1. 把交易视为至少20年的长期事业
2. 不贪不急——市场永远存在，等待清晰信号
3. 培养"如果A发生，则B可能发生"的多维分析框架
4. **先建立资金管理计划**，生存优先于盈利优先于高额利润
5. 承认自己是交易系统中最薄弱的环节
6. 用匿名戒酒会原则克制情绪化交易冲动
7. 探索自己内心，驱赶幻觉，改变思考方式

成功需要的不是更多资本、更好系统或更多知识，而是**动力、知识与自律的结合**，其中自律最为关键。
