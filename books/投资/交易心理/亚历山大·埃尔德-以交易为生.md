# 以交易为生

## 核心框架：成功交易的三大支柱

成功交易依赖三个相互支撑的支柱：**心理**、**市场分析**、**风险管理**。缺少任何一个，交易者必然亏损出局。大多数人只关注技术指标，却忽略心理和风险管理——这正是失败的根源。

第四个要素是**交易记录**，它把前三个支柱联结起来，是自我提升的唯一可靠工具。

## 第二支柱：市场分析（技术分析）

### 价格、价值与通道

**核心概念**：价格与价值不同。数学家曼德博的研究结论——"价格围绕价值上下波动"——构成通道交易的理论基础。

两条指数移动平均线（EMA）之间的区域称为**价值区间**：
- 长期 EMA（如26日）代表长期价值共识
- 短期 EMA（如13日）代表短期价值共识
- 两者之间是合理买卖区域

**通道线**平行于长期 EMA，涵盖过去100根K线中约95%的价格数据。价格触及下通道线是低估信号，触及上通道线是高估信号。严格原则：**永远不在上通道线之上买入，也不在下通道线之下卖出**。

### 指数移动平均（EMA）

EMA 为最新价格分配更大权重，不会因旧数据剔除而产生跳变。

**交易规则**：
- EMA 上升时，在价格回调到均线附近买入
- EMA 下降时，在价格反弹到均线附近做空
- EMA 走平小幅震荡时，不使用趋势跟随方法

### MACD 与 MACD 柱

MACD 线 = 12日 EMA 减 26日 EMA；信号线 = MACD 线的9日 EMA。
MACD 柱 = MACD 线 - 信号线。

**MACD 柱的斜率方向比正负更重要**：
- 柱线上升（即最新柱高于前一柱）→ 多头力量增强 → 买入信号
- 柱线下降 → 空头力量增强 → 卖出信号

**背离信号**（最强烈的技术信号之一）：
- **牛市背离**：价格创新低，MACD 柱底部比前次浅，两个底部之间曾穿越零线 → 强烈买入信号
- **熊市背离**：价格创新高，MACD 柱顶部比前次低，两个顶部之间曾穿越零线 → 强烈卖出信号

注意：两个顶部或底部之间若未穿越零线，不构成真正背离。

**"巴斯克维尔猎犬"信号**：出现完整背离形态，但市场未向预期方向运动 → 说明底层有更强的力量，准备迎接一波大趋势。

### 动力系统（Impulse System）

动力系统结合 EMA 斜率（惯性）和 MACD 柱斜率（能量）：
- **两者同时上升 → 绿色**：牛市主导，禁止卖空
- **两者同时下降 → 红色**：熊市主导，禁止买入
- **方向相反 → 蓝色**：中性，无禁止

动力系统是**监测系统而非交易系统**：它不告诉你该做什么，只告诉你不该做什么。严禁违背其禁令。

### 三重滤网交易系统

解决不同时间周期信号相互矛盾的问题。相邻时间周期之间约为5倍关系（月→周→日→小时→分钟）。

**操作流程**：
1. **第一重（战略级）**：选定偏好的时间周期后，先看大一级的周期图（如先看周线图再看日线图），用趋势跟随指标（动力系统/EMA）确定大方向，只允许顺大趋势方向交易。
2. **第二重（战术级）**：回到偏好时间周期图，用震荡指标（强力指数/随机指标/RSI）在逆大趋势方向的短期波动中找入场点——即周线上涨时，等待日线回调时买入。
3. **第三重（入场技术）**：利用更短周期或"平均穿透值"法，在 EMA 下方一个平均回调幅度处挂限价买单，避免追涨。

**止损与止盈**：用长期图设定止盈目标（通常为价值区间或上通道线），用中期图设定止损位。

### 支撑与阻力

支撑和阻力的存在依赖于交易者的**记忆、痛苦与悔恨**。在密集成交区，被套的多头和错失机会的空头都会在特定价位形成强烈的买卖意愿。

支撑/阻力强度的三个因素：
1. **时间长度**：震荡持续越久，支撑/阻力越强
2. **价格高度**：成交密集区越高，力量越大
3. **成交量**：成交量越大，感情投入越深，支撑/阻力越强

阻力被突破后转化为支撑，反之亦然。**假突破**是专业交易者最爱的信号：价格冲出后迅速返回区间内，意味着突破失败，往往引发反向运动。

### 袋鼠尾（手指线）

从密集成交区突破的单根超长 K 线，两侧被普通线柱包围。向上的袋鼠尾标志多方攻顶失败，是卖出信号；向下的袋鼠尾标志空方突袭失败，是买入信号。

操作：逆袋鼠尾方向交易，止损设在尾巴的中间位置（非末端）。

### 成交量与持仓量

**成交量**反映市场参与者的情绪投入程度——越大代表越多输家正在痛苦中。

关键规律：
- 成交量随上涨趋势增加 → 趋势确认
- 上涨中成交量萎缩 → 趋势将反转
- 下跌中成交量暴增 → 恐惧爆发，空方精疲力竭，底部临近
- 成交量在趋势中骤降 → 输家供给减少，趋势将反转

**持仓量**（期货/期权）：
- 持仓量增加 → 多空分歧扩大，确认现有趋势
- 持仓量减少 → 输家离场，赢家获利了结，趋势接近尾声

### 市场指标

**新高-新低指数**（NH-NL）= 创年内新高股票数 - 创年内新低股票数

这是股票市场最佳先行指标。长官的动向先于士兵：当主要指数上涨但 NH-NL 走低，说明领涨股票数量减少，牛市暗藏裂缝。

关键信号：
- **周度 NH-NL 跌破 -4000 后反弹** → 极度恐慌后的买入信号，罕见但极可靠
- **周度 NH-NL 升至 +2500 以上** → 确认牛市
- 价格创新高但 NH-NL 创次高 → 熊市背离，卖出预警

## 第三支柱：风险管理

### 两种最致命的错误

1. **不设止损**：将账户暴露在无限损失中，"鲨鱼的一击"随时可以摧毁账户
2. **过度交易**：相对账户持有过大仓位，如同在小船上装大帆

### 2% 原则（防鲨鱼）

**单次交易最大风险不超过账户总资产的2%**。

这不是交易规模，而是**入场点到止损点距离×股数**不超过账户的2%。

操作示例（账户5万元，2% = 1000元）：
- 计划以40元买入，止损38元，每股风险2元
- 最大可买手数：1000 ÷ 2 = 500股

**风险控制的铁三角**：
- A = 最大可承受风险额（账户的2%以内）
- B = 入场价与止损价之差（每股风险）
- C = A ÷ B = 最大可交易股数（不可超过）

专业交易者往往将单次风险控制在0.5%~1%以内，2%是上限而非目标。

### 6% 原则（防食人鱼）

**当月已实现亏损 + 当前所有持仓的风险暴露之和不超过月初账户的6%**，否则本月剩余时间停止开新仓。

这一规则强制你在连续亏损时暂停，保住主体资金，以便下月重新开始。

逻辑：好的交易者在盈利时可增加持仓（已盈利头寸的止损移至成本线以上，释放风险额度）；亏损时被强制减仓、直至停战。

### 止损的艺术

**永远使用止损**。止损是痛苦的，但没有止损会更痛苦。

**尼克止损法**：不把止损放在最低点（最高点）附近（那是止损单最密集处，最易被触及），而是放在**次低点（次高点）**附近。逻辑：若价格跌至次低点附近，大概率会继续跌穿最低点；此时尼克止损已出场，避开了那个密集的止损雷区。

**灾难性止损**：无论是否使用软止损，每笔交易都必须向经纪商下达一个硬止损指令——这是账户的最后防线。就像皮划艇上的救生衣，希望永远不用，但必须有。

**止损原则**：
- 不把止损设在整数价位（那是止损单扎堆的地方）
- 把止损设在市场噪声区域之外（至少一倍平均真实波幅 ATR）
- 只顺着交易方向移动止损线，永远不要"给更多空间"来拖延损失

### 从下降中恢复

连续亏损后，不是加大仓位追回，而是**缩小规模**：从正常规模的20%开始，连续两周盈利后增加20%，亏损时退回前一档。

更高的风险妨碍交易水平——这不是胆怯，而是科学。在桌面上走钢丝和在十层楼顶走钢丝需要的技术相同，但后者的风险会彻底摧毁表现。

## 交易实践细节

### 交易类型与时间周期

| 类型 | 持仓时间 | 特点 |
|------|---------|------|
| 长线投资 | 月/年 | 需要极强定力，回撤可达50%以上 |
| 波段交易 | 日/周 | 推荐初中级交易者，风险可控，学习曲线快 |
| 日内交易 | 分钟/小时 | 要求极高，不设时间思考，新手勿进 |

**建议**：先从波段交易开始，掌握后再考虑日内。相邻时间周期约为5倍，三重滤网原则适用于所有级别。

### A级交易标准

每次下单前问自己："这是一笔A级交易吗？"

A级交易的标准：
- 符合既定交易系统（不接受随机想法驱动的交易）
- 技术阿氏评分（5项指标，每项0/1/2分）总分7分以上，且无0分项
- 潜在盈利与风险之比至少为2:1
- 通道线评级达到30%以上（即盈利超过通道高度的30%）

一旦明确了A级交易的样子，把它打印出来贴在屏幕旁。只交易符合这个形态的机会。

### 盈利目标的设定

波段交易的三个合理盈利目标（按优先级）：
1. **移动平均线附近**（价值区间边界）
2. **通道线**（正常波动上限）
3. **前期支撑/阻力位**

"足够"是关键词。一次又一次达到"足够"，长期下来会有卓越的成果。不要贪图更大的利润而持仓过久，增加不确定性。

### 交易记录系统

**每日功课**（15分钟）：每天开盘前系统检查远东、欧洲市场，关键经济数据，主要货币/商品，新高-新低指数，VIX，标普500指数的动力系统状态。

**自我心理测试**（30秒，5题）：身体状况、昨日交易结果、计划完成度、情绪状态、日程安排。总分4分以下：不交易；5-6分：小心交易；7-8分：正常交易；9-10分：警惕过度自信。

**交易日志三要素**：
1. 完成每日功课（纪律的第一步）
2. 写下交易计划（入场、目标、止损、规模）
3. 执行并复盘（含"两个月后"回顾）

**交易评级公式**：
- 买入评级 = （当日最高价 - 买入价）/（最高价 - 最低价）
- 卖出评级 = （卖出价 - 当日最低价）/（最高价 - 最低价）
- 综合交易评级 = （卖出价 - 买入价）/ 通道线高度 ≥ 30% 为A级

每笔交易结束两个月后，找出当时的图表，用箭头标注入场点和退出点，写下评价。这是最有价值的自我学习方式。

## 交易工具的选择

**股票**：最适合入门，流动性好，信息透明。建议只选日均成交量超过100万股的品种。

**ETF**：表面便利，但暗藏缺陷——追踪误差、管理费用、一级市场对散户不利。只有标普500（SPY）、纳指（QQQ）等最常见品种尚可接受。

**期权**：买入期权是失败者的游戏，卖出期权是专业者的游戏。买入者只有约1/3的概率获利，卖出者有约2/3的概率获利（时间衰减始终对卖出者有利）。期权策略的本质是卖出"不可能实现的希望"。

**期货**：杠杆使收益和风险双双放大。对有严格资金管理的交易者是极好的工具，但新手使用必然爆仓。首先必须掌握资金管理，再考虑期货。

**外汇**：零售外汇经纪商是你的对手方，不是代理人。推荐使用外汇期货替代，后者的经纪商是为你工作的中间人。

## 核心心法总结

1. **市场是一个由竞争者组成的群体**，每一美元的利润都来自其他交易者的口袋。

2. **情绪是最大的敌人**：恐惧和贪婪驱使人们在最高点买入、最低点卖出。专业者做反向操作，但不是盲目逆向，而是在有客观指标支撑时逆群体情绪。

3. **止损是生存的保证，不是失败的标志**。止损出局后市场反转是常见现象，但如果每次都因为这种可能而不止损，终有一次会遭遇毁灭性亏损。

4. **简单胜于复杂**：最好的交易系统只有少数几个要素。指标越多并不代表信息越多，因为它们基于相同的五个数据（开、高、低、收、量）。只选择自己深度理解并信任的少数指标。

5. **成为自己的经理**：机构交易员表现好于个人交易者，核心原因是有外部经理强制执行纪律。个人交易者没有这个约束，必须自律——2%原则和6%原则就是自我约束的制度工具。

6. **交易记录是唯一的成长路径**：不记录就无从学习；不复盘就无从改进。保持详尽的交易日志是所有成功交易者的共同特征。
