# PWA 方向、阅读位置与更新

## 屏幕方向

安装后的应用允许系统支持的全部方向（`orientation: any`），遵循用户的系统旋转设置。横竖屏切换、窗口或正文尺寸变化时，阅读页按段落文字及段内比例恢复位置，不复用重排前的滚动高度。

## 更新交互

- 当前文章或应用功能有变化：显示非阻塞更新提示，用户可选择更新或稍后处理。阅读过程中不自动刷新。
- 选择稍后后，同一页面不重复提示相同版本；设置中的“检查更新”可重新唤出提示。
- 只有其他书籍或主题变动：不打断正在阅读的文章，在首页、书库等页面提示书库更新。
- 页面显示后、回到前台、网络恢复及前台每五分钟检查一次；一分钟内的重复检查合并。版本检查直接读取网络，不依赖 worker 内存或后台长驻定时器。
- 用户选择更新后，先下载并缓存当前页面；成功后激活等待中的 worker，再保存阅读锚点并刷新。下载或激活失败时保留页面并提供重试。
- 阅读锚点只存入当前会话，刷新后使用一次，十分钟过期。如果新版删除或改写了目标段落，优先回到其所属章节；章节也不存在时才回退至滚动位置。
- 从搜索结果进入后继续阅读，主动更新时优先恢复当前段落，保留搜索高亮，不重新跳回原命中位置。
- 新进入的页面在线优先读取网络，已有缓存时网络超过四秒先显示缓存；离线继续显示已缓存页面。带内容指纹的 Next 静态资源优先使用缓存。

构建清单分别记录应用代码、书库内容及各篇文章的版本，页面输出对应版本标识，用于比较当前已经显示的内容。检查更新不会替换当前正文。

## 验证

自动测试覆盖更新分类、worker 等待与主动激活、在线新内容与离线缓存、更新失败及段落重排恢复。发布前还需检查生产构建中的旋转、主动刷新恢复、更新提示与离线行为。

手机实机应额外验证已安装 PWA 的方向设置：安装元数据由浏览器管理，已有安装取得新 manifest 的时间因平台而异；普通页面刷新不等同于安装元数据已更新。

参考：[Chrome 更新交互](https://developer.chrome.com/docs/workbox/handling-service-worker-updates)、[manifest 更新规则](https://web.dev/articles/manifest-updates)、[屏幕方向设置](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/orientation)。
