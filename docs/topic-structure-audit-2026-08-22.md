# 主题结构审计表（2026-08-22）

本审计针对当前 74 个主题，目标不是追求更少或更多主题，而是检查历史上 `5-6 / 7-8 / 9-10`、`超过 10 本就拆`、以及“太薄就合并”等数量口径是否造成结构扭曲。

当前判断遵循 `docs/topic-curation-policy.md`：**书单长度是策展结果，不是策展输入**。是否拆分只看读者目标是否独立、是否需要自己的入口与框架；是否合并只看后一页是否实际上只是前一页的天然阶段或重复路径。

## 最高优先级结构调整

1. **合并 `如何处理亲密关系中的冲突` → `亲密关系阅读路径`**：7 本中 5 本重复，而且历史计划自己已经写明冲突页应先作为内部章节。
2. **合并 `如何验证产品机会` → `产品从 0 到 1`**：机会验证就是 0→1 的前半段，7 本中 5 本重复；历史计划同样要求先不单独发布。
3. **合并 `数字公共生活与信息网络` → `如何理解媒体、舆论与公共讨论`**：两页 7 本中共享 6 本，正文问题几乎相同。合并后建议题名升级为 `媒体、信息网络与公共讨论`。
4. **拆分 `如何理解交易、周期与市场风险`**：前半完整是交易系统/交易心理，后半完整是周期/宏观风险，两类读者可以彼此独立完成目标。
5. **拆分 `如何理解商业竞争、战略与平台效应`**：前半是竞争战略，后半是平台/网络效应。V8 原本就是两页，V9.2 仅因“页面太薄”合并；取消最低书数后，恢复两条路径更自然。
6. **拆分/迁移 `如何理解儿童安全感与教育成长`**：前半是依恋与儿童发展，后半是学习科学与家庭阅读，已经是两套框架。建议形成 `儿童安全感与发展`，教育学习部分再与父母主题一起策展为 `家庭学习与教育环境` 或并入现有父母页。

## 专项深读层级

建议保留以下页面，但在信息架构上显示为总览主题的专项/进阶路径：

- `理解焦虑与抑郁` → 位于 `如何理解情绪` / 心理健康路径之下。
- `如何做好产品发现` → 位于 `产品从 0 到 1` 之下。
- `看懂平台、算法与注意力风险` → 位于 `技术社会读什么` 之下。
- `如何读懂痛苦、自由与意义` → 位于 `人生哲学入门` 之下。
- `如何理解压力、恢复与身体信号` → 位于 `如何建立健康生活方式` 之下。

专项深读不是降级为“可有可无”，而是明确告诉读者：这是总路径中的一个可独立深入的分支。

| 如何理解运动与体能 | **保留** | 训练、动作、力量、耐力与生理学是独立专业路径。 |
| 如何理解饮食与代谢 | **保留但重构** | 结构成立，但证据风险高；应以教材/共识证据为主干，把《肥胖代码》《深度营养》等明确放到争议/对照位置。 |
| 面对衰老、疾病与照护 | **保留但重构** | 与哀伤死亡共享多本，但读者目标是衰老、医疗选择与照护。应增加老年医学/照护决策，降低睡眠、运动、意义类通用书的核心权重。 |
| 如何理解环境、气候与可持续生活 | **保留** | 环境危机、增长边界、农业、气候经济与公共资本构成独立系统问题；虽跨领域，但无需因归类问题拆分。 |

## 对历史数量规则的总体判断

历史规则并没有把 74 个主题普遍“拆坏”。相反，V9.2 已经主动合并过一批确实过碎的主题，例如写作/创意、公司经营/商业模式、消费主义/财富阶层，并且把 AI 实用变革与 AI 风险治理正确拆开。

真正遗留的问题主要有三类：

1. **为了避免单页超过上限，把天然阶段做成了独立主题。** 典型是亲密冲突、产品机会验证。
2. **为了避免页面“太薄”，把两个本来独立的目标硬合在一起。** 典型是商业竞争战略 + 平台网络效应；交易 + 周期风险也有类似问题。
3. **为了领域覆盖和主题对称，在不同一级领域复制了几乎同一条路径。** 典型是媒体公共讨论 vs 数字公共生活。

因此后续不应做“大合并”或“大拆分”。正确做法是逐项按读者目标校正，并允许主题数量自然变化。

## 建议实施顺序

### 第一批：纯结构修复

不需要先大规模补书，优先解决最明显的重复/层级错误：

- 合并亲密冲突。
- 合并产品机会验证。
- 合并媒体公共讨论 / 数字公共生活。
- 把 5 个专项深读建立父子层级。

### 第二批：拆开被硬粘在一起的主题

- 交易系统与交易心理 / 周期与市场风险。
- 商业竞争与战略 / 平台与网络效应。
- 儿童安全感与发展 / 家庭学习与教育环境（第二条是否单独成页，先重新策展后决定）。

### 第三批：保留但重构的 11 个主题

重点不是删页，而是让相邻主题真正长得不一样：

- 成瘾、自控与意义重建
- 如何建立长期职业资本
- 如何建立领导力与团队协作
- 建立财务常识
- 普通人如何长期投资
- 如何理解行为经济学与金钱心理
- 中国社会的现代转型
- 如何理解文明兴衰
- 如何理解国际秩序与地缘风险
- 如何理解饮食与代谢
- 面对衰老、疾病与照护

## 审计结论

这次审计最重要的结果不是“应该剩几篇”。即便把 3 个重复页合并、再把 3 个混合目标拆开，主题总数甚至可能碰巧接近原来的数量；这只是结果，不是目标。

以后判断一个主题是否存在，只问两件事：

- **读者能不能用一句明确的问题进入它？**
- **它是否有一条区别于相邻主题、可以自洽完成的学习路径？**

如果答案都是“是”，4 本或 14 本都可以独立存在；如果答案是否定的，哪怕正好 7 本，也不应该为了表格整齐保留。
