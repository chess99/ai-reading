# 微信小程序方案暂停说明

## 结论

暂时暂停小程序版本。

当前分支保留了一版“小程序原生入口 + WebView 打开 Web 详情页”的原型，但它不适合个人主体小程序上线：个人小程序后台没有业务域名配置入口，因此无法使用 `web-view` 承载 `read.cearl.cc` 的书籍详情页。

## 已验证限制

- 个人主体小程序不能按当前方案配置 `web-view` 业务域名。
- 没有业务域名时，小程序无法通过 `web-view` 打开 Web 版书籍详情。
- 因此当前原型只能作为工程备份或后续迁移到非个人主体小程序时的参考，不能作为个人小程序上线方案。

## 当前分支保留内容

- `miniprogram/`：原生小程序壳层，包含首页、搜索、书库、设置和 WebView 页面。
- `miniprogram/scripts/build-catalog.mjs`：从 `books/`、`topics/` 生成轻量 catalog。
- Web 端 `?miniapp=1` 嵌入模式：用于隐藏导航栏、底部导航和设置弹窗，方便 WebView 内阅读。

## 后续若重启

可选方向：

1. 使用非个人主体小程序，配置 `read.cearl.cc` 为业务域名，继续 WebView 方案。
2. 改成原生详情页，并通过内容分包或远程内容接口承载书籍正文。
3. 放弃小程序，只继续优化 Web SEO、微信分享卡片和公众号/社群入口。

当前建议：先不继续投入小程序实现。
