# 移动端导航重构设计规格

**日期**：2026-05-21  
**状态**：待实现  
**范围**：移动端（< 768px）导航架构重构；桌面端不动

---

## 背景与目标

### 问题

- 移动端唯一的「回首页」入口是顶部 Logo 文字点击，不明显
- 汉堡菜单触发的侧边抽屉是主要导航，但操作路径深（点开 → 找分类 → 展开 → 点书）
- 全文搜索（/search）和标题搜索（侧边栏/首页）是两个分散入口
- 设置是 Header 图标触发的 Dialog，藏在顶栏角落

### 目标

- 任意页面一键回首页
- 书库浏览、搜索、设置有清晰固定的入口
- 桌面端现有侧边栏体验完全不变

---

## 决策记录

| 问题 | 决策 | 理由 |
|---|---|---|
| 借鉴微信读书沉浸式隐藏导航？ | 不借鉴 | 书摘内容短（2000–5000字），非长篇小说，无需最大化阅读空间 |
| 底部 Tab Bar 响应式到桌面？ | 不响应式 | 底部导航是移动拇指热区设计，桌面侧边栏更优，业界标准双轨 |
| 搜索合并？ | 合并为单页 + 两 Tab | 一个入口降低认知负担，书名/正文 Tab 对应两套引擎 |
| 标签云保留？ | 移除独立标签云 | 与分类树高度重叠，库规模（174本）不足以产生有价值的跨类发现 |
| 标签本身保留？ | 保留为书籍页可点击 chip | 点对点横向导航有价值，不需要专属页面 |
| 书籍页底部导航？ | 常驻可见 | 用户已决定不做沉浸隐藏，底部 Tab 始终可用 |

---

## 导航架构

### 移动端（< 768px）：底部 Tab Bar

```
┌─────────────────────────────┐
│  顶部 Header（精简）          │
├─────────────────────────────┤
│                             │
│  页面内容区                   │
│                             │
├─────────────────────────────┤
│  🏠首页  📚书库  🔍搜索  ⚙️设置  │  ← 新增 BottomNav 组件
└─────────────────────────────┘
```

### 桌面端（≥ 768px）：维持现状

- 左侧 Sidebar 始终可见（文件/搜索/标签三 Tab）
- Header：汉堡菜单 + Logo + 设置图标
- BottomNav 不渲染（`hidden md:hidden` 或条件渲染）

## 页面设计

### 1. 首页（`/`）

**变化**：
- 内容完全不变（继续阅读 + 最新上架 + 浏览分类）
- 移动端 Header：`AI 阅读`（居中或左对齐），去掉汉堡菜单，设置图标仅桌面端显示
- 底部 Tab Bar 出现，🏠 首页高亮

### 2. 书库（`/library`）— 新增路由

**内容**：原侧边栏「文件」Tab 的完整文件树，升级为全页面

```
Header: 书库  |  [174本]
─────────────────────────
🔍 搜索书名、作者...（即时过滤，仅过滤树节点）

▶ 投资  48本
▼ 个人成长  9本
  • 10倍比两倍更容易
  • 认知觉醒
  • 最小阻力之路
▶ 心理学  12本
▶ 哲学  2本
...

─────────────────────────
🏠  📚  🔍  ⚙️
```

**交互**：
- 分类可展开/折叠（复用现有 Sidebar 逻辑）
- 顶部快速搜索框：即时过滤树节点（仅过滤，不跳转搜索页）
- 点击书籍跳转书籍页
- 自动定位当前书籍（复用 `autoReveal` 逻辑）

**实现**：提取 Sidebar 文件树部分为独立组件 `BookTree`，在 Sidebar 和 LibraryPage 中共用

### 3. 搜索（`/search`）— 升级现有页面

```
Header: 搜索
─────────────────────────
[🔍 搜索书名、作者、内容...]

[书名]  [正文]   ← Tab 切换

书名 Tab（默认）：
  即时匹配，结果展示书名 + 作者 + 分类标签

正文 Tab：
  Pagefind 全文索引，结果展示书名 + 摘录高亮
─────────────────────────
🏠  📚  🔍  ⚙️
```

**交互**：
- 两个 Tab 共用同一个输入框，切换 Tab 时保留输入内容重新搜索
- 书名 Tab 为即时搜索（无需回车）
- 正文 Tab 复用现有 Pagefind 逻辑
- SearchPage 需读取 URL 参数：`?q=<keyword>` 预填搜索词，`?tab=books|fulltext` 切换到指定 Tab（供书籍页标签 chip 跳转使用）

### 4. 设置（`/settings`）— 新增路由

**内容**：将现有 `SettingsDialog` 内容迁移到独立页面，结构不变

```
Header: 设置
─────────────────────────
离线阅读
  [离线模式]  开关
  已缓存：23 / 174 本

存储管理
  [清除所有缓存]

关于
  AI 阅读 · 174本书 · GitHub
─────────────────────────
🏠  📚  🔍  ⚙️
```

**实现**：`SettingsDialog` 组件内容提取为 `SettingsContent`，在 Dialog（桌面）和 Page（移动）中共用

### 5. 书籍页（`/books/[slug]`）— 改造顶部

**Header 变化**：

```
移动端前：  ☰  |  AI 阅读（可点击）  |  ⚙️
移动端后：  ← 返回  |  书名（截断）  |  📤 分享
```

- `← 返回`：`window.history.length > 1 ? router.back() : router.push('/')`，有历史则回退，无历史（直接打开书籍页）则回首页
- 书名居中，最大宽度截断加省略号
- 分享图标：复用现有 Web Share API 逻辑，从 FAB 移到顶栏

**FAB 变化**：
- 移除分享 FAB（移到顶栏）
- 保留目录（☰）FAB
- FAB 仍仅移动端显示

**底部 Tab Bar**：常驻，无高亮（当前不在任何 Tab 页）

**标签 chip**：书籍页底部显示可点击标签，点击跳转 `/search?q=<tag>&tab=books`

## 组件变更清单

### 新增

| 组件 | 路径 | 说明 |
|---|---|---|
| `BottomNav` | `components/BottomNav.tsx` | 底部导航，4 Tab，`md:hidden` |
| `BookTree` | `components/BookTree.tsx` | 从 Sidebar 提取的文件树，供 Sidebar + LibraryPage 共用 |
| `SettingsContent` | `components/SettingsContent.tsx` | 从 SettingsDialog 提取的设置内容 |

### 新增页面

| 路由 | 文件 | 说明 |
|---|---|---|
| `/library` | `app/library/page.tsx` + `library-client.tsx` | 书库全页 |
| `/settings` | `app/settings/page.tsx` | 设置全页（移动端） |

### 改造

| 组件/文件 | 变化 |
|---|---|
| `Header.tsx` | 重构 props：新增 `mode: 'home' \| 'book'`、`bookTitle?: string`；`home` 模式移动端隐藏汉堡和设置图标；`book` 模式显示 ← 返回 + 书名 + 分享 |
| `BookLayout.tsx` | 分享按钮从 FAB 移到 Header；FAB 仅保留目录 |
| `app/books/[slug]/page-client.tsx` | 传书名给 Header；点击标签跳转搜索 |
| `app/search/search-client.tsx` | 加书名/正文 Tab，整合即时标题搜索 |
| `app/layout-client.tsx` | 挂载 BottomNav；Sidebar 外层加 `<div className="hidden md:block">`，移动端完全不渲染（移除 `sidebarOpen` 状态和汉堡触发逻辑） |
| `SettingsDialog.tsx` | 内容提取为 `SettingsContent`，Dialog 壳保留供桌面使用 |

### 不变

- 桌面端 Sidebar（含三 Tab：文件/搜索/标签）
- 桌面端 Header（汉堡 + Logo + 设置图标）
- 所有书籍内容、阅读历史、PWA/离线逻辑
- 路由 `/search` 复用（升级）

## 路由与导航行为

```
首页  /             ← 🏠 Tab
书库  /library      ← 📚 Tab（新增）
搜索  /search       ← 🔍 Tab（升级）
设置  /settings     ← ⚙️ Tab（新增）
书籍  /books/[slug] ← 无 Tab 高亮，顶部 ← 返回
```

**`← 返回`** 行为：`router.back()`

- 从首页点书 → 书籍页按返回 → 回首页 ✓
- 从书库点书 → 书籍页按返回 → 回书库 ✓
- 从搜索点书 → 书籍页按返回 → 回搜索 ✓
- 直接打开书籍页（无历史）→ 返回 = 回首页（fallback：`router.push('/')`）
