# Topic Curation Policy

本文件定义主题阅读页的**当前策展规则**。它面向“应该推荐哪些书、推荐多少本、什么时候拆主题”这些问题，而不是书籍入库格式或页面写作风格。

## 优先级

- 本文件是当前主题书单策展的最高优先级规则。
- `docs/superpowers/plans/2026-06-01-topic-reading-panorama.md` 是一次全站规划快照，其中 `5-6 / 7-8 / 9-10` 的区间和“超过 10 本就拆分”等判断不再作为硬约束。
- `docs/topic-production-guide.md` 仍用于主题文章的结构、语气和生产流程；其中涉及固定书数的旧表述由本文件覆盖。
- 历史 plan 中的 Reading Path 是策展起点，不是永久冻结的书单。后续有明确的编辑判断或用户要求时，可以增删、替换、降级、升级和重排。

## 核心原则：最小充分，而不是固定数量

主题书单**没有固定最低本数，也没有最高本数**。

书单应当尽量短，但必须完整回答主题承诺的问题。判断一本书是否应该留下，不看“已经有几本”，而看它是否增加了一个不可替代的功能。

一本书至少应承担下列一种明确角色：

- **入口**：让非专业读者进入问题，建立基本语言和地图。
- **框架**：提供核心概念、方法、证据或分析模型。
- **实践**：把框架转成可执行动作、练习、流程或案例。
- **本土语境**：补足中国市场、制度、平台、文化或读者处境中无法由海外书替代的经验。
- **系统**：把个人问题放回产业、组织、制度、技术或长期结构。
- **批判/反例**：挑战主流叙事，暴露代价、边界、失败条件或证据争议。
- **桥梁**：把本主题与相邻主题连接起来，但仍对当前阅读目标有直接价值。

如果两本书承担几乎相同的角色，后一本只有“也是一本好书”而没有新的问题、证据、方法或重要对照，就应删掉或降为延伸阅读。

## 什么时候继续加书

满足以下任一条件时，可以继续增加书籍，即使书单已经超过 10 本：

- 当前路径缺少一个必要角色，例如只有方法，没有风险与边界。
- 海外经典解释了普遍机制，但缺少中国读者实际面对的平台、制度或市场语境。
- 某一争议问题需要不同立场或证据质量的对照，单本书容易形成误导。
- 主题横跨多个阶段，而每个阶段都服务于同一个最终读者目标。
- 新书明显更新了旧书已经过时的实践环境，同时旧书仍保留长期框架价值。

## 什么时候停止加书

出现以下信号时应停止：

- 核心问题已经被入口、框架、实践、系统/边界完整覆盖。
- 新增书只能提供更多案例，不能改变读者的判断或行动。
- 为了“全面”开始收集相邻主题的书，导致主题边界变模糊。
- 阅读成本继续上升，但新增信息的边际价值明显下降。

## 什么时候拆主题

**不要因为书单超过某个数字就拆。**

只有出现下列结构性问题时才拆：

1. 一个页面同时服务两个可以独立成立的读者目标；
2. 两部分分别需要自己的入口书、核心框架和建议读法；
3. 读完其中一部分并不需要理解另一部分，也能完成一个完整目标；
4. 合并后标题不得不变得宽泛，读者无法判断页面究竟解决什么。

如果只是同一目标包含多个连续阶段，例如“创作 → 分发 → 经营 → 平台风险”，可以保持为一条较长路径，并通过正文分阶段阅读。

## 本土与海外书的关系

不设置中外作者比例。

选择标准是解释力和适用性：

- 普遍机制、成熟研究、长期框架可以优先使用最好的来源，不因作者国籍排除。
- 强平台依赖、强制度依赖、强文化语境的问题，应主动检查是否缺少中国经验。
- 中国实战书不能因为“更接地气”就免于证据和时效审查；平台规则、流量比例、收入区间和功能说明尤其需要标注时效性。
- 海外经典不能因为“经典”就自动占据核心位置；若无法改变中国读者的实际决策，可以降为系统或延伸阅读。

## `in_library` 与 `planned`

策展和入库是两件事。

- 已有高质量书籍提炼的推荐使用 `status: in_library`，并提供真实 `slug` / `path`。
- 明确值得进入路径、但尚未完成书籍提炼的书，可以先用 `status: planned`。
- `planned` 不得编造 slug、path、微信读书链接或“已入库”状态。
- 后续补完书籍提炼后，再把该推荐升级为 `in_library`。
- 不应为了保持所有卡片可点击，而把更合适但暂未入库的书从策展结果中删除。

## 最终检查

发布或重构一个主题前，至少回答：

1. 这个页面承诺解决的读者问题是什么？
2. 每一本书比前一本多增加了什么？
3. 是否缺少中国语境、实践、系统风险或批判视角？
4. 是否有两本书只是重复同一种角色？
5. 如果有 12、15 本，它们是否仍服务同一个读者目标？
6. 如果只有 4、5 本，它们是否已经足够，而不是因为数量焦虑继续凑书？

**书单长度是策展结果，不是策展输入。**
