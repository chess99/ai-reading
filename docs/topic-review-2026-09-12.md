# 主题阅读全面复盘与优化建议（2026-09-12）

本次审查以 `bda7344` 时的仓库为基线。审查范围包括全部 74 篇主题正文、521 条结构化推荐、560 本馆藏的元数据、重点推荐与馆藏正文的对应关系、主题浏览和详情页实现，以及五月至八月的主要变更。

这是评估与建议稿，不是已经批准的新版策展规范。本轮没有修改线上主题、书籍内容、分类或页面功能。历史规划中的“最高优先级”“必须”“已批准”等措辞不作为本次判断的依据，也不把 Git 提交的作者身份等同于用户逐项批准了内容。

审查区分三种结论：**已确认的仓库内部错配**、**有文本依据的编辑判断**、**需要后续核实的书目或研究问题**。没有逐本核验 560 本书的原版、全部引文及最新研究，也没有用户访谈、访问漏斗或阅读完成率数据；因此下文不把编辑推断写成已验证的用户行为。

## 一、我的结论

**需要重构，但主要是策展方式和阅读体验的重构，不需要先推倒目录，也不宜再做一轮以合并、拆分和主题数量为中心的调整。**

当前主题体系已经是一套可用的通识书单：大多数读者问题可以辨认，推荐普遍有解释，八月的调整解决了几组明显重复，也纠正了普通投资与价值选股的混同。这些积累值得保留。

但它还没有稳定做到“帮读者选对书、读懂不同书之间的关系”。主要问题依次是：

1. **少数推荐已经发生对象错配。** 页面讲的书，与点击后看到的馆藏不是同一种内容。这会直接破坏信任，优先于任何主题分类优化。
2. **覆盖更像知识工作者的成长路线，离广泛的通识阅读仍有距离。** 自我管理、心理修复、管理、产品很细；自然科学、文学作品、具体历史经验、日常照护明显较弱。
3. **把太多不同目的的书组织成一条“先读完这些，再进入那些”的长链。** 看起来有梯度，实际常是不同维度或不同学派的并列，甚至只是给已有书单补过渡句。
4. **选书重知名度、概念角色和跨主题复用，轻对象核实、证据层次与不可替代的具体贡献。** “系统视角”“边界”“意义”尤其容易成为万能入选理由。
5. **文案已去掉不少夸张词，但仍有生产模板、改版说明和缺乏信息量的重复。** 自然、克制的语气，并没有自动保证选书正确或论证可靠。
6. **页面把荐读路径放在长文后面，缺少第一本的直接入口和明确的分支选择。** 已有专项层级也不能充分表达跨领域关系。

建议按“修错 → 调整读法与关键书单 → 补覆盖 → 扩展界面”的顺序推进，不预设最后必须剩多少个主题。

## 三、哪些旧原则值得保留，哪些应降为可选方法

| 旧原则或隐含习惯 | 本次判断 | 建议 |
|---|---|---|
| 不设固定书数 | 保留 | 数量确实不能决定质量；同时让读者明确哪些先读、哪些按需读 |
| 最小充分 | 作为实用主题的默认偏好 | 对文学、历史和哲学，“不可替代的信息增量”不是唯一价值；声音、形式、体验和解释冲突也值得并读 |
| 从读者问题出发 | 保留并放宽 | 问题可以是“怎么办”，也可以是“发生过什么”“这部作品怎样写”“我想看看陌生世界” |
| 每条路径都要入口、框架、实践、系统/批判 | 不宜继续要求 | 有些主题适合循序学习，有些适合比较，有些适合按问题查阅；不能为了补“系统”把泛书塞到末尾 |
| 两个目标独立才可以拆 | 有帮助，但不是唯一条件 | 同一大目标下，受众、基础知识和证据要求差异很大，也可能需要分支；反过来，两个目标也能通过导航页共享背景 |
| 每本书有一个短角色 | 不足以证明入选 | “系统”“边界”“入口”是标签；还要说明它具体补什么、读哪部分、为什么不用更直接的书 |
| 中外书不设比例 | 保留 | 判断本土适用性要看制度、案例和行动条件，不以作者国籍代替核实 |
| 可以先推荐待入库好书 | 保留 | 页面须明确“解读待补”；与已经可读的书区分，而不是靠取消点击能力暗示 |
| 敏感主题放免责声明 | 只是其中一项 | 需要的是相应的证据审查和恰当的入口顺序；免责段不能补偿错误选书，也不必给经济史机械加交易警告 |
| 既有层级是“主线—专项” | 保留为一种关系 | 增加并读、相关问题、需要时再看等关系；专项不必总是更难，也不必只从父页进入 |
| 统一语气和结构 | 语气可协调，文章不应同模 | 保留具体、审慎的写法；允许不同学科有不同的阅读方式 |

未来策展不需要再写一份更严的长规则。先用少量问题约束判断：读者为何来、书是不是这本书、证据或经验来自哪里、为什么选它、从哪里开始、什么时候可以停。

### 4.2 证据与解释方式的问题

以下是基于页面措辞的编辑审查，并非本轮已完成对每本书的研究复核。

- **社会心理页不应劝读者暂时绕过实验争议。** 当前写：“读这本书时，不要急着判断实验争议本身，而要抓住它提出的情境问题。”实验能支持怎样的结论，恰恰依赖争议涉及什么。建议把《路西法效应》《对权威的服从》《盲点》放入经典研究及其局限的比较阅读，核实相关方法与证据，不把所有经典一概判废，也不把结论预先保住。
- **行为经济学页把“可重复的非理性行为”写进《怪诞行为学》的推荐理由，强于当前提供的依据。** 可介绍其案例和研究问题，但“哪些结果得到怎样的复核”需要按具体研究核验。新入库的 *Science Fictions* 可以补研究可靠性视角，不能拿另一本大众书充当所有争议的最终裁决。
- **国际秩序页不是充分的理论比较。** 《世界秩序》《大国政治的悲剧》《大国的兴衰》《注定一战》主要把读者带向大国、实力、安全竞争和权力转移。应补国际合作、制度、国内政治与相互依赖等解释，或把题名缩为“大国竞争与安全困境”。“作者有立场”一句不足以提供替代解释。
- **心理主题几乎全沿治疗、自助与修复来理解心理。** 日常情绪、精神障碍、创伤、灵性体验不是同一类内容。把《当下的力量》放入内耗行动主线，容易让读者误认其与认知/行为方法具有同类证据基础。建议移为明确的精神体验选读。
- **健康页的问题不止是哪本书有争议。** 健康总览多本围绕睡眠、运动、精力，却没有同等直接的饮食、吸烟饮酒、预防和健康信息判断入口；照护页则用疾病机制和长寿替代了实际照护知识。补免责声明不能弥补这些内容空缺。
- **争议书不必因此得到固定推荐席位。** 饮食页把《肥胖代码》《深度营养》降为“争议对照”是进步，但入门者未必需要先读两本完整争议书。编辑应挑出需要比较的具体主张、给出核实结果，而不是把核查任务全部交给读者。

## 五、覆盖：从“成长路线”扩展成更完整的阅读入口

### 5.1 最值得补的空白

| 缺口 | 现状依据 | 可行动的方向 |
|---|---|---|
| 自然科学 | “科学世界观”读科学哲学和方法；没有独立的生命、物理、数学、物质世界主题 | 自然科学应有可见入口，不继续藏在“思维”里；可先做生命演化、物理世界两条，再看数学与工程 |
| 文学作品阅读 | 文学入门 6 本全是指导、理论、文学史或讲稿；实际作品只被偶尔借用作意义材料 | 将阅读指导与作品并用；既可做“怎样读一篇小说”，也可做围绕经验、形式、时代的作品专题 |
| 具体历史经验 | 五条历史路径偏通史、国家、制度、兴衰；新馆藏大量战争、殖民、社会史、传记未进入路径 | 增加围绕事件和普通人经验的深读，而不是再添一条宏大“文明解释” |
| 照护与生活支持 | “照护”四本只有《最好的告别》直接承担较多照护决策，缺长期照护与照护者日常 | 重构现有页，围绕功能下降、失能、照护分工、患者意愿和支持资源策展；不必先拆新页 |
| 青少年、友情、家庭阶段 | 关系六题集中于伴侣和较年幼孩子；同伴、青春期、成年子女与父母关系不充分 | 是潜在需求，不立即各建一页；先给养育页年龄入口，再结合真实需求决定独立主题 |
| 工作、住房与现实权利 | 职业偏能力积累，城市偏理论，法律偏法理；失业、劳动处境、租住和保障的路径不清楚 | 先用工作/住房问题连接现有主题，补社会调查与本土制度材料；有独立内容后再立专题 |
| 宗教、诗歌、音乐等人文经验 | 人文主要是小说方法、美术审美与人生智慧 | 属于后续可扩展方向；不为声称“全覆盖”立刻铺齐 |

自然科学和文学不是为了分类对称而补。当前书库已经具备可用材料，主题入口却仍停留在旧书池；这是内容增长与策展更新脱节。

### 5.2 从已有馆藏就可以开始的候选

下面是候选配对，不是批准后的书单。书名沿用当前馆藏显示方式，英文标题不代表本轮建议批量改名。新增路径前仍需核实提炼质量、难度和书目身份。

| 候选阅读问题 | 可用馆藏 | 编辑方式 |
|---|---|---|
| 生命怎样演化，又怎样相互依存 | 《自私的基因》《基因传》《我包罗万象》《万物的“视界”》 | 分别讨论选择、遗传、共生和感知；不强行宣称四本构成一条简单递进或同一立场 |
| 物理学怎样改变对世界的理解 | *The World According to Physics*、《上帝掷骰子吗》、《时间简史》、*The Perfect Theory* | 先有总览，再按量子/时空分支；阅读需要的数学基础明确说明 |
| 大脑、心智与意识是什么关系 | 《心智探奇》《意识的解释》《章鱼、海洋与深层起源》 | 按解释问题和立场比较，不把不同年代和理论当作依次升级的确定答案 |
| 权力怎样进入日常生活与语言 | 《动物农场》《1984》《美丽新世界》 | 以作品为主体，比较叙述、制度想象和人物经验；不要把小说变成政治结论摘要 |
| 身体、身份与他人的眼光 | 《黄色墙纸》《献给阿尔吉侬的花束》《一间自己的房间》 | 交代小说、短篇和随笔的差异，围绕文本做细读，而非简单归为“自我成长” |
| 战争怎样改变普通人的生活 | 《西线无战事》《昨日的世界》及已入库战争史/口述史 | 区分小说、回忆录和史学叙述；具体书单应缩到明确时代或比较问题，不能把所有战争都串起 |
| 看懂住房、劳动与机会 | 《逐出》《跑外卖》《社会学的想象力》《置身事内》 | 以具体调查为入口，再连接机制；明确美国住房与中国劳动、地方财政并非同一制度 |
| 技术背后有哪些物质条件 | *Nuts and Bolts*、*Exactly*、《石油风云》或 *Cobalt Red* | 从工程、精密制造、能源或矿产分支出发，补技术主题只看网络与媒介的偏向 |

这些方向不需要一次全部上线。第一轮扩覆盖可以挑“自然科学入口”和“作品细读”各一个，检验新的策展形式是否真的优于现有长书单。

### 5.3 领域层面怎么改

不建议现在重排所有一级领域。更小、更有理由的调整是：

- “思维”继续容纳判断、概率、证据和系统方法；给自然科学独立的浏览入口，科学方法可以跨入口出现。
- “环境、气候与可持续生活”离开健康领域的唯一归属，至少可以从科学、社会两个入口发现；若后续主题增多，再独立为领域。
- “人生哲学入门”保留其好生活问题，不让它代表全部哲学；认识论、政治哲学、宗教经验可逐步补入。
- 分类用于找主题；阅读方式、基础要求、场景阶段分别表达，不再让一个父子树同时承担所有关系。

## 六、主题划分与设计：不只问合不合并

### 6.1 学习、自我管理与职业资本

保留各自问题，但把边界落到读者可以分辨的结果上：

| 主题 | 应主要解决 | 应减少的内容 |
|---|---|---|
| 习惯 | 一个行为怎样稳定发生 | 过多动机、人生取舍和一般自控书 |
| 深度工作 | 怎样保护连续注意力并完成高认知任务 | 把技能训练、任务系统和整个职业成长都纳入核心 |
| 时间与个人系统 | 怎样管理承诺、安排优先级和回顾 | 为了收尾重复人生原则 |
| 学习 | 怎样记住、理解、迁移和练习 | 把阅读方法当所有学习的第一步；与习惯页重复解释坚持 |
| 阅读与笔记 | 怎样从材料形成可引用、可连接的理解 | 预设每个人都必须建设复杂笔记系统并持续写作 |
| 职业资本 | 能力怎样被市场看见、验证和认可 | 只讲练习、专注、取舍，却缺机会、合作、声誉与可迁移性 |

当前学习与深度工作共享 4 本，深度工作与职业资本共享 3 本。这不自动要求合并，但如果重写核心后职业资本仍只剩“认真练习、深度工作、少做事情”，就应暂改为导航/组合路径，等补上职业证据和机会机制再成为完整独立书单。

### 6.2 心理与关系

“情绪”“反刍与拖延”“焦虑抑郁”“创伤”“成瘾”“哀伤”可以分别成立，不能只按共享书多就合并。

更值得改变的是入口逻辑：日常情绪不必一路带向创伤；焦虑抑郁不必在“先完成情绪素养”后才能读；成瘾不应把刷屏、暴食、赌博和物质依赖处理成相同的日常自控问题。

建议让“焦虑与抑郁”在搜索和心理入口中直接可见，并把“专项”改为内容关联而非能力等级。关系安全也应先让读者找到控制、边界与支持的内容，不要求先读完整《亲密关系》和鲍尔比《依恋》。当前页已写现实危险时优先求助，也限制了《高难度谈话》的适用条件；应保留这些有效判断，同时调整书序。

亲密关系吸收冲突页的方向不必推翻，但 10 本不必全部设为同一路径。以《亲密关系》作总览，《幸福的婚姻》和《抱紧我》按需要并读；一般沟通、爱的哲学、依恋理论史、创伤分别按需进入。

### 6.3 产品、创业、经营与团队

“产品从 0 到 1”目前从独特命题一路走到主流市场、交付流动、创业管理和增长，实际承担创业总地图。建议保留它的总览价值，将专业分支直接连到产品发现、交付、经营和增长页，避免总览本身再成为完整课程。

“产品发现”不应定义成“产品已经值得做之后”的阶段。发现本身也在检验机会是否值得做，而且成熟产品同样需要持续发现。可以保持与 0→1 的关联，同时独立呈现在产品入口中，不必重新恢复“验证产品机会”重复页。

“商业模式与公司经营”与 0→1 共享《商业模式新生代》《客户开发入门》《精益创业》《创业维艰》4 本。建议把经营页重心移到价值创造、收入成本、现金流、定价和经营约束，客户验证只保留必要背景。

“产品组织与交付”缺的不是更多领导力书，而是更直接的软件交付、团队边界和工作流证据。可进一步评估 *Accelerate*、*Team Topologies* 等专门书；二者本轮未入库核实，不直接生成推荐元数据。

自媒体页是目前场景和本土意识较好的例子。保留创作、传播、经营的主目标；把 3 本产业研究作为明确的深入分支，而不是只有账号赚到钱才值得思考风险。不同阶段都可以按需看风险信息。

### 6.4 社会、历史、科技和环境

这几组书单的问题更多是解释角度相似，而不只是共享书：

- 世界史、兴衰、国际秩序都偏大国和宏观结构，需要具体历史和不同解释相互校验。
- “中国社会的现代转型”八月重构后更像“理解中国国家治理与地方发展”。如果保留原题，就应增加社会生活、家庭、人口、劳动等材料；若想维持当前核心，改题更诚实。
- “技术社会”实际主要讨论数字网络和媒介。可以缩题；若保留大题，应补工程、基础设施、能源和劳动。
- 平台商业、注意力与算法、媒体公共讨论是三个可区分的问题，保留即可。共享背景书只推荐必要章节，并给出跨页链接，不反复要求读完整书。
- 环境书单应回答排放、能源、生态代价和行动尺度，不能靠《枪炮、病菌与钢铁》的地理背景填满“长期约束”角色。

## 七、选书与阅读顺序应怎么改

### 7.1 用真实贡献替代角色填空

每本重点书需要回答的，不只是“我把它叫作什么角色”，而是：

1. 这本书究竟是哪位作者、哪部作品？馆藏提炼与推荐理由是否一致？
2. 它提出什么具体问题、机制、证据或作品经验？
3. 读者需要整本读，还是只查一部分？是否有基础要求？
4. 它与上一部是递进、替代、应用，还是意见不同？
5. 当前中国读者在哪些地方可以迁移，哪些地方必须重新核实？

“给选择加上系统视角”“最后补上意义”“提供边界”往往还不够。典型是《原则》《人的境况》《身体从未忘记》《反脆弱》《技术的本质》被用于多条路径的收尾。这些书可以跨主题出现，但跨主题的每次使用都要重新成立。

当前最高复用次数为 5，分别出现在《幸福的陷阱》《身体从未忘记》《也许你该找个人聊聊》《我们为什么要睡觉》。频率本身没有超标；它提示要检查心理领域是否把多个不同问题都导向同一组解法。

### 7.2 同时降低“读完全部”的暗示与教材门槛

若面向普通人，以下顺序需要解释或重排：

- 价值投资第二本就是《证券分析》，但没有先区分读者是否能读财报。可把它标作查阅/进阶，基础薄弱者先用已入库《一本书读懂财报》补财务语言。
- 儿童安全感第一本是鲍尔比《依恋》。这是理论原典，不应仅因为是理论来源就默认最适合家长进入。
- 证据判断一次容纳三本批判思维、统计史、因果图、技术性因果推断和专家判断。应给新闻读者与研究学习者不同读法。
- 运动页先《ACSM高级运动生理学》再《生理学》，是概念从“应用”回“底层”的解释，不是天然的学习难度顺序。
- 管理者前三本都较重，日常授权、反馈和一对一谈话很晚才出现；可按“刚带人”与“理解管理传统”分路。

建议按内容采用三种形式，不设统一篇幅和固定本数：

| 形式 | 适合主题 | 页面应提供 |
|---|---|---|
| 实用路径 | 习惯、沟通、产品验证、家庭财务 | 眼前问题、起读点、可尝试的动作、何时换分支 |
| 比较阅读 | 幸福、正义、文明兴衰、国际秩序、科学方法 | 共同问题、不同主张、各自依据、冲突与局限 |
| 作品/历史专题 | 文学、传记、事件史、艺术 | 阅读对象、背景、形式线索、经验差异；不强求行动产出 |

它们是编辑工具，不是下一轮每篇必填的模版。

## 八、文案：整体克制，但仍有明显模板与解释过度

文案的机器感风险为中到高，主要来自重复结构和缺少具体编辑判断，不来自个别词语。现有不少开头已经有读者处境，且会说明范围，应该保留。需要优先处理以下五组问题。

| 类型 | 原文或例子 | 为什么值得改 | 建议 |
|---|---|---|---|
| 同一描述套用 20 篇 | “围绕理解价值投资，从《聪明的投资者》进入，逐步建立框架、实践判断和系统视角” | 用户从卡片看不出这页与一般投资页有什么不同 | 写具体主题范围和取舍 |
| 把编辑历史写进正文 | “本页因此不再借……撑篇幅”“所以本页从‘金钱’领域移回‘思维’” | 读者没有看过上一版，也不需要理解生产争论 | 移到变更记录，只写当前承诺 |
| 过度解释书序 | “适合作为第一本，因为”“放在最后，是为了”反复出现 | 容易把任意次序写成必要梯度 | 直接讲本书解决什么；只有顺序有实际前提时解释 |
| 再讲一遍完整书单 | 开场概览、逐本介绍、建议读法重复 | 篇幅增加，却没有帮助读者少读或选读 | 建议读法改成不同读者从哪里开始、哪些可以跳过 |
| 给读者布置机械作业 | “每读一章写三张自己的卡片” | 原章内容和读者目的并不支持固定产量 | 围绕需要保留的问题与引用做笔记，不按数量交作业 |

### 8.1 可直接采用的改写方向

**价值投资卡片描述**

原文：围绕理解价值投资，从《聪明的投资者》进入，逐步建立框架、实践判断和系统视角。

建议：从安全边际、财报和企业质量理解价值投资，比较格雷厄姆、费雪与巴菲特的不同重心。

**长期学习标题与描述**

当前题目是“如何长期坚持学习”，但主体在讲记忆、练习和反馈。

建议题目：怎样学得会、记得住、用得上。

建议描述：从提取练习、间隔学习和反馈开始，区分熟悉、记住与真正掌握；坚持和注意力问题可转入相邻路径。

**产品发现开头中的定位**

原文：这一页专门深入产品已经值得做之后，团队如何持续发现、验证和组织方案。

建议：无论是新产品还是已有产品，都需要检验用户问题与方案假设。这组书帮助团队决定下一步该验证什么、用什么证据判断。

**系统页《弹性》推荐**

原文：系统不只是要高效，也要能承受冲击、保留冗余、快速恢复。

建议：本次建议移出系统恢复力主线。若在创意主题保留，可写“当熟悉的解题方式失效时，这本书讨论如何换一种方式表示问题、容忍模糊并产生新联想。”

这里需要的是换角色或换书，不能只润色原句。

**自媒体待入库书**

当前正文写“计划补入”或直接展开书的作用，卡片则没有明确状态。

建议在卡片写“已选入书单，解读待补”，并给出当前可读的起点；正文不需要反复解释生产状态。

**阅读与笔记的读法**

原文：每读一章写三张自己的卡片，每周合并成一段短文。

建议：先带着一个问题读。只记录会改变你理解的观点、值得保留的引文和仍未解决的疑问；准备写作时，再把这些材料组织起来。

### 8.2 不应为了去模板而删掉的内容

自媒体页对中国平台时效、收入与生活边界的说明，长期投资页对账户制度的限定，关系安全页对危险关系与普通冲突的区分，都有具体功能，应保留并压缩重复。

改文风也不需要假装有人读过每本书、虚构个人经历或写得更随意。需要更明确地承认“这是一个解释”“这本只适合这一部分”“这个角色目前没有合适书”。

## 九、页面体验与维护机制

本节依据当前组件和数据实现，不把代码推断写成实测的用户流失结论。

### 9.1 找到第一本应比读完导读更容易

详情页在小屏使用上下排列：文章在前，荐读卡片的 `aside` 在后；正文中的书名多数只是普通文字。读者会先经过整篇文章，才遇到可点击的完整书单。

建议页面开头直接提供当前场景和起读书链接；正文中提到书时也能点击。长文下方仍可保留完整书单。不要只把侧栏机械挪到前面，导致用户又必须滚过十几张卡片才见导读。

### 9.2 序号不应独自代表读法

现在统一显示 01、02……，角色虽有“争议对照”，卡片呈现仍然平级。建议分别表达起读、并读、按需深入、查阅和对照；这是阅读方式，不是给书打高低等级。

对五本或十三本的主题，用户都应能马上判断：这次先选哪一本、有没有必要继续、另一分支是否更适合。

### 9.3 领域与父子关系不宜限制发现

搜索已有书名、作者、角色和理由匹配，这是优点。但领域筛选只看父主题领域，专项必须跟父页显示；当前数据模型只有一个父级。

建议先给主题添加明确的相关阅读链接，并允许专项直接作为搜索结果出现。以后确有需要再加多个领域入口和跨主题关联，不必先建设庞大的知识图谱。

“产品发现”应可从成熟产品工作进入，“焦虑抑郁”应可直接进入；“平台与网络效应”与“平台注意力风险”相互链接，分别解释商业结构和社会后果。

### 9.4 待入库状态需要显式说明

8 条 `planned` 分布在长期投资、国际秩序、文明兴衰、中国转型和自媒体 5 个主题，当前精确书名比对均未发现已入库同名记录。页面仅通过是否可点击区分，正文部分会提“计划补入”，体验不一致。

建议统一可见状态，并说明条目数包括待补解读。选书不因未入库而删除，但避免把“13 本书”暗示成“13 篇均可立即阅读”。

### 9.5 历史地址迁移还有缺口

`TOPIC_MERGES` 目前只为八月合并的 3 个旧 slug 提供迁移页。八月拆分删除的 3 个 slug，以及随后成瘾、团队协作改名删除的 2 个 slug，没有进入当前路由生成列表。六月还做过大批 slug 缩短。

建议从 Git 历史生成一次旧地址清单，针对一对一迁移设置明确目标、一对多拆分提供选择页。GitHub Pages 静态站点应采用适合静态部署的跳转或迁移页面，不能假设有动态服务器重定向。当前能确认的是源代码未生成这些迁移路由，未在本轮逐个实测生产地址。

### 9.6 让检查保障真实性，而不冻结上一代 AI 的选择

当前主题测试验证 slug、状态、路径存在、正文长度和“建议读法”等，还硬编码部分旧合并、拆分与父子关系；它不检查推荐理由是否对应书的内容，标题作者与馆藏元数据也没有全面相等校验。

建议后续区分三层检查：

- 可自动验证：链接存在、书目身份字段一致、待入库状态、迁移目标、无失效父级或环路。
- 需要编辑核查：作者/原作核实、具体角色与章节依据、重复内容、证据表达、读法是否成立。
- 可以修改的产品决策：父子关系、分支数量、标题与结构。这些改变时更新相应测试，而不把旧测试当策展真理。

元数据一致也只是必要条件：《对赌》目前标题、作者、链接都互相一致，错误发生在推荐内容上。每次实质策展应留下简短的核验记录；无需把内部核验字段全部显示给读者。

## 十一、建议实施顺序与验收方法

### 第一轮：修复能直接损害信任的错误

范围：两条《对赌》推荐、《弹性》《情绪勒索》《身体使用手册》的角色错配；核对《字字珠玑》与宇泽弘文书的推荐重心；修掉让人绕过实验争议的措辞。

完成标准：每条争议推荐都能对应实际作品和具体内容；如果更换目标书，重新核实作者、馆藏与微信读书映射，不仅修改显示名。这个阶段不做全站主题增删。

### 第二轮：选择不同类型主题，试出更好的读法

优先用“产品从 0 到 1”“亲密关系”“证据判断”“国际秩序”“文学入门”“照护”试编，分别检验总览、按情境分支、技术门槛、理论比较、作品细读与真实生活支持。

完成标准：读者在开头就能找到起读点；能看出不同书之间是承接、替代还是争论；不读全部也能完成明确目标；核心内容有实际书籍或可靠资源支撑。这个样本不是以后批量写作必须照抄的统一模板。

### 第三轮：按矩阵清理现有主题

优先处理心理健康、家庭财务、儿童发展、AI 和社会心理的适用性与证据问题；再整理学习、职业和商业重叠。同步重写 20 篇模板描述，删除正文改版史，校正书籍角色与按需读法。

完成标准：每个主题的标题、书单和阅读建议相互兑现；没有为了“系统/意义/批判”保留的空角色；共用书不要求读者反复整本重读。

### 第四轮：补可见的覆盖缺口

先增加自然科学和作品阅读的入口，再按馆藏质量与实际需求推进具体历史、住房劳动、青少年与照护相关内容。不用新领域数量、各领域平均篇数或书数作为验收标准。

### 页面改进与迁移可随内容迭代同步进行

先做起读链接、正文书名链接、待入库标签、相关主题和旧地址迁移；之后再考虑多领域入口、比较阅读展示与阅读状态。无需为了本次建议立即更换框架或重写整个网站。

若有条件做读者验证，重点观察三件事：能否选到合适主题、能否选到第一本、看过导读后能否说清两本书的差异。行为数据可以补点击入口、书籍跳转和返回主题的情况；不能把点击率简单等同于学习效果。
