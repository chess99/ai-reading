# 产品从 0 到 1

做出产品之前，最值得花钱验证的可能是用户是否真的遇到问题；有了使用者之后，问题可能变成是否愿意付费、是否持续回来，以及交付能否承担成本。

## 从当前最不确定的地方开始

| 当前处境 | 阅读重点 |
|---|---|
| 只有想法，还缺用户事实 | 用《妈妈测试》准备访谈，追问真实行为 |
| 有初步证据，不知道怎样试验 | 用《精益创业》明确假设与学习目标 |
| 用户需要，但业务算不清 | 用《商业模式新生代》检查收入、成本和资源 |
| 早期用户满意，扩展却卡住 | 按市场条件选读《跨越鸿沟》 |

《四步创业法》适合作为阶段参考。《启示录》帮助理解持续发现，它既发生在新产品阶段，也存在于成熟产品的每次重要选择中。

## 想法独特，不是唯一的起点

《从零到一》强调独特判断与市场位置，是一种有鲜明立场的战略论述。已有方案的改进、特定人群的需求和服务过程创新，同样可能值得做。是否投入，应回到用户价值与业务条件。

## 建议读法

先写出最危险的一个假设、能观察到的行为和改变决定的条件。完成一次验证，再决定下一阶段需要什么。交付、经营和增长可以进入对应主题，不必在第一次访谈前学完整套创业课程。
