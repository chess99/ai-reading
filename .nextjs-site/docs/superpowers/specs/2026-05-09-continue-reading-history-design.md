# 继续阅读 — 多条历史记录设计

**日期**: 2026-05-09  
**状态**: 已确认，待实现

---

## 背景

当前"继续阅读"组件只记录最近一本书（`localStorage` 存单条 `ReadingState`）。需要扩展为支持多条历史记录，让用户能快速返回近期读过的书。

---

## 设计目标

- 首页默认不增加视觉噪音
- 用户能快速跳回近 5 本读过的书
- 交互直觉，无需学习

---

## 最终设计

### 外观与布局

卡片分三层，从上到下：

1. **主行**：展示最近阅读的一本书（书名、作者、时间），整行可点击跳转
2. **触发条**：内嵌在卡片底部，显示"最近读过 +N"角标，点击展开/折叠
3. **历史面板**：默认折叠（max-height: 0），展开后列出其余最多 4 条历史记录

历史记录为空（只有 1 条）时，触发条不渲染。

### 交互行为

**触发条**
- 点击切换展开/折叠
- 折叠动画：`max-height` transition，约 280ms，`cubic-bezier(0.4,0,0.2,1)`
- 角标数字 = 历史条数（不含主卡片）

**点击历史条目**
- 乐观更新：主卡片内容立即切换为被点击的书（淡出淡入，约 120ms）
- 同时发起页面跳转（不等动画结束）
- 历史面板收起

**hover 效果**
- 主行 hover：背景变浅紫，书名变 brand 色，箭头右移 2px
- 历史条目 hover：背景变浅紫，文字变 brand 色，整行右移 2px

### 存储结构

`localStorage` key 从 `reading-state-last-book` 改为 `reading-state-history`，值为数组：

```ts
type ReadingHistory = ReadingState[]  // 最多 5 条，index 0 为最近
```

**写入规则**：
- 每次进入书籍页时，将当前书插入数组头部
- 若已存在相同 `bookSlug`，先移除旧条目再插入头部（去重）
- 超过 5 条时截断尾部

**读取规则**：
- `history[0]` → 主卡片
- `history[1..4]` → 历史面板列表
